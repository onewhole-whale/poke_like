# 现有精灵命名风格诊断（2026-09-17）

> 分析模式产出。样本：index.html SPECIES 全部 66 只精灵、21 条进化链；素材与技能命名作对照。本诊断不新增批量命名（示例除外）。

## 一、总评

现有命名系统的病灶不是「个别名字俗」，而是「整套命名走的是标签式生产逻辑，不是设计逻辑」。
66 只精灵 100% 采用「修饰词 + 名词」结构，没有一只是独立意象词（对比：宝可梦的 Onix/Lapras 是独词意象）。
56%（37 只）直接以动物物种词结尾（狼/龟/雀/狐/枭/猫/隼/犀/蛛/鹿/蛇/蛟/蝠/豹/凰/龙/兽/妖）。

## 三、命名结构规律

1. 基础形态：绝大多数为「属性/特征词 + 物种名」直拼（炎狼、熔岩龟、雷枭、风隼……），名字 = 图鉴字段。
2. 进化递进：靠「形容词膨胀」+「权力后缀」（炎→炽焰→焚天；+王/+魔/+神/+皇），等级越高形容词越大。
3. 意象来源单一：全部来自元素表面特征，无典故、无生态位、无故事（与设计哲学「精灵有来历有记忆点」相悖）。
4. 各元素系词汇 = 元素标签堆叠（火=炎/焰/焚，雷=雷/电/霆，水=水/潮/沧），14 属性套同一套词库。

## 四、俗在哪（逐项）

1. **物种名直裸当后缀**：狼、龟、雀、狐直接进名字，像图鉴字段不像名字。好命名的物种词应该被转化（牙/鬃/眸/蹄/歌/客……），而不是裸奔。
2. **「X王」批发**：6 个王——狼王/鹰王/隼王/犀王/蝠王/南瓜王，古早玄幻小说权力词库的最顶层。
3. **「焚天/万雷/圣辉/罡风」形容词膨胀**：进化只是把形容词换大，不是身份、形态、来历的转变。等级升了，但名字的「叙事」没有升。
4. **链上断裂个案**：
   - 幽蝠 → 暗夜蝠王 → 血翼幽蝠：完美态与基础态撞「幽蝠」，链感断裂；
   - 寒潭蛟 → 寒蛟：进化后字数倒退（3→2），「寒潭」有画面，「寒」只剩形容词，意象变弱；
   - 雷枭 → 雷鹰王：枭→鹰是物种跳变，不是进化连续性。
5. **素材命名 > 精灵命名**：素材里有「余烬火绒、蚀月爪、魂烛、血珀、锈风铃、哀嚎珠」这批有画面、有细节的名字——说明文案手感在线，精灵命名是批量生产时掉线了。

## 五、例外（可作标杆）

- 蚀时之蛇：概念化命名（「时间被腐蚀」这个意象成立且独特）；
- 拾穗人 → 丰收使者 → 麦田守望者：人设化命名，有故事感、有生态位；
- 织影蛛：动作+意象（「织影」比「影蛛」高一个档次）；
- 血月侯：「侯」是爵位，有身份感，是传说精灵里最好的；
- 缠纱使、不朽法老：身份化命名；
- 狼嚎客：「客」字用得妙，有画面。

## 六、可固化规范（更新《文案风格规范》）

1. 禁用「X王 / X皇 / X神 / X魔 / 焚天 / 万X / 天X」直白权力词（除非名字本身能讲出来历）；
2. 命名单位从「属性+物种」转为「意象+意象 / 动作+意象 / 身份+意象」；
3. 物种名不裸奔：用身体部位、动作、生态位、典故替代（狼→牙/鬃/嚎/客……）；
4. 进化链递进 = 形态/身份/来历的跃迁，不是形容词变大；禁止链上撞名、字数倒退、物种跳变；
5. 素材命名的质量线 = 精灵命名的底线（余烬火绒、蚀月爪是参照系）。

## 七、示例（供确认方向，非定稿）

- 火狼链：烬牙 → 燎鬃 → 灰烬行者（意象特写 → 形态跃迁 → 身份）
- 熔岩龟链：负焰 → 驮岳 → 不周（动作意象 → 神话意象，龟背不周山）
- 水灵狐链：尾珠 → 潮歌 → 沧海谣（细节 → 意境 → 气质）
