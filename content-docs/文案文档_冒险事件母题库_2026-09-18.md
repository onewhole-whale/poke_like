## 1. 母题设计原则

1. **片段级**：冒险事件不需要完整故事三幕，只给**一个场景遭遇**（触发 → 2~3 层选择 → 结局）。
2. **可复用框架**：母题是"故事骨架"，不是具体故事——用变量位（【随机】地形生态、【判定】亲和力/属性门槛）替换后即可套任意地图。
3. **奖励温和**：冒险事件可重复发生，结局奖励以**素材 / 信物 / 局内状态**为主；永久性大奖励（传承、亲和力、传说物）留给一次性奇遇事件（防批量刷取，服务核心设计理念）。
4. **有惩罚梯度**：允许失败/错过分支（丢一点素材、被逐出、触发战斗），但冒险事件无永久损失，玩家可放心试错。
5. **母题间可转接**：一条事件链可串两个母题（如「迷途引路」→「守宝者考验」），落地时支持。
6. **故事内部完整**（可重复刷取的硬约束）：每个事件条目是独立闭合的小故事——触发 → 过程 → 结算，拿走该拿的、失去该失去的。**不留悬念钩子、不引入额外元素**（"晶石空心藏芯""神秘脚印""更早来的人"这类引向后续故事的钩子一律不写）；触发文案不锁频率（可重复事件不写"十年一见"）。
7. **文风反玄虚反装逼**：只写发生了什么（动作／事实／对话），删"它是在挑人""暗处有什么在看你"式升华；路人行为要符合身份——普通守林人第一次见天降异象会震惊、会喊人，不会一脸"果然来了"的大佬样，无叙事功能的角色干脆不写；措辞书面（不写"没兽理你"式口语缩略，应是"没有妖兽理会你"）；参考冒险小说文笔。
8. **竞争者用本图真实生态**：事件中的妖兽挂地图既有精灵（狼群、鹰等），不凭空造神秘角色（"黑兽"类删除）。每个分支都要有结算（胜／败／得／失），不存在"没代价"的路径；战斗路径的"打赢"本身即门槛，不需要额外加码；速度判定路径与战斗路径成本不同，是逃课机制，属设计使然。

## 4. 母题框架明细（10 个，分支式）

### 4.1 坠崖获宝
```
触发：意外坠落（踏空/被击落/追逃失足）
├─① 中途求生 [判定：反应]
│   ├─ 抓住藤蔓/凸石 → 缓落半崖，发现裂缝/洞穴 → 钻入
│   └─ 直坠 → 水潭/树冠缓冲 → 谷底
├─② 崖下奇遇 [随机其一]
│   ├─ 秘洞藏宝 → 取宝 → [守护机关/守宝兽] → 得宝而逃 / 触发战斗
│   ├─ 前辈遗骸 → 安葬取物 → 得遗物 / 染怨念
│   ├─ 妖兽空巢 → 有蛋/幼崽/收集物 → 带走 / 不动 → 母兽归来 → 结缘 / 冲突
│   └─ 灵泉 → 疗伤+恢复 → 守泉兽现身 → 契约（付素材） / 被逐
└─③ 脱身：原路攀回（耗体力） vs 发现地下通道 → 通向本图随机新区域
```

### 4.2 渡水遇劫
```
触发：渡河/跨桥/泛舟遇险（急流/断桥/水兽）
├─① 落水 [判定]
│   ├─ 挣扎上岸 → 原地打转，损失部分素材（被冲走）
│   └─ 被冲下游 → 漂至水湾/隐蔽入口 → 新发现
└─② 水兽（可选）→ 战斗 / 绕行
```

### 4.3 迷途引路
```
触发：误入雾林/迷阵/岔路，方向感失效
├─① 遇引路者 [随机：光点/灵兽/老者/萤火]
│   ├─ 跟随 → 引向隐藏资源点 / 秘境入口 / 宝地线索
│   └─ 警惕拒绝 → 原路摸索 → 无事 / 误入险地
└─② 引路者真意 [随机]
    ├─ 善意：引到灵物旁，讨一点"引路费"（素材）→ 双赢
    ├─ 考验：引到守宝者面前 → 转「守宝者考验」
    └─ 恶意：引入困兽地/幻境 → 战斗 / 脱身
```

### 4.4 幻象迷心
```
触发：踏入幻境（瘴气/古阵/妖异花香）
├─① 幻象内容 [随机：渴望之物/恐惧/已逝之人]
│   ├─ 识破 [判定：感知/心智] → 幻境破 → 得幻境核心物（素材碎片）
│   ├─ 沉溺 → 被幻境"刮"走部分素材/生机 → 被赶出
│   └─ 以力破幻 → 战幻兽 → 胜得宝 / 败被逐
```

### 4.5 鬼市奇遇（志怪风）
```
触发：雾中遇夜集/神秘摊位
├─① 入市交易 [随机：以物易物/答题/奇货]
│   ├─ 换得宝（超值）→ 天亮成真
│   ├─ 换得假物 → 天亮变普通/消失
│   └─ 奇货"以物易代价"（寿命/记忆）→ 接受 / 拒绝
└─② 醒来：市集消失 → 仅留所换之物
```

### 4.6 枯骨遗愿
```
触发：发现遗骸/残破遗物（洞穴/遗迹/古树下）
├─① 处理方式
│   ├─ 辨识遗愿 [判定：感知/知识] → 送物归乡/安葬/毁某物/传信
│   ├─ 直接翻找遗物 → 得物 → 可能触怨念/诅咒（短暂debuff）
│   └─ 离去 → 无事
└─② 完成遗愿
    ├─ 完成 → 遗骸显灵 → 赠信物（可换素材）/指点宝地 → 善意结局
    ├─ 拒绝/破坏 → 怨念缠身 → debuff / 触发战斗
    └─ 安葬但取物 → 得物，无额外馈赠
```

### 4.7 残局古阵
```
触发：发现残缺阵法/机关/封印纹路
├─① 解阵 [判定：知识/试错/道具]
│   ├─ 成功 → 阵心之物 → 得宝
│   ├─ 部分成功 → 小机关 → 躲过得残料 / 被弹开
│   └─ 失败 → 阵反噬 → 扣血 / 被传送（随机位移）
└─② 阵后之物 [随机：宝库/封印/通道]
    ├─ 宝库 → 取宝 → 或遇守阵灵
    ├─ 封印 → 加固 → 封印灵馈赠；破除 → 放出祸患（战斗/逃）
    └─ 通道 → 通向隐藏区域
```

### 4.8 两强相争
```
触发：两只/两群妖兽争斗，或一兽被围
├─① 立场
│   ├─ 帮弱势 → 胜：弱势方感激 → 赠信物/情报；败：一起逃
│   ├─ 旁观 → 分出胜负 → 胜者警惕你 → 对峙 / 让路
│   └─ 渔翁 → 两败俱伤后捡漏 → 得素材
└─② 后续
    ├─ 结缘：获信物/稀有资源点情报
    ├─ 记恨：败方族群记仇 → 本图后续遭遇战概率上升 / 复仇战
    └─ 卷入：被拖入更大冲突 → 脱身 or 战
```

### 4.9 守宝者考验
```
触发：发现宝地/宝光，有主（守兽/山灵/器灵）
├─① 接近方式
│   ├─ 礼敬（献礼/说明来意）→ 守宝者出题
│   ├─ 强闯 → 直接战斗（精英级）
│   └─ 绕行 → 错过
└─② 考验内容 [随机：问答/献宝/试炼战斗]
    ├─ 答对/献上合意之物 → 得宝（中档素材）+ 好感
    ├─ 失败 → 被逐出（无损失）/ 被戏弄（丢一点素材）
    └─ 试炼战斗 → 胜得宝 / 败空手
```

### 4.10 天降异象（v2 · 环节 × 手段模型）

**母题本质**：场景出现一个"大家都知道的好处"（异宝／矿藏／神兽幼崽／传承；连"拍卖会散场后的黑吃黑"也归此类）。NPC 侧永远走固定流程：**发现好处 → 聚集 → 争斗 → 结束**。主角改变的是：**从哪个环节介入 × 用什么手段介入 × 最后拿到没有、拿到多少**——变量组合即一个新故事。

**六种爽点原型**（主角行为类型，落地时尽量让多数可及）：

| # | 原型 | 行为 | 爽点 |
|---|---|---|---|
| 1 | 闷声发大财 | 隐藏身份，提前拿走好处 | 素质过硬或机缘巧合，无人知晓 |
| 2 | 无后果的发大财 | 隐藏身份，击败所有敌人后拿走 | 打完没人敢追究 |
| 3 | 偷偷发财 | 隐藏身份，从众人眼皮底下偷走 | 神不知鬼不觉 |
| 4 | 偷袭·以弱胜强 | 隐藏身份，趁两败俱伤击败对手 | 捡便宜＋越级战胜 |
| 5 | 天下无敌 | 明目张胆击败所有对手 | 参与者变收益（宝＋对手掉落素材） |
| 6 | 玩心跳 | 明目张胆抢了就跑 | 速度与心跳 |

**落库骨架（介入时机为第一层选择，夺宝手段为第二层）**：
```
触发：异象起（宝光/流星/地动），兽群与人都被惊动
├─ 介入时机 [三选一]
│   ├─ 抢先（发现环节）→ 独享线：第一个到，坑边无兽
│   │   ├─ 拿了就跑 [速度判定] → 成：完整好处，无人知晓（爽点1）｜ 败：被围，丢素材
│   │   └─ 贪心多看 → 兽群到，被围 → 转对峙线
│   ├─ 混入（聚集环节）→ 对峙线：兽群围而未斗
│   │   ├─ 潜伏偷 [隐匿判定] → 成：完整好处（爽点3）｜ 败：丢素材
│   │   ├─ 抢了就跑 [速度判定] → 成：完整好处＋烫伤（爽点6）｜ 败：丢素材
│   │   ├─ 等两败俱伤再出手 [战斗] → 胜：完整好处，无人敢拦（爽点4）｜ 败：丢素材
│   │   └─ 直接出手打服两边 [战斗] → 胜：好处＋对手素材掉落（爽点5）｜ 败：丢素材
│   └─ 晚到（争斗环节）→ 混战线：已开打，双方挂彩
│       ├─ 趁乱摸走 → 残渣/伴生物（小收获，无风险）
│       ├─ 等打完再捡 → 残渣＋兽毛（小收获，无风险）
│       └─ 横扫残局 [战斗] → 胜：完整好处（爽点2/5，对手已残易胜）｜ 败：丢素材
└─ 收束：得宝路径统一汇入"得手·收束"；失败路径各有结算（丢素材/小收获）
```

**收益梯度**：介入越早越"赌"（判定失败血亏），越晚越"稳"（捡漏无风险但收益薄）；横扫线用战斗换全宝，对手已残，难度低于对峙线打满状态。

**硬约束（可重复刷取）**：见 §1 第 6~8 条——故事内部完整不留悬念、不引额外元素、触发不锁频率、战斗即门槛、通用状态用通用名（烫伤，不用自造词）、竞争者用本图真实妖兽、文风反玄虚。

**范例**：见 4.10.1「赤光坠地」完整事件链。

### 4.10.1 范例：赤光坠地（天降异象 · 坠星晶）

**事件：赤光坠地**｜灵物：坠星晶｜kind: adventure（可重复）｜两章结构

**n0 触发**
> 入夜，西边天际亮起一道赤光，拖着长尾斜斜坠下。落地那一下，整条山脉亮了一瞬，连村里水缸都晃出圈纹。兽吼从四面八方响起来，一波接一波往西涌，惊得村口的狗叫了一夜。
> 天亮前动静小了，可西边半空还泛着红。你想了想，决定去看看。

- 抄近路翻山，赶在兽群前头（判定位：速度／攀爬）→ n1
- 混进兽道，跟着兽群走 → n2
- 不急，等那边消停了再去看看 → n3

**n1 翻山（判定）**
> 山路陡，你贴着崖壁走，山那头的兽吼越来越密。
- 成功：翻过山脊，赤光还亮着，坑边一只兽都没有——你是第一个到的 → n4
- 失败：脚下一滑滚了半坡，爬起来绕了远路。你到时，兽群已经围了一圈 → n2

**n2 兽道**
> 兽道上全是往西跑的兽，你夹在中间走，没有妖兽理会你。到西岭时，狼群蹲在东边低吼，鹰在天上盘旋压低，几头大兽蹲在坡上没动。围成一圈，还没开打。
→ n5

**n3 晚到**
> 你慢悠悠晃到西岭，狼群和鹰已经打成一团，晶石被踢得满坑滚，两头都挂了彩。
→ n6

**n4 独享（发现环节 · 第一个到）**
> 坑里嵌着拳头大的晶石，周围一圈草烫得冒烟。四周静悄悄，只有远处兽吼越来越近。
- 抓起就跑（判定位：速度）
  - 成功：你跑出西岭时，兽群才扑到坑边，扑了个空。完整晶石到手，谁也不知道是你拿的 → n7
  - 失败：你跑慢了，兽群围上来。你扔出两件素材，趁它们抢素材的空当跑了（损失 2 件素材，结束）
- 想看看有没有伴生：你多看了一眼——就这一眼，兽群到了，你被围在坑边 → 转 n5

**n5 对峙（聚集环节 · 四手段）**
> 狼群蹲东边，鹰在天上盘旋，谁都没先动。你挤进前排，几道视线落在你身上。
- 退到石堆后面，等它们打起来再摸进去（判定位：隐匿／敏捷）
  - 成功：狼群先动，鹰俯冲，两头打成一团。你趁乱摸到坑边，拿走晶石，没人注意 → n7
  - 失败：你摸到一半被鹰发现，俯冲下来抓你。你扔素材保命，跑了（损失 1~2 件，结束）
- 直接冲进去抓了就跑（判定位：速度）
  - 成功：你一把抓住晶石——烫得掌心冒烟——转身就跑。兽群反应慢半拍，你扔出一件素材甩掉追兵 → n7（附烫伤）
  - 失败：你被狼群堵住去路。你把晶石扔回去保命，衣兜里还掉了几件素材（损失 1~2 件，结束）
- 等它们两败俱伤再出手（战斗位）
  - 胜利：狼鹰打残了，你站出来收拾残局。两头兽盯着你，没敢上。你拿走晶石，没人拦 → n7
  - 失败：你想捡便宜，被反扑的兽撞翻，滚出老远，素材洒了一地（损失 1~2 件，结束）
- 直接出手，把两边都打服（战斗位）
  - 胜利：你冲进圈子，几招放倒狼群头领，又一道劲风把鹰逼回天上。兽群散了。你拿走晶石，顺带从它们身上捡到几件掉落的素材——参与者也成了你的收获 → n7
  - 失败：你一对二，被狼群和鹰联手围攻。你且战且退，滚出山坳，衣兜里的素材掉了（损失 1~2 件，结束）

**n6 混战（争斗环节 · 三手段）**
> 你到时，狼群和鹰已经打成一团，晶石被踢得满坑滚。两头都挂了彩，谁也没顾上坑。
- 趁乱摸走：你摸到坑边，捡起半块没被踢走的碎晶，温的（碎晶 ×1，结束）
- 等它们打完再捡：狼群和鹰打散了，各自退开。你翻坑，捡到几块溅落的碎晶，还有一撮兽毛（碎晶 ×2＋兽毛，结束）
- 出手收拾残局（战斗位）
  - 胜利：你冲进混战，几招打退两头挂彩的兽。兽群散了，你拿走晶石 → n7
  - 失败：残兽合力把你赶出山坳，衣兜里的素材掉了（损失 1~2 件，结束）

**n7 得手 · 收束**
> 你带着晶石走出山坳。背后没有追兵。走出二里地，你停下来细看：赤红、温热，表面一道天然的纹路，像火留下来的。东西到手了，这一趟没白跑。
- 奖励：坠星晶（完整）｜ 部分路径附「烫伤」

**范例说明**：9 节点、三线介入（发现／聚集／争斗）、五类爽点（闷声发大财／偷／抢／以弱胜强／横扫）、得宝路径统一收束、失败路径各有结算。竞争者为狼群／鹰（本图真实妖兽），无悬念钩子、无额外元素，可重复刷取。
