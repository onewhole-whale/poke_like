## 功能

### F1. 撤退

**要做：**

把格子上现有的「主动撤退（带走已得）」改成【撤退】。仍然只保留这一颗，不另加第二颗。

点【撤退】之后：

- 丢掉本趟冒险已经进背包的素材：把本趟对 `matState` 的增加扣回去。采集、击杀剥取、捕捉失败、安抚、事件链奖励都算。
- 丢掉本趟已经进背包的道具：把本趟对 `toolInv`、`toolDur`、`blueprintInv` 的增加扣回去。
- 战斗经验留在灵兽身上，不扣回。等级、胜场这些已经由 `gainExp` 写上的结果一起留下。
- 退出冒险。人回到地图列表（`S.wild.state==='idle'`，没有格子，没有战斗）。
- 扣完并回到地图列表之后，这个新状态可以写入玩家进度档（见 F2）。

金色出口仍走现在的到达出口结算：本趟材料和道具留在背包，经验也留着。出口结算不要改成丢掉收获。

**不做（边界）：**

- 不在战斗、遭遇、事件链里新加【撤退】。战斗中离开页面走 F2 的关闭规则。
- 不把战败改成丢掉收获。战败仍进现有收获盘点，已经进包的材料和道具还在。
- 撤退不退还本趟花掉的体力，不把灵兽血量或能量改回进冒险前的数。
- 撤退不熄灭已经点亮的图鉴。
- 用户原话只点了材料和道具。本趟活捉进 `S.beasts` 的妖兽、写进 `S.wonderQueue` 的奇遇囊，是否随撤退丢掉，见待确认。在待确认落地之前，这两样保持现在的行为：撤退不从妖兽列表和奇遇囊里删本趟收获。

**确认方法：**

1. 操作者：测试者在已运行的游戏里进入一张冒险地图的格子，采集或打一场并拿到素材，看一眼出战灵兽等级或经验，再点【撤退】。
   - 通过：按钮文案是「撤退」。回到地图列表。本趟新进背包的素材数量没了，本趟新进的工具或蓝图数量没了。灵兽经验仍是战斗后的数。格子和战斗画面都不在。
   - 失败：按钮仍是「主动撤退（带走已得）」；或回到地图列表后素材还在；或经验被扣回进冒险之前；或仍停在格子、战斗、收获盘点。
2. 操作者：测试者走到金色出口并看结算。
   - 通过：本趟材料和道具仍在背包，经验仍在。出口没有变成丢掉收获。
   - 失败：出口结算把本趟素材或道具扣没了。

### F2. 存档

**要做：**

补上玩家进度存档。刷新之后还在的进度至少包括：灵兽（含经验、等级、技能、胜负）、妖兽、萌芽、灵息、体力与体力时间戳、手札 `S.logs`、内置素材持有 `matState`、炉膛、奇遇囊、修炼槽与修炼记录。图鉴编辑、点亮、精魄、缘分、工具、蓝图继续能读回。可以仍写在 `localStorage`；允许和现有键 `refine-proto-codex` 放在一起，也允许另开键。刷新后不得再变成「只有开局那只新的烬烬狼、素材持有全 0」。

两种离开分开写，不能混：

- 点「进入冒险」的那一下之前写玩家进度档。档里的野外是地图列表：`state` 为 `idle`，没有格子，没有战斗。人还在地图详情上时，档里也不要记下「已经生成的格子」。
- 从这一下开始，直到离开冒险，禁止再写玩家进度。正在战斗、遭遇、事件链、格子上游走、收获盘点还没离开，都算还在冒险里。
- 按【撤退】是离开冒险：材料和道具已经丢掉，战斗经验留在灵兽身上，人在地图列表。这个新状态写入档。之后在冒险外关掉页面，下次读到的是撤退之后的档：经验在，本趟素材和道具不在。
- 冒险中途关掉页面或直接退出：没有冒险中的档。下次读到的是进入冒险之前的那一档，画面是地图列表这一层（野外地图列表，或灵兽仓 `#/stable`）。这一趟里的经验不在那一档里，素材和道具也不在。这是读到了旧档，不是撤退时把经验扣回。
- 金色出口的收获留在内存里的背包。人还停在收获盘点时，仍算没有离开，不写玩家进度档。点「返回营地」或「再探荒野」之后人在冒险外（灵兽仓或地图列表），这时写入档，收获和经验都在档里。
- 人在冒险外时，玩家进度发生变化就写入，这样不进冒险也会在刷新后留住灵兽和素材。
- 冒险进行中已经存在的 `saveDraft`（例如驻扎结束）不得把本趟灵兽、经验、素材持有、道具数量、体力、灵息、手札、野外格子写进可读的玩家进度。工具和蓝图现在写在 `saveDraft` 的同一个对象里，冒险中的写入要保持进入前的道具数量。

退出冒险后的画面是进入冒险之前的那一层：地图列表。收获盘点上的「返回营地」仍可去灵兽仓。这两处都是冒险外。不要停在格子中间或战斗中间。

**不做（边界）：**

- 不新增一颗单独的「存档」按钮。能存、不能存指的是上面的写入时机。
- 不把战斗中的画面、格子坐标、遭遇卡、事件链写进档。
- 不在冒险中把本趟经验写成新档来「保住经验」。关掉页面就要回到进入前。
- 战败后若还停在收获盘点，与出口盘点一样，算还没离开，不写新档。点离开、人到了地图列表或灵兽仓之后再写，已进包的收获保留。

**确认方法：**

1. 操作者：测试者在冒险外让一只灵兽获得经验或让背包多出一份素材，刷新页面。
   - 通过：刷新后这只灵兽的经验和这份素材还在，不再变成一只新的、经验为 0 的开局烬烬狼。
   - 失败：刷新后灵兽或素材回到开局空进度。
2. 操作者：测试者打开地图列表，进入地图详情，点「进入冒险」，在格子里打赢一场并看到经验增加，然后关闭页面再打开。
   - 通过：打开后是地图列表或灵兽仓，不是格子，不是战斗。这趟增加的经验和素材都不在。出战灵兽的经验与点「进入冒险」之前一致。
   - 失败：打开后仍在格子或战斗；或这趟经验留在了档里。
3. 操作者：测试者在格子里拿到素材并打赢一场，点【撤退】，看到地图列表后关闭页面再打开。
   - 通过：经验仍是战后的数，本趟素材不在背包，画面在地图列表或灵兽仓。
   - 失败：经验回到进冒险前；或素材还在；或打开后在格子里。
4. 操作者：测试者走金色出口，在收获盘点上直接关闭页面再打开；另一次走金色出口后点「返回营地」或「再探荒野」，再关闭页面并打开。
   - 通过：停在盘点时关掉，下次是进入前的档（这趟收获和经验都不在）。点了离开再关掉，下次收获和经验都在，画面在地图列表或灵兽仓。
   - 失败：盘点上关掉却保住了这趟进度；或点了离开再关掉却把出口收获扣掉了。

### F3. 演示模式

**要做：**

演示模式当作测试模式来用，让炼化、野外、战斗能顺着走通。本次只补代码里已经对得上的缺口。

- 启动后按钮亮起和 `S.demo` 一致。默认 `demo:false`，所以亮「真实」，不亮「演示」。点「演示」才把 `S.demo` 设为 `true` 并亮「演示」。点「真实」则相反。
- 切换提示和炼化预览里的概率，与代码里已经存在的分支一致：真实为定向出灵约 1%、异色约 5%；演示为定向出灵约 28%、异色约 18%。提示里不再写代码中不存在的「高阶约 3%」。不改这些百分比、不改缘分上限 60/120、不改修炼 15 秒 / 900000 毫秒、不改捕捉异色 15% / 3%。
- 还没有玩家进度档时，点「演示」发放一次测试资源，并且只发放一次：
  - 普通斧 `DJ_none_002000` 一把、普通镐 `DJ_none_002006` 一把（号段见 `src/sim/skills.js`：六档斧占 `002000`–`002005`，下一号是普通镐）。
  - 一组现有素材，投入炉中后能命中规则「烬烬狼 · 爪牙之炉」（`src/sim/refine.js`：火 ≥15、爪 ≥4、至少一份精良）。用现有素材 id 凑齐，不新造素材，不改这条规则的门槛数字。
- 已经有玩家进度档时，再点「演示」或「真实」只切换概率，不增发、不扣回持有数量。
- 真实模式的新开局保持现在的持有：素材为 0，工具背包为空，不发上面这套测试资源。

野外和战斗的入口已经有：开局烬烬狼可以进冒险，遭遇可以点「正面 · 战斗」。本次不另做「跳过到战斗」的入口。

**不做（边界）：**

- 不改玩法数值：技能代价、能量上限 10、体力上限 120、体力每 6 分钟恢复 1，都不因演示模式而改。
- 不把战斗背包「功能筹备中」做成能用。该页不读 `S.demo`，不是演示模式的空洞。
- 不改图鉴编辑品质下拉里「中阶 · 可出灵兽」「高阶 · 高概率与稀有候选」那句说明（`src/view/codex-forms.js`）。
- 安抚 40% / 60%、突袭 22%、捕捉成功 60%、空手 50% 是否要跟着演示模式提高，见待确认。本次不改这些数。有了斧和镐之后，采集走现有的「有工具则出货」分支，品质锁仍按工具等级把超出的品质压成普通。

**确认方法：**

1. 操作者：测试者重新打开页面，先不点概率按钮。
   - 通过：「真实」亮起，「演示」不亮。此时若预览里能看到出灵概率，按约 1%，不按 28%。
   - 失败：一打开就是「演示」亮着，而出灵仍按 1%；或「真实」亮着而出灵按 28%。
2. 操作者：测试者点「演示」，再点「真实」，看提示和炼化预览。
   - 通过：演示提示能对上约 28% 和约 18%；真实提示能对上约 1% 和约 5%。两句提示里都没有「高阶约 3%」。
   - 失败：提示仍是「中阶约 1%，高阶约 3%」，或提示的百分比和预览不一致。
3. 操作者：测试者清掉玩家进度档后打开游戏，点「演示」，不进入野外，把新出现的素材投入炼化炉。
   - 通过：预览出现可出灵兽，出灵概率约 28%，并含烬烬狼这一候选。背包里有普通斧和普通镐各至少 1。
   - 失败：点了演示仍然没有任何素材，预览仍是未命中定向配方；或没有斧、镐。
4. 操作者：测试者在演示模式的新开局里进入野外，在已探索且有植物或矿物的当前格点采集。
   - 通过：不出现「空手采集一无所获（50% 出货率）」。
   - 失败：背包里已有对应工具，采集仍提示空手 50%。
5. 操作者：测试者在已有玩家进度档时来回点「演示」「真实」。
   - 通过：持有的素材数量和工具数量不变，只有概率分支切换。
   - 失败：每次点「演示」都再发一套素材或工具。

## 待确认

1. 撤退是否同时丢掉本趟活捉的妖兽，以及本趟推进 `S.wonderQueue` 的奇遇囊。用户原话是丢掉材料和道具，经验不收回。代码里妖兽在 `S.beasts`，奇遇囊不是 `matState` 道具。落地前按 F1 边界：这两样不删。
2. 演示开关要不要写入玩家进度档。不写入则每次打开默认真实、按钮亮真实；已经发过的测试资源留在进度档里。
3. 演示开局要不要连生命精华、蓝图一起发。锻造分支需要它们（`src/view/refine-play.js`），定向出灵的「爪牙之炉」不依赖锻造。本次不把锻造材料写成已经定了。
4. 安抚成功率（正面 40%、悄悄 60%）、非首领突袭 22%、捕捉成功 60% 要不要在演示模式里提高。它们都不读 `S.demo`。战斗可以用「正面 · 战斗」走进去，所以本次不改这些数。

## 红线

后续开发不得改掉下面这些边界：

- 不改玩法数值。技能代价、能量上限 10、体力上限 120 不动。演示模式也不改体力每 6 分钟恢复 1。
- 不做 M3-3 立绘，不做全画。属性 emoji 占位保持现状。
- 不改出生文案「炉火中一声清鸣，一头灵兽在壶中成形。灵兽资质圆满、性格自选，是真正的伙伴。」不改来源文案「先天资质圆满」。
