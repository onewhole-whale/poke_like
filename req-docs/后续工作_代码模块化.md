## 现在的目录

游戏在仓库根目录，不再包在日期材料文件夹里。

| 路径 | 只放什么 |
|---|---|
| `index.html` | 页面骨架，按 `src/modules.txt` 引用脚本 |
| `css/app.css` | 样式 |
| `data/*.js` | 物种、素材、技能、地形、事件、地图 |
| `src/sim/` | 规则：属性、面板、炼化、进化、沙盒、伤害、状态、回合。不读写 DOM |
| `src/view/` | 浏览器画面：格子、战斗演出、图鉴、弹层 |
| `src/app/boot.js` | 绑定按钮、`init()`、`route()` |
| `src/modules.txt` | 页面、`tests/_load.js`、`acceptance/probe.js` 共用的加载顺序 |

`src/sim` 可以调用 `toast` 和 `render*`。这两类名字是画面钩子。迁到 Python 或 Unity 时，带走 `data/` 和 `src/sim/`，把钩子换成那边的通知，`src/view/` 留在浏览器。

语句顺序和拆开前的那一段脚本相同，所以数值和演出没有一起改。
