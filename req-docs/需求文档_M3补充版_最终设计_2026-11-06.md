## 本版交付（已实现）

### 主页与五槽存读
- 行为：启动必进主页；「体验开局 / 正式开局」只开内存局不写槽；「存档 / 读档」选 1–5 槽；图鉴编辑数据本机公用。  
- 边界：无云存档；冒险中禁存禁读。  
- 入口：顶栏菜单（开局后）。

### 战斗血蓝瓶
- 行为：血瓶回最大生命 25%；蓝瓶能量回满；占一回合；战斗包只显示药剂；可炼化获得。  
- id：`DJ_none_002020` / `DJ_none_002021`。

### 野外补洞
- extraDrops 精英/首领掉入 `toolInv`；灵息换斧按钮；冒险中 `beforeunload` 提示。

### 演出速度与自动战斗
- 演出速度（1× / 2× / 跳过演出）只在**设置**里改；战斗界面不放倍速钮。  
- 「跳过」只跳过演出，不跳过战斗。  
- 战斗「自」：按设置自动选招；可自动血瓶（&lt;50%）、蓝瓶（放不出最大期望伤害技时）；回能策略三选一（无攻击技 / 能量为 0 / 最大期望技不可用）。

### 菜单
- 存档、读档、设置、手册、图鉴编辑、返回主页面。

### 配置健壮性（本版捎带）
- 地图假物种 id（如已删的 `JL_grass_*`）已改真实物种；`wildBeast` 无效 id 整只回退；`tests/config_species_accept_test.js` 守门。
