一句话：炼妖壶在 M3-2 封板与立绘入库之后，把**已上线流程里仍悬空或会坑玩家的缺口**收进一个「M3 补充版」；不碰新手关卡/音频/场地美术，也不抢「自动战斗」「迁 Unity」两条已单独准备的轨。

> 版本：范围草案 | 日期：2026-11-06 | 状态：梳理稿（先定进出版本，再拆功能需求）  
> 需求目录：`req-docs/`  
> 排除（本版不做）：新手教程关卡、音频、场地/场景美术  
> 旁轨（本版不做，另开）：自动战斗、迁移 Unity  
> 冰箱（不进本版）：`灵感记事本.md` 全部条目

### A10. 主页面 + 多槽本机存档（存读独立）— **已定**

| | |
|---|---|
| 现状 | 启动直进炼化；单一 `localStorage` 键 `refine-proto-play`；顶栏存/读立刻写读这一份；无主页 |
| 心智（已定） | **开新局与存档无关**。内存里开一局玩；只有点「存档」时才选槽写入；只有点「读档」时才选槽读入。存档是独立功能，不在「开始」时决定写哪。 |
| 要做 | ① **主页面**：每次打开网页**总是先到主页面**。品牌 + **开始游戏**（进入/新开内存局，**不删、不写任何槽**）+ **读档**（选槽）+ 说明「进度靠存档保留在本机」。② **多槽固定 5 个**；每槽可空，有档时显示摘要（如时间、灵兽数）。③ **存档**：弹层选 1～5 槽 → 写入**当前内存玩法进度**（覆盖前确认）。④ **读档**：弹层选槽 → 读入内存并进主循环（可提示将丢弃未存内存）。⑤ 冒险中仍禁存禁读。洗髓露等玩法字段随槽存。⑥ **图鉴编辑 / `refine-proto-codex` 本机公用一份**（改的是底层数据，不跟槽走）；玩法槽只存玩家进度（灵兽、素材持有、体力等）。 |
| 边界 | 不做账号/云；开始时不选槽、不清槽；codex 不分槽。 |
| 确认 | 开网页必见主页；开始后不存→刷新丢本局、五槽旧档仍在；存槽 3→读槽 3 恢复；覆盖有确认；编辑图鉴对各槽开的局同样生效 |
