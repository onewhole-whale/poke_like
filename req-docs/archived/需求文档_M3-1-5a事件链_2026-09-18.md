# M3-1-5a 事件链 · 需求文档

- **版本**：v1.0（2026-09-18；本窗口从事件链机制讨论 → 《赤光坠地》文案转配置 → 判定动态化 → loseMats 玩家选择，全部拍板后落盘）
- **前置**：M3-1-4（工具/地形表/事件表基类/沙盒生成，v1.17.0 已落地）
- **范围**：① 事件条目升级为**事件链**（choice/check/end 节点引擎）；② 条件系统四类（亲和力/消耗素材/属性/stat 动态判定）；③ 效果系统（含 loseMats 玩家选择）；④ 战斗分支（车轮战）；⑤ 挑战等级（地图层新字段 + 敌方创建改造）；⑥ 沙盒事件生成规则（事件条目池 + 密度小数 + 奇遇一次性过滤）；⑦ 事件链 UI（群星式弹窗）；⑧ 《赤光坠地》冒险事件内容；⑨ WONDERS 4 条迁移。
- **不在本版**：技能池扩充（拆为 M3-1-5b，后续单独开）；信物物品设计（预留字段）；其余 4 个冒险事件故事（等产品总监提供文件后填充）。

## 1. 需求背景与目标

M3-1-4 立起了事件表三层体系（基类 → 派生 → 实例化），但 adventure 条目为空、wonder 是线性文本。本版把事件从"占位"升级为**事件链**（参考群星事件系统 / 文字冒险游戏）：起点事件 → 按选择与玩家能力走不同分支 → 不同结局与收获。

**核心目标**：
- 用《赤光坠地》一个完整事件跑通事件链全流程（判定 / 战斗 / 选择 / 损失 / 奖励）；
- 奇遇事件升级为一次性传奇故事（地图级 once 状态，触发即消耗）；
- 事件判定与敌人强度跟随地图挑战等级动态化，同一事件可被不同地图复用。

**服务设计哲学**：冒险事件可重复但奖励温和（素材/局内状态为主），永久大奖励留给一次性奇遇——防批量刷取。

## 2. 需求详情

### 2.1 事件条目结构（事件表基类）

事件条目 = `{ id, kind, name, once, entry, nodes }`

- `kind`：`'adventure'`（冒险，可重复）/ `'wonder'`（奇遇，一次性）
- `once`：`true`（一次性）/ `false`（可重复）
- `entry`：起始节点 id
- `nodes`：节点字典，三种节点类型：

| 节点 | 结构 | 行为 |
|---|---|---|
| **choice** | `{kind:'choice', text, choices:[{label, cond?, battle?, rewards?, effects?, next?\|end}]}` | 展示文本 + 选项按钮，玩家选择后执行 |
| **check** | `{kind:'check', text, check:{stat,race,iv,lvlRef}, success, fail, failEffects?}` | 进入即自动判定，成功走 success / 失败走 fail（玩家无选择） |
| **end** | `{kind:'end', text, rewards?, effects?}` | 收束节点：结算奖励/效果后关闭弹窗 |

- **插图位**：每个节点预留 `img: null` 字段，本版占位不显示（后续文案/美术填充）。

**选项字段说明**：
- `cond`：可选条件（见 §2.2），不满足时选项**置灰不可点（仍显示）**
- `battle`：战斗引用 key（见 §2.4），带 battle 的选项走战斗流程
- `rewards` / `effects`：选项执行时的直接奖励/效果
- `next`：下一节点 id；`end` 为字面量表示事件结束（结束时的奖励/效果在目标 end 节点或选项自身配置）
- **内嵌 check**：选项可带 `check`（点击后判定），`success` / `fail` 各自带去向与效果（如《赤光坠地》n4「抓起就跑」）

### 2.2 条件系统（cond，四类）

| 类型 | 结构 | 语义 |
|---|---|---|
| 亲和力 | `{aff:{elem, gte}}` | 元素亲和力 ≥ 阈值 |
| 消耗素材 | `{mats:[{id, qty}]}` | 背包持有该素材且数量达标（达标才可选；执行时扣除） |
| 属性判定 | `{elem:'fire'}` | 当前出战精灵元素属性匹配 |
| **stat 判定** | `{stat, race, iv, lvlRef}` | 面板达标/不达标（见下） |

**stat 判定动态化（关键设计）**：
- `race` / `iv`：**配置在事件表**（事件定义"这条线的参考种族值/个体值"）
- `lvlRef`：**读派生事件表**的挑战等级——`'max'` = 区间上限，`'mid'` = 区间中位向下取整 `⌊(min+max)/2⌋`
- 面板计算走 `spiritStats` 公式：`spe = floor(2×race×lvl/100) + 5 + round(iv×2×lvl/100)`（其他五维同理）
- 判定基准：**当前出战精灵**的对应 stat 面板
- 效果：同一事件在不同挑战等级的地图自动缩放判定难度，无需重配

### 2.3 效果系统（effect）

| 类型 | 结构 | 语义 |
|---|---|---|
| 给素材 | `{type:'reward', items:[{id, qty}]}` | 入背包（matState） |
| 局内状态 | `{type:'status', status:'烫伤'}` | 本次冒险内持续；**烫伤复用灼伤状态**，不新增状态 |
| 体力代价 | `{type:'stamina', cost:n}` | 扣除体力 |
| 触发战斗 | `{type:'battle', key}` | 走战斗分支（见 §2.4） |
| 损失素材 | `{type:'loseMats', qty:n\|'a~b'}` | 玩家选择后扣除（见 §2.6） |
| 跳节点/结束 | `{type:'goto', node}` / `end` | 流程控制 |
| 信物 | 预留字段 | 本版不设计信物物品，字段保留待后续 |

### 2.4 战斗分支（车轮战）

- 选项 `battle` 字段 = **参数 key 引用**（事件表不写敌人），如 `"battle": "fight_beat"`
- 具体敌人配置在**派生事件表**：`MAP_CONFIGS[map].eventConfig.eventParams[事件id]`：
  ```
  { "fight_weak":  { "enemies": [ { "speciesId": "JL_fire_normal_0001",  "template": "normal" } ] },
    "fight_clean": { "enemies": [ { "speciesId": "JL_fire_normal_0001",  "template": "normal" },
                                   { "speciesId": "JL_thunder_normal_0038", "template": "normal" } ] },
    "fight_beat":  { "enemies": [ { "speciesId": "JL_fire_elite_0007",  "template": "elite" },
                                   { "speciesId": "JL_wind_normal_0041", "template": "elite" } ] } }
  ```
- **车轮战**：`enemies` 数组 = 顺序连战（战斗机制不支持群战）；**全胜 = onWin 分支，中途败 = onLose 分支**；胜负不绑定事件结束（由配置决定去向）
- 车轮战之间**不自动恢复**（玩家可换精灵，保持连战压力）
- **默认无掉落**：事件战斗不走妖兽掉落表；胜利分支显式配置 `rewards` 才有素材奖励
- 敌人创建：`wildBeast(speciesId)` + `applyTemplate`（精英 血×3 攻防×1.5 / 首领 血×4 攻防×2，速度不乘）；**等级按地图挑战等级**（§2.5）

### 2.5 挑战等级（地图层新字段）

- `MAP_CONFIGS[map].challengeLvl: [min, max]`
- **微风平原 = `[1, 15]`**（新手图）
- 敌方创建等级规则：
  - 普通模版 = `rand[min, max]`
  - 精英模版 = `rand[⌈(min+max)/2⌉, max]`（区间减半、下限上升）
  - 首领模版 = `max`（上限）
- **改造现有 `wildBeast`**：等级不再按物种稀有度固定（1/3/5/6），改为按地图挑战等级 + 模版规则（调用方传入 challengeLvl 与 template 确定等级）
- 应用范围：本图所有敌方创建（战斗事件、事件链战斗分支、后续野生）

### 2.6 loseMats（玩家选择，方案 B）

- 触发：fail 分支 / 选项失败路径带 `{type:'loseMats', qty}`
- `qty`：数字（固定损失数）或 `'a~b'`（**先随机 roll a~b 决定损失数量**，玩家只选择"哪几件"，不选数量）
- **交互流程**（方案 B，玩家自选，避免系统自动扣的厌恶感）：
  1. 事件链弹窗切换到「损失素材」面板
  2. 列出背包全部素材（`matState[id] > 0`），行显示：品质色标 + 名称 + 持有数，可多选
  3. 选满 qty 件后【确认损失】按钮亮起；点击 → 扣减 `matState` → 关闭弹窗，事件结束
- **边界**：
  - 背包素材总数 < qty → 允许全选扣光（不足也确认，不追罚）
  - 背包无素材 → 跳过选择直接结束
  - 只扣素材（matState 的 SC_ 素材）；工具（toolInv）/ 蓝图（blueprintInv）/ 技能石·专长石（ITEMS DJ_）不在 matState，数据结构天然隔离，不写额外过滤

### 2.7 事件生成规则（沙盒阶段 C 升级）

- **冒险事件**：从地图连接的冒险事件条目池随机选条目 → 生成 `{kind:'adventure', eventId, chain:{nodeId, ...}}` 事件块
- **奇遇事件**：从地图连接的奇遇条目池（**过滤 once 已触发**）随机选；条目池空 → **不生成奇遇地块**
- **密度语义升级**（配置值 = 期望数量）：
  - `< 1`：概率判定（`0.6` = 60% 生成 1 个 / 40% 不生成）
  - `≥ 1`：`floor(N)` 必定生成 + 小数部分概率补 1（期望值语义）
  - 确认生成后，才从「已连接 + 允许生成」的条目池随机选具体条目
- **微风平原密度不改**：冒险×2 / 奇遇×2（数值不变，仅密度语义升级）

### 2.8 奇遇一次性（地图级状态）

- 存档记录**每个地图**已触发的奇遇事件（`S.wonderOnce[mapId] = {eventId: true}`）
- **触发即消耗**：进入事件弹窗那一刻标记 once（不管中途放弃/失败/收获）
- 同图重开沙盒：已完成奇遇不再生成；全部完成 → 该图沙盒不再生成奇遇地块
- **地图间隔离**：A 图触发的奇遇不影响 B 图生成
- 冒险事件不受影响（once=false，可重复）

### 2.9 事件链 UI（群星式弹窗）

- 触发事件 → 弹出事件链弹窗：
  - 上方：节点文本 + 插图位（本版无图，留空）
  - 下方：选项按钮（竖排）；`cond` 不满足的选项**置灰不可点**（仍显示）
- check 节点：进入自动判定，展示判定反馈（如"翻山成功/失败"）后走对应分支
- end 节点：显示奖励结算摘要 + 关闭按钮
- 战斗分支：从弹窗进入战斗流程，战斗结束按 onWin/onLose 回到事件链对应节点
- loseMats：弹窗内嵌「损失素材」选择面板（§2.6）

### 2.10 《赤光坠地》（adv_starfall，冒险事件条目）

**结构**（文案全文落库，不做省略/截断）：

| 节点 | 类型 | 内容 |
|---|---|---|
| n0 | choice | 触发文案；3 选项：抄近路翻山→n1 / 混进兽道→n2 / 等消停→n3 |
| n1 | check | 翻山判定（高线）成功→n4，失败→n2 |
| n2 | choice | 兽道过渡→n5 |
| n3 | choice | 晚到过渡→n6 |
| n4 | choice | 独享：抓起就跑（内嵌 check 高线，成功→n7 / 失败 loseMats 2 件结束）；看伴生→n5 |
| n5 | choice | 对峙 4 手段：隐匿（check 低线，成→n7 / 败 loseMats 1~2）；突袭（check 低线，成→n7+烫伤 / 败 loseMats 1~2）；等残局（战斗 fight_weak，胜→n7 / 败 loseMats 1~2）；打服（战斗 fight_beat，胜→n7+素材奖励 / 败 loseMats 1~2） |
| n6 | choice | 混战 3 手段：趁乱摸走→碎晶×1 结束；等捡→碎晶×2+兽毛×1 结束；收拾残局（战斗 fight_clean，胜→n7 / 败 loseMats 1~2） |
| n7 | end | 得手：坠星晶×1 |

**判定配置**：
- 高线（n1 翻山 / n4 抢跑）：`{stat:'spe', race:100, iv:10, lvlRef:'max'}`
- 低线（n5 隐匿 / n5 突袭）：`{stat:'spe', race:100, iv:0, lvlRef:'mid'}`
- 微风平原实例值：高线 = 15 级面板（30+5+3）= **38**；低线 = 8 级面板（16+5）= **21**

**战斗派生**（微风平原 eventParams，见 §2.4）：
- fight_weak：烬烬狼 `JL_fire_normal_0001` ×1 normal
- fight_clean：烬烬狼 + 轰枭 `JL_thunder_normal_0038` ×2 normal
- fight_beat：狼嚎客 `JL_fire_elite_0007` + 嗖隼 `JL_wind_normal_0041` ×2 elite

**奖励素材**（id 占位，随素材表落库）：
- 坠星晶（完整）：火 · 稀有 `SC_fire_rare_000xxx` ×1（n7）
- 坠星碎晶：火 · 普通 `SC_fire_normal_000xxx`（n6 摸走×1 / 等捡×2）
- 兽毛：普通系 · 普通 `SC_none_normal_000xxx` ×1（n6 等捡）
- n5 打服胜利：显式配置妖兽素材×1~2（奖励列表占位，内容填充时定具体 id）

**失败损失**：n4 抢跑失败固定 2 件；n5/n6 各失败路径随机 1~2 件（均玩家自选，§2.6）

**烫伤**：n5 突袭成功路径附加局内状态「烫伤」（复用灼伤，本次冒险内持续）

### 2.11 WONDERS 4 条迁移

- 现有 wonder_fire / wonder_water / wonder_thunder / wonder_light 4 条**迁移到事件链结构**（`kind:'wonder'`, `once:true`），内容占位保留现有故事文本
- **一套代码**：新事件链渲染统一处理所有事件条目，**不写任何兼容分支**（更新不是兼容）

## 4. 验收标准（可观测 · 可断言）

1. **冒险入口**：进入微风平原，沙盒生成 2 个冒险事件地块、2 个奇遇地块；冒险事件地块均为《赤光坠地》
2. **事件链触发**：走到冒险事件地块 → 弹出事件链弹窗（n0 文案 + 3 个选项按钮）
3. **check 判定**：选「抄近路翻山」→ n1 自动判定；出战精灵 spe ≥ 38（微风平原高线）→ 进 n4，< 38 → 进 n2
4. **战斗分支**：n5「打服」→ 车轮战 2 只（狼嚎客精英 + 嗖隼精英，等级 8~15 区间）；全胜 → n7，中途败 → 弹出「损失素材」面板
5. **loseMats（方案 B）**：损失面板列出背包素材；随机决定损失数量（1~2）后玩家多选对应件数；选满后【确认损失】亮起；确认后 matState 相应扣减；素材不足可全选扣光；背包为空直接跳过
6. **敌人等级**：微风平原战斗敌人 普通=1~15 / 精英=8~15 / 首领=15（按 challengeLvl 生成，不再按稀有度 1/3/5/6）
7. **奇遇一次性**：触发奇遇弹窗即标记 once（存档）；同图重开沙盒该奇遇不再出现；4 条全触发 → 该图沙盒无奇遇地块；换地图奇遇照常生成
8. **密度语义**：冒险/奇遇配置 2 → 每局各生成 2 个事件地块（整数部分必定 + 小数概率）
9. **奖励结算**：n7 结束奖励坠星晶×1 入背包；n6 摸走奖励碎晶×1；n5 突袭成功附加烫伤（灼伤状态）
10. **WONDERS 迁移**：4 条奇遇用新事件链弹窗渲染，无旧渲染兼容分支

## 5. 待拍板 / 开放问题

- ✅ 本版无待拍板项（冒险事件池暂以《赤光坠地》1 条跑通机制；其余 4 条等产品总监故事文件，落地后按补丁/后续版本填充）
- ⚠️ 开发者遇到未覆盖边界：事件链内选项 cond 不满足一律置灰显示；loseMats 数量随机与选择按 §2.6；不得自行新增条件/效果类型
