## 专属素材规则（2026-09-17 拍板，已落实为落库口径）

1. **每只精灵 5 条专属 = 2:2:1**（平级×2 / 高一档×2 / 高二档×1），品质档随精灵品级：
   - 普通精灵：普通×2 / 优秀×2 / 精良×1
   - 精英精灵：优秀×2 / 精良×2 / 稀有×1
   - 完美精灵：精良×2 / 稀有×2 / 史诗×1
   - 传说精灵：稀有×2 / 史诗×2 / 传奇×1
2. **命名格式**：「属性 + 种族 + 完整词汇部件」（如 火狼獠牙、冰狼霜屑）。**部件用完整词汇**（瓜皮/藤须/灯芯 等，不限单字，用户拍板 2026-09-17）；最终名字由文案 agent 润色，本表为粗稿。
2.1 **种族 = 有辨识度的设计原型**（狼/龟/雀/南瓜/稻草人/巫师/木乃伊/亡灵/鹰/蛇 等，用户拍板 2026-09-17）：种族词取玩家一眼能识别出物种/意象的原型名，**不与精灵名重复不作为回避理由**。
2.2 **种族词合并口径（2026-09-17 拍板）**：骸骨族统一「亡灵」（骨/骸并入）；蛇族统一「蛇」（蟒并入，蛟保留）；猛禽族统一「鹰」（隼/雕并入，枭因猫头鹰辨识度独立保留）；**传说精灵种族直接用精灵名**（混沌兽/血月侯/南瓜王），不另定种族名。
3. **品质×设计原型矩阵**：普通=边角料（**禁用 心/魂/核/印/冠**）、优秀=完整部件、精良=核心器官、稀有=灵性精华、史诗=至宝、传奇=唯一至宝。
4. **部件选择依据**：精灵的 简述 / 生态 / 外形 三字段（第 7 章定稿）；同家族内部件零重复（同族同属性靠部件区分）。
5. **设计原因**：一句话，引用三字段核心证据。

## 1. 素材落库配置（定稿）

### 1.1 定稿来源与口径

- **名称 / 品质 / 设计原型唯一事实源**：`content-docs/文案文档_素材全设定_2026-09-17.md`（545 条七字段定稿）。本需求文档不再复制文案全文（减少干扰），生态 / 外观 / 设计理由字段以文案文档为准，开发如需 desc 之外的文案内容直接读文案文档。
- **落库字段**：`id`（编码=唯一种类识别符，规则见 §21）/ `name`（文案定稿名）/ `elem`（精灵属性）/ `quality`（素材品质）/ `type: 'beast'`（beastMatIds 按此收集）/ `count`（默认 0）/ `tags`（词条，进 REFINE 匹配）/ `desc`（设计原型一句话，tip 渲染用）。
- **编码号段（全局顺序递增）**：`SC_none_fine_000001` 生命精华（机制保留）+ `SC_none_*_000002~000013` M3-1-4 测试素材预留（v1.16.5 已登记）→ **本条专属素材承接 000014 起**，按文案文档顺序顺序递增至 `000558`（与精灵家族无关，纯顺序编码），共 545 条，数字段全局唯一。
- **tags 定稿口径**：实体部位词优先（爪/牙/绒/羽/翼/鳞/角/甲/骨/魂/冠 等）；鬼族"灵"前缀剥离；元素/颜色词不入 tags（元素由 elem 自动计，避免双计）；普通/优秀档不含 心/魂/核/印/冠 高品词；南瓜族用「南瓜」词条、蚀时之蛇用「时空」词条、混沌兽用「混沌」词条、血月侯用「血」词条、木乃伊用「纱」词条（对齐定向配方）。配方 23 个实体词条已全覆盖校验（含 嗞嗞猫「须」= 黑亮毛、蛇「涎」= 半炷香 两处补配）。

## 21. id 编码规则与全量对照表（M3-1-3 补丁 · 2026-09-17 用户拍板）

### 21.1 编码规则（唯一种类识别符）

- 精灵：`JL_m_xx_nnnn`（JL 前缀 + m=属性 + xx=品质 + **4 位数字**，顺序递增 0001 起，不按家族分段）
- 素材：`SC_m_xx_nnnnnn`（SC 前缀 + m=属性 + xx=品质 + **6 位数字**，顺序递增 000001 起）
- m 位取值：fire / ice / thunder / wind / water / earth / light / dark / poison / ghost；**无属性统一 none（普通系）**，不预留特殊系位
- xx 位取值：精灵 = normal / elite / perfect / legend；素材 = normal / good / fine / rare / epic / legend
- 编码 = 精灵/素材的**唯一种类识别符**，与显示名（中文名）解耦；显示名润色/改名不影响编码
- 旧语义 id 全部替换，旧 id 引用全部清空；素材表旧 13 条采集素材已清，仅生命精华（机制保留）重编码
