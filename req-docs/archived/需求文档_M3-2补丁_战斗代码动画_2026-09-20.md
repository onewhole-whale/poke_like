# 需求文档 M3-2 补丁 · 战斗代码动画

> 版本：v1.0 | 日期：2026-09-20 | 性质：M3-2 补丁

---

## 一、需求背景

M3-2 战斗 UI 布局已完成（顶部血条、中间场地、左右展示板、功能栏），但战斗动画还没做——现在是静态展示，没有打击感。本补丁用纯代码动画实现最低限度的战斗演出，不需要美术资源。

---

## 二、动画设计

### 2.1 攻击动画

| 项目 | 说明 |
|---|---|
| 触发时机 | 技能命中时 |
| 效果 | 攻击方精灵往对方方向冲一下（位移 0.3s），然后回到原位 |
| 实现 | CSS transform 位移动画 |

### 2.2 受击动画

| 项目 | 说明 |
|---|---|
| 触发时机 | 被攻击时 |
| 效果 | 受击方精灵闪红 + 左右震动 0.2s |
| 实现 | CSS 红色滤镜 + 位移抖动动画 |

### 2.3 伤害数字飘字

| 项目 | 说明 |
|---|---|
| 触发时机 | 伤害结算后 |
| 效果 | 伤害数字从受击精灵位置向上飘，0.8s 后消失 |
| 暴击 | 数字放大 + 红色 + 震动 |
| 治疗 | 绿色数字 |

### 2.4 技能粒子特效

按技能属性在战斗场地生成粒子效果：

| 属性 | 粒子效果 |
|---|---|
| 火 | 红色粒子从技能位置向外扩散 |
| 水 | 蓝色水滴下落 |
| 草 | 绿色叶片飘动 |
| 雷 | 黄色闪电线条闪烁 |
| 冰 | 白色雪花飘落 |
| 暗 | 紫色烟雾扩散 |
| 其他 | 对应颜色的基础粒子 |

实现：Canvas 粒子系统，10~20 个粒子，0.5~1s 后消失。

### 2.5 状态图标动画

| 状态 | 动画 |
|---|---|
| 获得新状态 | 图标弹出动画（缩放 0→1.2→1） |
| 状态消失 | 图标缩小消失 |

---

## 三、验收标准

1. 攻击时攻击方精灵往前冲一下，然后回到原位。
2. 受击时受击方精灵闪红 + 左右震动。
3. 伤害数字飘在战斗场地中，从下往上飘，0.8s 消失；暴击放大+红色。
4. 治疗数字绿色。
5. 释放技能时按属性生成对应颜色的粒子效果。
6. 获得新状态时状态图标有弹出动画。
7. 所有动画总时长不超过 1.5s，不拖沓。
