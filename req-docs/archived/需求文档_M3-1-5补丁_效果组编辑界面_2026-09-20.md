# 需求文档 M3-1-5 补丁 · 效果组编辑界面

> 版本：v1.0 | 日期：2026-09-20 | 性质：5 补丁（承接效果组通用化）

---

## 一、需求背景

效果组（effectGroup）数据结构已落地，但编辑界面只读展示，无法编辑概率、子效果、分支增删。需要针对效果组模式做专属编辑界面。

---

## 二、需求详情

### 2.1 效果组卡片结构

效果组在技能编辑界面中渲染为一张卡片：

```
┌─────────────────────────────────────────────────┐
│  效果组: [mode下拉▼]                    [× 删除] │
│                                               │
│  ┌─────────────────────────────────────┐     │
│  │ 分支1: 概率 [50]%            [删分支] │     │
│  │  [目标▼] [效果类型▼]            [×] │     │
│  │  层数: [输入框]    概率%: [输入框]   │     │
│  └─────────────────────────────────────┘     │
│                                               │
│  ┌─────────────────────────────────────┐     │
│  │ 分支2: 概率 [50]%            [删分支] │     │
│  │  [目标▼] [效果类型▼]            [×] │     │
│  │  层数: [输入框]    概率%: [输入框]   │     │
│  └─────────────────────────────────────┘     │
│                                               │
│  [ + 加分支 ]                                 │
└─────────────────────────────────────────────────┘
```

### 2.2 顶部模式下拉

- 三个选项：all / randomOne / randomRoll
- all 模式：分支不显示概率输入框，子效果平铺排列
- randomOne 模式：每个分支显示概率输入框
- randomRoll 模式：每个分支显示概率输入框（独立掷骰，不需合计100%）

### 2.3 分支卡片

- 每个分支是一个子卡片，带边框/背景区分
- randomOne / randomRoll 模式下：分支卡片顶部显示"概率 [输入框]%"
- 分支卡片内部：嵌套现有效果编辑组件（目标下拉 + 效果类型下拉 + 层数 + 概率%）
- 分支卡片右上角有"删分支"按钮

### 2.4 加分支按钮

- 效果组卡片底部"+ 加分支"按钮，新增一个空子效果
- 空分支默认目标=敌方、效果类型=请选择、层数=0、概率=0

### 2.5 randomOne 概率合计校验

- 实时显示"当前合计：XX%"
- 不等于 100% 时高亮提醒（红色文字或警告色背景）
- 尝试保存/切换技能时如果不等于 100%，弹提示"randomOne 模式下分支概率合计应为 100%"
- randomRoll 模式不需要此校验

---

## 三、验收标准

1. 效果组卡片可编辑：模式下拉可切换 all/randomOne/randomRoll。
2. 分支卡片可编辑：概率输入框、子效果目标/类型/层数/概率%都可修改。
3. 可加分支、可删分支。
4. all 模式下不显示分支概率输入框。
5. randomOne 模式下所有分支概率实时显示合计，不等于 100% 时有高亮提醒，保存时弹提示。
6. randomRoll 模式下显示分支概率输入框，但不做合计校验。
