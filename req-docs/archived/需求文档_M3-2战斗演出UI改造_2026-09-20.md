# 需求文档 M3-2 战斗演出 UI 改造

> 版本：v1.0 | 日期：2026-09-20

---

## 一、需求背景

当前战斗界面是纯文字日志流，缺乏视觉演出反馈。M3-2 将战斗 UI 改造为可视化布局——横屏 PC 端，参考太吾绘卷的布局结构。

---

## 二、整体布局

```
┌─────────────────────────────────────────────────────────────┐
│ [我方展示板]   [血条]    回合数/信息    [血条]   [敌方展示板] │
│ ┌─────────┐  ┌───────┐              ┌───────┐  ┌─────────┐ │
│ │ 立绘    │  │血条   │              │血条   │  │ 立绘    │ │
│ │ 名字    │  │能量   │              │能量   │  │ 名字    │ │
│ │ 状态栏  │  └───────┘              └───────┘  │ 状态栏  │ │
│ │ 状态图标│                                      │ 状态图标│ │
│ │ 队列槽  │                                      │ 队列槽  │ │
│ └─────────┘                                      └─────────┘ │
│                                                             │
│              ┌─────────────────────────────┐                │
│              │   战斗场地（动画+伤害数字）  │                │
│              │                             │                │
│              │  [敌方出招名片]              │                │
│              └─────────────────────────────┘                │
│                                                             │
│              [技能] [日志] [背包] [逃跑]  ← 功能栏            │
│              ┌─────────────────────────────┐                │
│              │   技能栏 / 日志栏（切换）    │                │
│              └─────────────────────────────┘                │
└─────────────────────────────────────────────────────────────┘
```

## 三、各区域详细设计

### 3.1 左右展示板

| 项目 | 说明 |
|---|---|
| 位置 | 屏幕左右两侧，从顶到底 |
| 内容（从上到下） | 立绘 → 名字 → 状态栏 → 状态图标 → 队列槽 |
| 立绘 | 先用 emoji 占位，后续替换为立绘 |
| 状态栏 | 等级、血量数值、能量 |
| 状态图标 | 圆圈图标，见§3.4 |
| 队列槽 | 敌方显示其他敌人（有队列），我方暂留空位 |

### 3.2 顶部血条区

| 项目 | 我方 | 敌方 |
|---|---|---|
| 血条 | 有刻度，每 25 一格 | 有刻度，每 25 一格 |
| 数值显示 | 鼠标 hover 显示具体数值 | 不显示具体数值 |
| 能量 | 蓝色数字 `XX/YY`（个位数补 0，如 `05/10`） | 同左 |
| 回合数 | 双方血条中间，显示 `第 N 回合` | — |

### 3.3 出招名片

| 项目 | 我方 | 敌方 |
|---|---|---|
| 位置 | 我方展示板右侧，战斗场地左侧 | 敌方展示板左侧，战斗场地右侧 |
| 内容 | 技能名 + 克制图标 | 克制图标 + 技能名 |
| 克制图标方向 | 图标在技能名右边（→） | 图标在技能名左边（←） |
| 克制图标 | 克制↑ / 正常→ / 抵抗↓ | 同左 |

### 3.4 状态图标

| 项目 | 说明 |
|---|---|
| 位置 | 立绘下方的状态栏里 |
| 样式 | 圆圈图标 |
| 颜色 | 绿色=增益属性状态，红色=减益属性状态，其他颜色=效果状态 |
| 图标内容 | 先用占位字符，后续替换为 icon |
| 层数角标 | 右下角白色角标，显示层数 |

### 3.5 战斗场地（中间）

| 项目 | 说明 |
|---|---|
| 内容 | 战斗动画区域 |
| 伤害数字 | 飘在战斗场地里（演出的一部分） |
| 占位方案 | 先做最小演出：攻击时精灵往前冲一下 + 伤害数字飘字 |

### 3.6 功能栏

| 项目 | 说明 |
|---|---|
| 位置 | 展示板之间的下方，详情栏上方 |
| 按钮 | [技能] [日志] [背包] [逃跑] |
| 样式 | 圆框图标按钮，先用首字占位（技/日/包/跑） |
| 背景 | 透明背景和边框 |
| 居中 | 按钮在功能栏内居中排列 |
| 切换逻辑 | 点技能/日志/背包 → 下方详情栏切换内容；点逃跑 → 直接触发 |

### 3.7 详情栏（下方）

**默认：技能栏**
- 卡片式布局，每张卡片：技能名、属性、类型（物理/特殊/状态/防御）、威力（攻击技能显示数值，非攻击显示"-"）、技能描述、克制图标
- 选中高亮（点了就释放）
- 冷却中灰化
- 技能多了支持滚轮

**切换后：日志栏**
- 显示战斗日志文字
- 替代原来的纯文字界面

**切换后：背包栏**
- 显示背包物品列表
- 可以使用道具

## 四、精灵立绘占位方案

| 元素 | 占位方案 |
|---|---|
| 精灵立绘 | emoji（如 🐺 🔥）或 SVG 几何图形 |
| 状态图标 | 圆圈内放文字占位（如 "毒" "烧" "麻"） |
| 功能栏按钮 | 圆框内放首字（技/日/包/跑） |

---

## 五、验收标准

1. 战斗界面布局：左右展示板到顶，血条+回合数在顶部中间，战斗场地居中，功能栏+详情栏在底部。
2. 血条有刻度，我方 hover 显示数值，敌方不显示。
3. 能量用蓝色数字 `XX/YY` 格式，个位数补 0。
4. 状态图标为圆圈样式，绿色增益/红色减益/其他效果，右下角层数角标。
5. 出招名片对称布局：我方技能名+右图标，敌方左图标+技能名。
6. 功能栏四个按钮（技能/日志/背包/逃跑），点击切换下方详情栏。
7. 技能卡片显示完整信息：名称、属性、类型、威力、描述、克制图标。
8. 技能选中高亮，冷却灰化。
9. 伤害数字飘在战斗场地中。
10. 回合数显示在双方血条中间。
