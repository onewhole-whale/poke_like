# 需求文档 M3-2 补丁 · 战斗UI修正 + 代码动画

> 版本：v1.0 | 日期：2026-09-20 | 性质：M3-2 补丁

---

## 一、需求背景

M3-2 战斗 UI 布局已完成，但和设计预期有差距。本补丁修正 UI 布局问题，并补充战斗代码动画。

---

## 二、UI 布局修正

### 2.1 立绘区

| 项目 | 我方 | 敌方 |
|---|---|---|
| 名字位置 | 立绘框内左上角 | 立绘框内右上角 |
| 立绘 | emoji/SVG 占位 | 同左 |

### 2.2 血条

| 项目 | 说明 |
|---|---|
| 精度 | 线性展示，精确到小数点后 1 位（70.0% 血量 = 70% 长度的血条） |
| 刻度 | 血条管子本身加三角刻度，方便一眼看大致血量 |
| 收缩方向 | 朝角色方向收缩——我方空的部分在右边，敌方空的部分在左边 |

### 2.3 能量显示

| 项目 | 说明 |
|---|---|
| 位置 | 血条下方，靠近展示板那侧 |
| 格式 | 蓝色数字 `XX/YY`（个位数补 0） |

### 2.4 状态栏

| 项目 | 说明 |
|---|---|
| 内容 | 只放状态图标，不放名字 |
| 显示逻辑 | 只有附加了状态才显示图标——初始不该有一堆状态 |
| 图标 | 不同属性状态用不同图标（现在都是一样的圆圈，要区分） |
| 颜色 | 绿色=增益，红色=减益，其他颜色=效果状态 |
| 层数 | 右下角白色角标 |

### 2.5 队列栏

| 项目 | 说明 |
|---|---|
| 位置 | 状态栏下方 |
| 我方 | 只有 1 只精灵，队列栏留空位置 |
| 敌方 | 显示队列里的其他敌人 |

### 2.6 技能卡片

| 项目 | 说明 |
|---|---|
| 尺寸 | 缩小——现在卡片和状态栏差不多长，太占空间 |
| 内容 | 名称、属性、类型、威力、描述、克制图标 |

### 2.7 战斗场地

| 项目 | 说明 |
|---|---|
| 大小 | 放大——网页版空间大，中间场地要占主要视觉面积 |

## 三、战斗代码动画

### 3.1 攻击动画

| 项目 | 说明 |
|---|---|
| 触发时机 | 技能命中时 |
| 效果 | 攻击方精灵往对方方向冲一下（位移 0.3s），然后回到原位 |

### 3.2 受击动画

| 项目 | 说明 |
|---|---|
| 触发时机 | 被攻击时 |
| 效果 | 受击方精灵闪红 + 左右震动 0.2s |

### 3.3 伤害数字飘字

| 项目 | 说明 |
|---|---|
| 触发时机 | 伤害结算后 |
| 效果 | 伤害数字从受击精灵位置向上飘，0.8s 后消失 |
| 暴击 | 数字放大 + 红色 + 震动 |
| 治疗 | 绿色数字 |

### 3.4 技能粒子特效

按技能属性在战斗场地生成粒子效果：

| 属性 | 粒子效果 |
|---|---|
| 火 | 红色粒子从技能位置向外扩散 |
| 水 | 蓝色水滴下落 |
| 草 | 绿色叶片飘动 |
| 雷 | 黄色闪电线条闪烁 |
| 冰 | 白色雪花飘落 |
| 暗 | 紫色烟雾扩散 |

实现：Canvas 粒子系统，10~20 个粒子，0.5~1s 后消失。

### 3.5 状态图标动画

| 状态 | 动画 |
|---|---|
| 获得新状态 | 图标弹出动画（缩放 0→1.2→1） |
| 状态消失 | 图标缩小消失 |

---

## 四、验收标准

1. 名字在立绘框内：我方左上角，敌方右上角。
2. 血条线性精确展示，管子有三角刻度；收缩方向朝角色（我方空在右，敌方空在左）。
3. 能量在血条下方靠近展示板那侧，蓝色数字 XX/YY 格式。
4. 状态栏不放名字；初始无状态时状态栏为空；不同属性状态用不同图标。
5. 队列栏在状态栏下方，我方留空位置，敌方显示队列。
6. 技能卡片尺寸缩小。
7. 战斗场地放大。
8. 攻击时攻击方往前冲一下。
9. 受击时受击方闪红+震动。
10. 伤害数字飘字，暴击放大+红色，治疗绿色。
11. 技能释放时按属性生成对应粒子特效。
12. 获得状态时图标有弹出动画。
