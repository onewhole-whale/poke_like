# M2 补丁 · 炼化技能石/专长石 + 副本无战斗结算 + 亲和力修复

- **版本**：v1.4（2026-09-17，三项待确认全部拍板：道具表 DJ_ 编码 / 0 敌人不足 1000 禁止出发 / 无战斗体力沿用 −10）
- **关联**：M2 副本构建（秘境）与炼化系统；M3 各版本不涉及
- **性质**：M2 补丁（用户拍板 2026-09-17），独立小版本
- **核心变化**：① 炼化常规产出改为「技能石 / 专长石」并重排产出优先级；② 副本支持「无敌人直接结算抽奖」；③ 修复副本训练亲和力——**亲和力按投入的元素结晶计算**（替代现状"按首个素材元素"的错误实现）

---

## 1. 需求背景与目标

**问题**：
1. 副本构建需要带技能/专长的原始素材（决定敌人 + 存在分奖励池），炼化也消耗原始素材；但炼化常规产出（凝材/萌芽等）对副本-技能-养成主循环无有效价值；
2. 副本训练增益的亲和力按"投入素材中第一个素材的元素"计算（`trainGainAll`），与设计意图（元素结晶 = 亲和训练素材）不符——属错误实现，本次一并修复。

**目标**：
1. 炼化常规产出（未出灵兽时）改为**技能石/专长石**——每块 = 指定技能/专长的 100 存在分，可直接投入副本奖励池，让炼化产出回流副本链；
2. 技能石/专长石不产生敌人，支持**无敌人副本直接结算抽奖**（扫荡/委托式路线）；
3. **副本训练亲和力改为按投入的元素结晶计算**：投什么元素的结晶，就提升对应属性亲和力；不投结晶则不提升亲和力。

**设计对比**（两条素材路线并存）：

| 路线 | 存在分 | 战斗 | 经验/训练 | 代价 |
|---|---|---|---|---|
| 战斗路线（现状） | 素材 100% 分散到多技能/专长 | 肉鸽连战 | 5 倍经验 + 亲和（按结晶）+ 熟练度 | 费时、有风险、分分散 |
| 技能石路线（新增） | 炼化 200 分 → 100 分石，定向集中 | 无（0 敌人直接结算） | 无经验/训练 | 50% 折损 + 余数弃 + 无经验 |

## 2. 需求详情

### 2.1 新道具：技能石 / 专长石（用户拍板：独立道具表，非素材）

- **定义**：炼化常规产出（未出灵兽时）。每块 = 指定技能/专长的 **100 存在分**；投入副本时直接给该技能/专长 +100 分，**不产生敌人**。
- **品类**：**道具（非素材）**——新开独立道具表（ITEMS），与素材表 MATS 平行；不参与素材类逻辑（掉落/采集、进化素材单位、炼化投料）。
- **id 编码**（用户拍板 2026-09-17）：`DJ_m_nnnnnn`——`DJ` 前缀（道具标志）、`m` = 技能/专长的属性（`flamebreath`→fire，通用技能/专长→none）、`nnnnnn` = **6 位数字顺序编号**（全表全局连续递增、不按属性分段；未来新增技能/专长时继续递增、不重用旧号）。
  - 示例：`DJ_fire_000001`（技能石·<技能名>）、`DJ_none_000042`（专长石·<专长名>）
- **道具表内容**：当前游戏全部技能/专长各 1 条（按 GLOBAL_SKILL_POOL / GLOBAL_PERK_POOL 顺序生成）；字段：`id` / `name`（「技能石·<技能名>」/「专长石·<专长名>」）/ `elem`（= 技能/专长属性）/ `skillId` 或 `perkId`（绑定）/ `type:'item'` / `tags:['技能石']|['专长石']` / `count:0` / `desc`（如「炼化凝出的定向技能石，投入秘境可为 <技能名> 提供 100 存在分，不产生敌人。」）。
- **持有与使用**：
  - 进背包可持有、可投入副本构建（选材时道具可选）；
  - **不可再投入炼化炉**（炼化投料校验排除 `DJ-`，防止无限循环）；
  - **不参与进化素材单位判定**（`matUnitSum`/`allMatDef` 排除 `DJ-`，防止充当进化素材）；
  - 不参与妖兽掉落 / 野外采集。

### 2.2 炼化产出流程（`doRefine`，用户拍板优先级）

**流程顺序**（用户 2026-09-17 拍板）：

```
投入素材
  └─ 1. 灵兽判定（spirit 配方）：出灵兽 → 只出灵兽，流程结束
  └─ 2. 技能石/专长石判定（按素材独立）：
       每个素材的 extractInfo 中，任一技能分 ≥200 或专长分 ≥200 →
         该素材用于出石头：每个到 200 的技能/专长各出 1 块（每 200 分 1 块，余数弃）
       若该素材所有技能/专长分均 <200 → 该素材走第 3 步素材炼化路径
  └─ 3. 素材炼化路径：走素材路径的素材按词条单位匹配保留规则
       （仅 r-chr-fine / r-chr-perf / r-gel，纯素材配方已删）→ 产出结晶/凝胶
  └─ 4. 再剩下的素材转化为灵息结晶（剩余素材按保底比例换门票，不蒸发）
```

**具体规则**：

1. **灵兽判定不变**：spirit 配方匹配（出灵兽则跳过后续全部常规产出，既有逻辑）。
2. **技能石/专长石判定（素材独立，不跨素材聚合）**：
   - 逐个素材判定：其 `extractInfo.skillScore` / `extractInfo.talentScore` 中，**任一技能/专长分 ≥200** → 该素材"用于出石头"；
   - 每个到 200 的技能/专长各出 1 块对应石（每 200 分 1 块，如 420 分 → 2 块余 20）；**余数直接损耗**（不累计、不返还、不结转）；
   - 该素材所有技能/专长分均 <200 → 该素材**不走石头路线**，进入素材炼化路径；
   - 例：素材 A `flamebreath` 260 + `pyre` 180 → 出「技能石·flamebreath」×1（余 60 弃），`pyre` 180 分弃，素材 A 不再走素材路径；素材 B `pyre` 150 → 不出石头，走素材路径。
3. **素材炼化路径（保留规则）**：
   - 保留：`r-chr-fine`（词条 ≥3 单位 + 精良）、`r-chr-perf`（词条 ≥4 单位 + 稀有）、`r-gel`（词条 ≥3 单位 + 混沌）——按原规则照常触发；
   - **删除纯素材配方**：`r-micro`（元素微粒·口粮）、`r-ling`（标准灵材·凝材）、`r-sprout`（元素萌芽）不再作为炼化产出。
4. **剩余素材转化灵息结晶**（用户拍板 2026-09-17）：走素材路径且词条单位未匹配到任何保留规则的剩余素材，**不再蒸发**，转化为灵息结晶（秘境门票）；转化数量沿用现状保底公式——`outLing = 1 + floor(剩余素材单位/4)`（剩余 1~3 单位 → 1 个，每满 4 单位 +1；仅存在剩余素材时触发，剩余 0 → 不出）。

### 2.3 副本构建改造

1. **技能石/专长石投入副本**：
   - `scorePlan` 特殊处理：检测 `DJ-` 前缀道具（按绑定的 skillId/perkId），**直接给对应技能/专长 +100 分**（不走 `defaultExtract` 哈希）；属性归入对应技能/专长属性（none→universal）；
   - **不产生敌人**（敌人生成 `enemyStats` 只看 `type:'beast'/'plant'/'ore'`，道具天然排除）。
2. **无敌人副本直接结算**（用户拍板）：
   - 出发时 `buildEnemyList` 敌人数 = 0 → 校验**存在分是否满 1000**：
     - **存在分不足 1000 → 禁止出发**（toast 提示「无敌人副本需存在分满 1000 方可开启」，不消耗灵息/体力）；
     - **存在分满 1000 → 跳过冒险/战斗过程，直接进入结算抽奖**（走通关分支 `finalizeDungeon(won=true)`）；
   - 结算按存在分 roll（每属性 1000 分容量，满 1000 完整抽取——沿用 `rollEntry`）；
   - **无战斗 → 无 5 倍经验、无训练增益（exp/aff/mastery）、无挂机复刻记录**（`kills=0` 不产生记录）。
3. **消耗**（用户拍板）：沿用出发消耗——灵息结晶 −1、**体力 −10**（无战斗副本不免体力）。

### 2.4 UI

- **炼化预览**：新增「预计技能石/专长石」行（按投入素材 extractInfo 分预览：每技能/专长累计 200 分 = 1 块）。
- **副本构建**：
  - 技能石/专长石可投入（道具表条目可被选材）；
  - 存在分预览含技能石固定加分（scorePlan 结果）；
  - 0 敌人时：存在分不足 1000 → 出发按钮置灰/提示「需存在分满 1000」；满 1000 → 提示「无敌人：出发后直接结算抽奖」。
- **背包**：技能石/专长石条目正常显示（道具表解析）。

### 2.5 副本训练亲和力修复（用户拍板）

**现状（错误实现）**：`trainGainAll` 的亲和力属性取"投入素材中第一个素材的元素"（`matsToList(mats)[0].elem`），与设计意图不符。

**修复后**：
- 亲和力属性 = **投入的元素结晶（`chr-`）的元素**；投入多个不同属性结晶时，取**数量最多的结晶元素**，并列时取首个；
- 亲和力值 = 沿用训练值换算（`trainValue(mats) × 0.002`，受训练上限约束，默认上限 200、可被 `affCap` 专长突破——既有机制不变）；
- **未投入元素结晶 → 副本训练不给亲和力**（亲和增益为 0/省略）；经验与技能熟练度增益维持现状（按既有素材训练值）。

## 3. 参考案例

- **定向委托/扫荡（多款放置类）**：用资源折损换取免战斗自动获取——本项目以"200 分换 100 分 + 余数弃 + 无经验"作为免战斗的代价，战斗路线仍保留经验/训练优势，避免扫荡完全替代肉鸽。
- **定向许愿（抽卡保底类）**：技能石把 100 分集中到指定技能，对比素材散分（哈希分散到多个技能），玩家可精确规划刷取目标。

## 4. 验收标准

1. 炼化未出灵兽：投入素材后，`flamebreath` extractInfo 累计 ≥200 分 → 背包新增「技能石·flamebreath」×1（道具表条目，id 为对应 `DJ_` 编码），余数不显示不返还；每个技能/专长各自独立计数。
2. **素材独立判定**：素材 A 任一技能/专长分 ≥200 → A 出石头且不再走素材路径；素材 B 所有技能/专长分均 <200 → B 不进石头路线、走素材炼化路径。
3. 素材炼化路径：精良素材（词条 ≥3 + 精良）→ 出元素结晶；无词条匹配（如普通素材词条 <3）→ 剩余素材按第 4 步转化为灵息结晶。
4. 剩余素材转化灵息结晶：素材路径素材词条未匹配任何保留规则时，剩余单位按 `1 + floor(剩余单位/4)` 转化为灵息结晶（如剩余 1~3 单位 → 1 个、剩余 4 单位 → 2 个）；投入素材全部被石头/结晶/凝胶消耗（剩余 0）→ 不出灵息结晶。
5. `r-micro`/`r-ling`/`r-sprout` 不再产出；`r-chr-fine`/`r-chr-perf`/`r-gel` 照常触发。
6. 出灵兽流程不受影响（出灵兽则不出石头、不走素材路径）。
7. 技能石/专长石投入副本：`scorePlan` 对应技能/专长存在分 +100；`enemyStats` 敌人数不变（贡献 0）。
8. 纯技能石副本（10 块同技能石 = 1000 分）：出发后**跳过战斗，直接弹结算抽奖**；抽取结果包含该技能（满权重，抽空概率为 0）。
9. **0 敌人副本存在分不足 1000 → 禁止出发**（toast 提示，不消耗灵息/体力）。
10. 0 敌人 + 满 1000 副本：结算无经验/亲和/熟练度增长；不产生挂机复刻记录（`trainLogs` 无新增）。
11. **亲和力修复**：投入火系元素结晶的副本，通关训练增益亲和力 = 火系（值按训练值换算、受上限约束）；未投结晶的副本，训练增益无亲和力项。
12. **道具表与编码**：技能石/专长石为独立道具表条目，id 遵循 `DJ_m_nnnnnn`（m=技能/专长属性、6 位数字顺序编号、全表全局连续）；不可再投入炼化炉（投料校验排除）；不参与进化素材单位判定。
13. 全量回归绿（战斗副本、挂机、炼化、图鉴、背包、进化）。
