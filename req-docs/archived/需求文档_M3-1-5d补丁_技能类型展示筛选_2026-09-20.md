# 需求文档 M3-1-5d 补丁 · 技能类型展示与筛选修复

> 版本：v1.0 | 日期：2026-09-20 | 性质：5d UI 补丁

---

## 一、需求背景

技能列表 UI 中，属性后面的类型字段统一显示 track（物攻/特攻），但状态技能和防御技能没有物攻/特攻轨道，显示"特攻/物攻"属于误导。同时筛选框只有一个属性筛选，缺少技能类型筛选。

---

## 二、需求详情

### 2.1 技能列表类型列修正

当前：所有技能都显示 track 字段（物攻/特攻）。

修正后：
| 技能 type | 类型列显示 |
|---|---|
| 攻击（phys） | 物理 |
| 攻击（spec） | 特殊 |
| 状态 | 状态 |
| 防御 | 防御 |

即：类型列显示的是技能的**战斗定位**（物理/特殊/状态/防御），而不是轨道。状态技能和防御技能不再显示"物攻/特攻"。

### 2.2 筛选区新增技能类型标签

当前筛选区只有属性标签一行。

修正后：在属性标签上方新增一行**技能类型标签**，样式与现有属性标签一致——圆角按钮形式，每个标签后面带该类型技能的数量：

```
技能类型  [物理 199]  [特殊 159]  [防御 54]  [状态 167]
```

- 点击标签选中（高亮），再点取消
- 支持多选（选多个类型时，列表显示类型为其中任意一个的技能）
- 不选时=全部类型
- 与属性标签为 AND 关系（选了属性+类型，就同时过滤）
- 数量实时统计当前筛选条件下各类型的技能数

---

## 三、验收标准

1. 状态技能（如水雾疗养、毒雾、笔仙等）在技能列表中类型列显示"状态"，不显示"物攻/特攻"。
2. 防御技能（如水环、毒液镀层、阴影潜行等）在技能列表中类型列显示"防御"，不显示"物攻/特攻"。
3. 攻击技能正常显示"物理"或"特殊"。
4. 筛选区有一行技能类型标签（物理/特殊/防御/状态），每个标签后面带数量，样式与属性标签一致。
5. 点击类型标签可多选，列表实时过滤；不选时显示全部类型。
6. 同时选择属性和类型后，列表只显示同时满足两个条件的技能。
