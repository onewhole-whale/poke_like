# 需求文档 M3-1-5d 补丁 · 技能效果编辑区排版优化

> 版本：v1.0 | 日期：2026-09-20 | 性质：5d UI 补丁

---

## 一、需求背景

技能编辑界面的效果区域排版混乱：多条效果堆叠在一起，下拉框、数字输入框、删除按钮挤成一团，用户无法快速分辨哪个输入框属于哪条效果。

---

## 二、需求详情

### 2.1 每条效果做成独立卡片

每条效果（effects 数组的一个元素）渲染为一个独立卡片：
- 卡片有浅边框（1px 深色边框或浅背景色），与相邻卡片有间距（8~12px）
- 卡片右上角放删除按钮（×）
- 卡片内部布局：

```
┌─────────────────────────────────────────────────────┐
│  [目标下拉▼]  [效果类型下拉▼]              [× 删除] │
│  层数: [ 输入框 ]    概率%: [ 输入框 ]              │
└─────────────────────────────────────────────────────┘
```

- 第一行：目标下拉 + 效果类型下拉 + 删除按钮（右对齐）
- 第二行：两个数字输入框，上方带小标签（"层数"和"概率%"）

### 2.2 数字输入框加标签

- 第一个数字输入框上方标注"层数"
- 第二个数字输入框上方标注"概率%"
- 标签字号小（11px），颜色为次要文字色

### 2.3 加效果按钮

保持现有"+ 加效果"按钮样式，放在所有效果卡片下方。

---

## 三、验收标准

1. 多条效果之间有明确的视觉分隔（边框或间距），每条效果是一个独立卡片。
2. 每条卡片内：第一行=目标下拉+效果类型下拉+删除按钮，第二行=带标签的两个数字输入框。
3. 数字输入框上方有"层数"和"概率%"小标签。
4. 点击删除按钮可移除对应效果卡片。
5. 点击"+ 加效果"在末尾新增一张空白效果卡片。
