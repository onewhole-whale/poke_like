## 1. 需求背景与目标

**解决什么问题**：
1. **出灵兽概率（1%）未经思考随手定**，无保底——改为「冒险次数拉节奏 + 120 次纯硬保底兜底」；
2. **战斗能量不自动增长**——改为「受击回能 +1」；
3. **冒险系统线性 3–5 节点**、无探索无梯度——重构为**秘境沙盒**（御兽小说秘境 × 太吾绘卷走格子），并建立**地块/事件三层架构**（通用单元可复用）；
4. **采集无工具概念**——新增**全品质六档工具系统**（素材细分、品质池、图纸+炼化制作）；
5. **体力 = 行动经济**——进入不扣、移动/采集扣 1、事件不扣（空手采集 = 体力效率惩罚）。

**核心目标**：休闲玩家（每天约 2 把中图冒险）**1 个月稳定获得 1 只灵兽**（120 次配方炼化纯硬保底）；冒险成为有探索感的沙盒；采集成为素材操作层。

**版本边界（用户拍板）**：
- **本版（M3-1 机制补全，本期开发）**：三层架构 + 沙盒生成 + 黑雾/移动/出口 + 体力行动制 + 采集工具（全品质）+ 受击回能 + 炼化保底 120 + demo 修复 + 全量回归。
- **下版（内容填充，大版本统一做，6 项清单见 §5）**：技能池、地块表、事件表、掉落素材清单、工具表、冒险地图派送表；区域 Boss/徽章、世界 Boss、赛季系统、装备另立文档。

## 2. 需求详情

### 2.0 验证基准（用户拍板）

- 休闲玩家每日登录 1 次收菜；单登体力溢出是特性（奖励双登）。
- 炼化节奏基准：**每天 2 把中图（7×7）冒险**；每把期望 ≈12 战 ≈ 2 次配方炼化机会 → 30 天 ≈ 120 次 → 保底 1 个月 1 只。

### 2.1 表1 · 升级曲线（⚠ 冒险重构后需重校）

| 等级 | 本级经验 | 累计经验 |
|---|---|---|
| 10 | 271 | 729 |
| 30 | 2,611 | 24,389 |
| 60 | 10,621 | 205,379（灵根突破至 70：328,509） |

**变更沿用**：冒险 2 战/把 → 12 战/把，经验供给大增（预计 28 天满级 → 约 10 天）。**随冒险重构后重验**：通过副本/挂机/冒险经验配比或曲线拉长回调至 20–30 天满级（用户已认可处理方向）。

### 2.2 表2 · 素材产耗比（沙盒口径）

- 供给：中图 7×7 清图约七成 ≈ 12 战 ≈ **70–80 单位素材/把**；每天 2 把 ≈ 144 单位。
- 消耗：配方炼化 4 次（60–80 单位）+ 副本门票（本版副本场次下降，见 2.5）+ 挂机/其他 ≈ 110 → **略盈余**。
- 采集工具效率是「时间/体力换素材」放大器，不破坏保底。

### 2.3 表3 · 炼化定价锚点 + 出灵兽判定（定稿）

**定向配方条件（实测）**：元素 ≥15–20 单位 + 特征词条 ≥4–12 + 品质 ≥精良；候选池 ≥1 只即判定（计划文档「≥3 种」作废）。

**节奏**：12 战 ≈ 2 次配方炼化；每天 2 把 = 4 次/天 → 120 次/月。**基础 1% 不动**（自然期望 1.2 只/月，期望首出 ≈25 天）；**纯硬保底 120 次必出**（只防脸黑不缩短节奏）。**无软保底渐进**（v1.1 方案废弃）。

### 2.4 表4 · 战斗节奏 / 能量（定稿）

实测 1v1 平均 3.74–4.00 回合、能量恒 5。**方案：受击回能 +1**（敌方攻击动作结算后我方 +1；每次攻击动作 1 点不看段数；上限 20 不变；妖兽不参与；「回能」机制技保留急用价值）。**不下调爆发阈值、不动绝技/普攻数值**（用户红线）。

### 2.5 表5 · 体力经济（v1.3 行动制）

| 项 | 数值 | 说明 |
|---|---|---|
| 自然恢复 | **6min+1，上限 120** | 12h 回满 |
| 进入冒险 | **0 体力** | 门票制取消 |
| 移动（沙盒） | **1 体力/步** | 上下左右一步 |
| 采集 | **1 体力/次** | 空手采集同样扣 1（效率惩罚） |
| 事件/战斗 | **0 体力** | 触发不额外扣；剧情选项可带体力代价（下版） |
| 副本 | 10/场 + 1 灵息结晶 | 不变 |
| 微粒 | 炼化 2 单位 → +20 | 二级补给 |
| 单登 | 120/天 ≈ **2 把中图（~60–70 体力）+ 副本 ~5 场（50）** | — |
| 双登 | 240/天 ≈ 4 把中图 + 副本 ~10 场 | 奖励投入 |

**重校点**：副本场次较旧平衡流（10 场/天）下降 → 若技能/专长获取受影响，后续重校副本门票（结晶 1→更低）或副本收益（随冒险实现后验证）。体力成为探索深度与节奏的真实闸门：每把可移动/采集的行动数 = 剩余体力。

### 2.6 委托口径敲定（同 v1.0 不变）

1. 洗髓露：图鉴里程碑 10 只→1 瓶 + 世界 Boss 周 1/月 3；撤销炼化 6%。
2. 异色（洛克模型）：3% RNG（演示 15%）+ 飞升保异色；捕捉成功 60 次保底（杀死不计）；赛季 2 个月、代币商店每季 8 凭证（高强度 8 只 vs 收菜 4–6 只，1.8:1）；赛季结束清空、返场后定。
3. 灵材：2 单位同词条 → 1 标准灵材；妖兽投炉伴生 1 精良生命精华。悬案关闭。
4. 结晶/凝胶：结晶·精良 亲和投入 +10（≤200）、结晶·完美 +20（破限 300）；凝胶洗训练亲和。功能后置。
5. 传说个体值：与普通灵兽一致（≤3 项 ×1–20 + 性格），不额外满个体。

### 2.8 灵兽缘分保底（定稿）

1. 数据：`S.refineFate = { speciesId: count }`（持久化，旧档缺省兼容）。
2. 计数：配方炼化候选池非空 → 池中每只 +1；候选池空不涨。
3. 出率：fate < 120 恒 1%；**fate ≥ 120 必出**。无软保底。
4. 选种：fate ≥ 120 者在池 → 直接出该只（并列按品质权重 0.1^rank）；否则 `pickSpiritByRarity`。
5. 清零：只清被出的那只，池中其他保留。
6. UI：候选池每只「缘分 X/120」进度，逼近必出有提示。
7. 演示模式：硬保底 60（减半）。

**数学验证**：4 次/天 → 120 次 = 30 天必出；自然 1% 期望首出 ≈25 天；30 天 ≥1 只概率 100%。素材分流拉长保底周期（玩家取舍）。

### 2.9 冒险沙盒系统（三层架构，本期落地）

**参考**：御兽小说秘境（体验）× 太吾绘卷早期走格子（形式）。

#### 2.9.1 三层架构总览（用户拍板）——继承模型

```
【层1 · 全局方块库 = 基类定义】（超越冒险地图，通用生成单元）
  地块表 TERRAIN：{id, name, size:1, 资源量范围{plant:[a,b], ore:[c,d]},
                   品质概率 qualityDist{normal:…,legend:…}（仅大类品质概率）,
                   细分概率 baseSubDist, 素材清单（可选默认）}
  事件表 EVENTS：{id, name, size:1, kind:战斗/奇遇/冒险, 内容参数}
  → 只定义该类地形/事件「核心且确定」的属性，不实体化

【层2 · 冒险地图配置 = 派生覆写】（关联层1 + 本图特化）
  {id, name, 尺寸档位, 
   terrainWeights: 各地形生成概率,
   eventWeights:   各事件生成概率（事件密度 ~50% 叠加）,
   overrides: {   // 继承机制：按地形/事件 id 可选覆写，缺省 = 继承基类
     地形id: { qualityDist?: 品质占比特化,
               resRange?:   资源量范围特化,
               matLists?:   素材清单与细分概率特化（地图限定具体素材）}
   }}

【层3 · 沙盒生成 = 实例化】（进入冒险时执行）
  按配置铺地形图（满格）→ 撒事件（允许空）→ 标记出口/落点 → 两层叠放 → 黑雾遮盖
  → 资源量在范围内 roll、品质按 qualityDist roll、素材按 matLists roll → 完全实例化
```

- **继承语义（用户拍板）**：
  - **基类属性**（层1 定义，覆写时建议不动）：`size`、地形/事件类型语义（决定渲染、行走、战斗语义）、事件 kind。
  - **可覆写属性**（层2 override）：品质占比 `qualityDist`、资源量范围 `resRange`、素材清单与细分概率 `matLists`——**部分覆写**（只改想改的字段，其余继承基类）。
  - **允许区域特化**：同一地形在不同冒险地图可不同（例如同为「平原」：焚风原·平原品质偏普通、矿石偏多；夜雨泽·平原品质偏高、植物偏多）。**一般无改动，机制上允许**。
  - **派生即定素材清单**：层2 的 `matLists` 直接存该地块的**可采集素材 list**（按大类→细分→素材 id 列表），本图各地块「能采到哪些素材」在派生层就确定；层3 只做数值 roll。
  - **出货概率分配（用户拍板）**：`P(素材 m) = 品质概率 × 细分概率 × 平分系数`——
    1. 品质概率：继承（或覆写后）的 `qualityDist`，在「品质 ≤ 工具品质」池内归一化；
    2. 细分概率：继承（或覆写后）的细分分布，在该品质内分配；
    3. 平分系数：**同一细分类型、同一品质下若有多个素材 → 平分该细分在该品质下的概率**（1/N）。
  - **实例化不可变**：层3 生成后本局内固定（不随探索 re-roll）。
  - **地块采集出货**：品质概率由（覆写后的）qualityDist 定；素材种类由（覆写后的）matLists 限定——「概率地形定、种类地图限」。

**事件块继承（用户拍板）**：
- **冒险事件 / 奇遇事件**：高度定义化，**原样派生**（层2 直接用基类结构，不特化）——结构一致，方便后续维护与更新（内容重设计放下版）。
- **战斗事件**：需要派生——
  - 基类（层1）确认**难度**（难度档决定敌人强度、buff 可选池、实例化 buff 数量）与战斗大方向；
  - 派生（层2）确认**敌人池**（区域限定）+ **全程 buff 规则**（本图该难度战斗事件有没有 buff、从全局 BUFFS 表选哪些可用、实例化抽几个）；
  - 实例化（层3）抽 buff（战斗全程常驻）。

#### 2.9.2 尺寸档位（用户拍板）

| 尺寸 | 战斗数/把 | 炼化机会 | 每把移动+采集体力 | 定位 |
|---|---|---|---|---|
| 5×5 小 | ≈6–8 战 | ≈1 次 | ~15–25 | 快刷 |
| **7×7 中** | **≈12 战** | **≈2 次** | ~25–40 | 标准档（节奏基准） |
| 10×10 大 | ≈20+ 战 | ≈3–4 次 | ~50–80 | 深潜（肝党向） |

#### 2.9.3 黑雾 / 移动 / 出口
- 未探索格黑雾遮盖（占位）；已探索格显示地形名/图标。
- 每步 = 上下左右移动 1 格（边界不可越）；**移动扣 1 体力**。
- **出口格唯一且直接可见**（去黑雾、随机位置、每次不同）：朝出口规划路径但路径被黑雾遮挡 → 直冲/绕路/全清三选一。
- 到达出口 → 结算离开；可随时主动撤退（带走已得）。

#### 2.9.4 格子状态机
未探索（黑）→ 已探索（显地形）→ 事件待触发 → 已解决 → 可采集（资源量 >0）→ 采空（**格子变灰，名称等不变**）。出口格 = 到达即结算。

#### 2.9.5 事件方块（本版框架，内容下版填充）
- **战斗事件**（派生结构，用户拍板）：
  - 基类：`{id, kind:'fight', size:1, difficulty:'简单|普通|困难'（buff 方向难度）, templateProb:{normal:x, elite:y, boss:z}（敌方模版出现概率）}`；
  - 派生（层2）：`{enemyPool:[物种id…]（区域限定敌人池）, buffRule:{enabled, pool:[buffId…], count}}`——buff 从全局 BUFFS 表按难度选（规范化，不乱配）；
  - 实例化（层3）：确认三件事——**本次敌人是谁**（enemyPool 采样）、**什么模版**（按 templateProb roll，见 2.9.6）、**本次 buff 是啥**（按难度方向抽，见 2.9.7）；buff **战斗全程常驻**；触发不扣体力。
- **奇遇事件**：现有 WONDERS 选择支沿用（good/bad/perfect）；**原样派生**；故事链重设计下版做。
- **冒险事件**：小型事件框架（探索/陷阱/机遇，可产出素材/体力/图纸，剧情选项可带体力代价）；**原样派生**；内容下版填充。

#### 2.9.6 敌方模版系统（用户拍板）

- **难度与模版概率完全独立**（正交）：难度只决定 buff 方向（2.9.7），模版概率独立 roll。
- 基类定义本次战斗有多大概率碰到哪种模版（templateProb）；模版 = 敌方属性倍率模板：

| 模版 | 速度 | 血量 | 攻/防/特攻/特防 |
|---|---|---|---|
| 普通模版 | 同普通生成 | ×1 | ×1 |
| 精英模版 | 同普通 | **×3** | **×1.5** |
| 首领模版 | 同普通 | **×5** | **×2.5** |

- **基准概率（用户拍板）**：普通 80% / 精英 15% / 首领 5%——按中图期望反推：自然流程（清图约七成 ≈12 战）≈1.8 精英；开全图（≈16 战）≈0.8 首领。区域/事件可覆写。
- **首领特殊规则**：**不发动突袭**（ambush 不适用）；战斗事件中**可逃离**——逃离 = **退回上一个地块、不扣体力**（当前事件保留未解决，下次进入可再触发）。
- 实例化：roll 模版 → 以 `wildBeast` 生成基础属性 → 套模版倍率。
- **收获差异 + 上位素材（怪物猎人式，用户拍板）**：
  - 普通模版：正常掉落（不变）；
  - 精英模版：掉落**上位素材**，品质 = 该精灵死亡掉落品质 **+1**；
  - 首领模版：上位素材品质 = 死亡掉落 **+2**（**封顶传奇 legend**）；
  - **所有妖兽精灵都需设计上位素材**（命名规范：`上位·{精灵名}{词条名}`，如「上位·火狼裂爪」；具体清单下版批量填充，机制本期落地）；
  - 上位素材用途：**沿用现有高级素材用途体系（高级工具/炼化/图鉴），不单独设计新用途**（用户拍板）。
  - 注：当前掉落基线（普通妖兽击杀掉普通、死亡掉落高 1 品质；完美精灵如「普通掉落精良、死亡掉落史诗」）以 DROPS 表实测为准，上位素材在其上叠加 +1/+2。

#### 2.9.7 战斗全程 Buff 表（全局超越层，用户拍板）

- **buff 匹配难度（简单/普通/困难）**，side 方向由难度决定（不是 buff 自带）：
  - **简单**：对玩家增幅 / 对敌方减益（buff→玩家，debuff→敌方）；
  - **普通**：无 buff，或敌方与玩家**同时获得同一 buff**；
  - **困难**：对玩家减益 / 对敌方增益（buff→敌方，debuff→玩家）。
- **数值固定**（不分弱/强档）：BUFFS 表字段 `{id, name, effectType:'buff'|'debuff'|'neutral', desc(固定效果数值), params}`；duration 一律 battle（全程常驻）；**难度只控制对哪一方生效**。
- **buff 数量由地图派生配置**（`buffRule.count` 在层2 确认，地图特色：有的图 buff 多、有的图 buff 少），不由难度决定。
- 用户案例（已收录）：
  1. `回能潮`（neutral）：每回合结束时全体回复 3 点能量（当前妖兽无耗能技能，实际收益偏玩家，可作简单档使用）；
  2. `元素护甲`（buff）：每次受到攻击获得 1 层对应属性减伤（每层 5%，上限 19 层）——简单=玩家叠甲，困难=敌方叠甲；
  3. `再生`（buff）：每回合回复 12% 最大血量——**简单=玩家回血，困难=敌方回血**（用户明确）。
- 补充案例（固定数值，可调）：
  | id | name | effectType | 固定效果 |
  |---|---|---|---|
  | b-harden | 铁皮 | buff | 受到伤害降低 8% |
  | b-swift | 迅捷 | buff | 速度 +20% |
  | b-fury | 狂暴 | buff | 攻击 +25% |
  | b-thorn | 荆棘 | buff | 受击反弹 8% 伤害 |
  | b-vuln | 易伤 | debuff | 受到伤害 +20% |
  | b-drain | 能量流失 | debuff | 每回合结束 -1 能量 |
  | b-berserk | 血怒 | buff | 血量 <50% 时攻击 +30% |
  | b-regen-20 | 再生·强 | buff | 每回合回复 20% 最大血量 |
  | b-energy-5 | 能量激流 | neutral | 每回合结束 +5 能量 |
  | b-shield-8 | 元素护甲·强 | buff | 每层 8% 减伤，上限 12 层 |
- 实例化：按难度 × effectType 映射 side；按地图 `buffRule.count` 从「强度可用池」抽 buff（规范化，不乱配）。

#### 2.9.8 采集
- 已解决事件格/有资源地形格可采集；每格标注**大类资源量**「植物 X / 矿物 Y」（不细分）；资源量为**范围随机**（地块表定义范围，生成时采样）。
- 采集扣 1 体力 + 工具耐久 1；按出货算法产出（2.10.4）。
- 采空 → 变灰不可采集。

#### 2.9.9 结算
- 到达出口/主动撤退 → 素材入包、奇遇奖励入账、战斗经验结算。
- **死亡：保留已得素材 50%**（用户拍板）。

### 2.10 采集工具系统（全品质六档，本期落地）

#### 2.10.1 素材类型树（挂现有 `type` 字段）

| 大类 | 细分 | 工具 |
|---|---|---|
| plant 植物 | 木头 | 斧 / 锯 |
| | 花草叶 | 手套 |
| | 水生植物 | 网兜 |
| | 果实 | 剪刀 |
| ore 矿物 | 金属 | 镐 |
| | 石料 | 凿 |
| | 气体 | 瓶子 |

#### 2.10.2 工具品质六档（全品质设计，用户拍板）

| 工具品质 | 出货池（≤品质） | 单次采集量 | 耐久 | 获取 |
|---|---|---|---|---|
| 普通 normal | 普通 | ×1 | 100 | 商店购买（标准版） |
| 优秀 good | ≤优秀 | ×1.5 | 120 | 图纸 + 炼化 |
| 精良 fine | ≤精良 | ×2 | 140 | 图纸 + 炼化 |
| 稀有 rare | ≤稀有 | ×2.5 | 160 | 图纸 + 炼化 |
| 史诗 epic | ≤史诗 | ×3 | 180 | 图纸 + 炼化 |
| 传奇 legend | 全品质 | ×4 | 200 | 图纸 + 炼化 |

- 8 种细分 × 6 品质 = **48 种工具**；**锯变体**：同品质效率 ×2、耐久 ×0.6（单次采 2 份、更快报废）。
- 消耗品：每次采集耐久 -1，0 销毁。
- 图纸来源：奇遇稀有结局 + 冒险事件（用户拍板）；本版先落框架，图纸内容下版填充。
- 无工具可采集：50% 出货率 + 仅普通 + 同样扣 1 体力（体力效率惩罚）。

#### 2.10.3 品质规则
- 资源量占用 = **1 + 2×品质档**（普通 1 / 优秀 3 / 精良 5 / 稀有 7 / 史诗 9 / 传奇 11）。
- 出货池 = 品质 ≤ 工具品质；高于工具品质的素材排除重算。
- 地块只标大类资源量；出货细分按工具 roll（概率地形定、种类地图限）。

#### 2.10.4 出货算法（可断言）
1. 校验：大类资源量 >0、格子未采空、耐久 >0、体力 ≥1。
2. 品质池：品质 ≤ 工具品质（无工具 = [普通]）。
3. 品质 roll：按**（覆写后）qualityDist**（品质池内归一化）roll 品质 q。
4. 素材 roll：按**派生层 matLists**（该地形可采集素材 list）——先按细分分布 roll 细分 s，再在「品质 q × 细分 s」的素材列表中**平分选取**（N 个素材各 1/N）；**工具定向优先**——s 取工具对应细分，若该品质池该细分无素材（或概率为 0）→ 该细分概率置 0 后**同大类其他细分按比例顶替**（镐采金属无金属 → 该品质其他矿物）。
5. 出货：选中的素材 id（MATS 按 type+细分+品质 匹配）。
6. 扣减：资源量 -=（1+2×品质档）× 单次采集量；耐久 -1；体力 -1。

## 4. 验收标准（可断言）

1. **受击回能**：敌方攻击动作结算后我方 +1（上限 20）；多段只 +1；未命中不加；妖兽不受影响；reg_cdp/mech/damage_accept 全量回归通过。
2. **炼化保底**：fate<120 恒 1%（采样 200 次 ≤5 出）；fate=120 必出（采样 30 次全出）；出后只清被出的那只；`S.refineFate` 持久化、旧档兼容；UI「缘分 X/120」。
3. **三层架构**：地块表/事件表独立可配（含 size、资源量范围、qualityDist）；冒险地图配置可关联限定（terrainWeights/eventWeights/matLists）；沙盒生成按配置铺图，地形图满格、事件密度 ~50%（±5%）、出口唯一且生成时可见、落点随机。
4. **体力行动制**：进入冒险不扣体力；移动/采集各 -1；事件触发 0 体力；边界移动正确；空手采集同样扣 1。
5. **采集**：大类资源量标注；品质占用 1/3/5/7/9/11；出货池按工具品质；顶替规则正确；采空变灰名称不变；无工具 50% 出货率仅普通。
6. **工具**：48 种（8 细分 × 6 品质）可定义；普通档商店购买、其余图纸+炼化；锯变体 ×2/耐久 ×0.6；耐久 -1、0 销毁。
7. **事件继承 + 战斗 buff + 敌方模版**：冒险/奇遇事件原样派生；战斗事件派生含 enemyPool + buffRule + templateProb；实例化三要素（敌人/模版/buff）齐全；模版倍率正确（精英 血×3 攻防×1.5；首领 血×5 攻防×2.5，速度均同普通）；难度与模版概率独立；首领不突袭、战斗可逃离（退回上一格、事件保留、不扣体力）；精英/首领掉落上位素材（+1/+2、封顶传奇）；buff 数值固定、side 按「难度 × effectType」映射、数量按地图 buffRule.count；buff 战斗全程常驻且效果可验证。
8. **demo 默认修复**：新档 `S.demo === false`。
9. **后置口径**（登记）：洗髓露周 1/月 3；异色 60 保底/8 凭证/1.8:1；凝材 2→1；结晶 +10/+20；凝胶洗训练亲和；传说 IV 同普通。
