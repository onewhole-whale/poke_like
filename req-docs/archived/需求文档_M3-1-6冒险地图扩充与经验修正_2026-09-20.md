## 三、变体地块机制

### 3.1 定义

变体地块是基于标准地块的奇幻变种——叙事上是特殊环境下的特殊地貌。

### 3.2 生成逻辑

1. **后生成**：初始锚点（平原/水域/山地/高原）全部生成完后，再落变体地块锚
2. **基底落锚**：从地图上随机找一个"基底地块"作为变体地块的锚点
3. **侵蚀式扩张**：从锚点开始，按配置的扩展尺寸区间随机一个目标格数，只侵蚀同类地块
4. **同类地块**：基底地块本身 + 该地块的所有变体（毒瘴沼泽只能侵蚀沼泽类地块）
5. **遇阻停止**：遇到非同类地块就停止扩张

### 3.3 派生地形表配置

变体地块在派生地形表中额外配置：

```js
poison_swamp: {
  plant: [1, 3],
  ore: [0, 1],
  qualityDist: { normal: .60, good: .25, fine: .12, rare: .03 },
  spreadSize: [2, 5],  // 扩展尺寸区间（仅变体地块需要）
  fightPools: { ... }
}
```

## 四、地块表改造

### 4.1 新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `attribAffinity` | 数组 | 属性偏向，如 `['water', 'grass']`，用于指导敌人池配置 |
| `isVariant` | 布尔 | 是否变体地块（默认 false） |
| `baseTerrain` | 字符串 | 基底地块 id（仅变体地块需要） |

### 4.2 新增地块

| 地块 id | 名称 | 类型 | 植被 | 属性偏向 | 变体 | 基底 |
|---|---|---|---|---|---|---|
| `poison_swamp` | 毒瘴沼泽 | 平原 | 积毒烂泥 | ['poison', 'water', 'grass'] | true | 'swamp' |
| `volcano` | 火山 | 山地 | 火山岩 | ['fire', 'earth'] | false | null |

### 4.3 现有地块补属性偏向

微风平原现有地块全部补 `attribAffinity` 字段：

| 地块 | 属性偏向 |
|---|---|
| grassland | ['grass', 'normal'] |
| plain_forest | ['grass', 'wind'] |
| lake | ['water'] |
| river | ['water'] |
| hill | ['earth', 'normal'] |
| valley | ['earth', 'normal'] |
| plateau | ['earth', 'normal'] |

## 五、微风平原改造

### 5.1 地块级敌人池

现在敌人池是地图级别的（所有地块共享），改为**地块级**：

```js
// 现在（地图级）
fightPools: { fight_normal: {...}, fight_elite: {...}, fight_boss: {...} }

// 改为（地块级）
tilePools: {
  grassland: { fight_normal: [...], fight_elite: [...], fight_boss: [...] },
  lake: { fight_normal: [...], fight_elite: [...], fight_boss: [...] },
  hill: { fight_normal: [...], fight_elite: [...], fight_boss: [...] },
  // ...
}
```

不同地块根据属性偏向配敌人池——草原多草系，湖泊多水系，丘陵多土系。

### 5.2 驻扎行动支持

微风平原所有地块都支持驻扎行动（见§六）。

## 六、驻扎行动

### 6.1 规则

| 项目 | 说明 |
|---|---|
| 消耗 | 1 体力 |
| 触发条件 | 玩家在任意地块上，点击【驻扎】按钮 |

### 6.2 效果

| 情况 | 效果 |
|---|---|
| 地块属性偏向和精灵属性有交集 | 回复全部血量 + 全部能量 |
| 无交集 | 回复 50% 血量 + 5 点能量 |

判断逻辑：精灵的属性列表和地块 `attribAffinity` 列表，只要有一个交集就算匹配。

### 6.3 表现形式

```
点击【驻扎】
  ↓
弹出事件式弹框
  ┌─────────────────────┐
  │   精灵休息中...      │
  │  [4秒读条进度条]     │
  └─────────────────────┘
  ↓（读条完）
  ┌─────────────────────┐
  │ 你和精灵都得到了良好 │
  │ 的休息，又是活力满   │
  │ 满啦！              │
  │      [确认]         │
  └─────────────────────┘
  ↓
结算效果（回血/回能）
```

读条 4 秒，文案："精灵休息中..."，带进度条动画。

## 七、经验系统修正

### 7.1 战斗经验公式

**旧公式**：`max(5, 敌方等级 × 8)`

**新公式**：`max(5, 敌方等级 × 基础经验值) × 模板系数`

### 7.2 基础经验值（按精灵品质）

| 精灵品质 | 基础经验值 |
|---|---|
| 普通 | 10 |
| 精英 | 20 |
| 完美 | 30 |
| 传说 | 40 |

### 7.3 模板系数（按战斗模板）

| 战斗模板 | 模板系数 |
|---|---|
| 普通 | ×1.0 |
| 精英 | ×2.0 |
| 首领 | ×3.0 |

### 7.4 副本经验

副本中的每场战斗按新公式计算，结算时总经验 **×5**（额外奖励）。

### 7.5 例子

- 普通品质普通模板 15 级：15 × 10 × 1.0 = 150 经验
- 精英品质精英模板 15 级：15 × 20 × 2.0 = 600 经验
- 完美品质首领模板 15 级：15 × 30 × 3.0 = 1350 经验

## 八、验收标准

1. 静水沼泽和冒烟火山两张地图可正常进入，沙盒生成逻辑正确。
2. 变体地块（毒瘴沼泽）在后生成阶段正常落锚，侵蚀式扩张只影响同类地块。
3. 地块表新增 `attribAffinity`、`isVariant`、`baseTerrain` 字段，现有地块全部补齐。
4. 微风平原敌人池改为地块级，不同地块遇到的敌人类型符合属性偏向。
5. 驻扎行动正常触发：消耗 1 体力，按属性匹配回血回能，带 4 秒读条表现。
6. 战斗经验按新公式计算：等级 × 基础经验值 × 模板系数。
7. 副本经验结算时总经验 ×5。
