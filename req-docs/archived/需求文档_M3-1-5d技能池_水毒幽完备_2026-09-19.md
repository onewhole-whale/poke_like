# 需求文档 M3-1-5d · 技能池 · 水/毒/幽完备池

> 版本：v1.0 | 日期：2026-09-19 | 前置：M3-1-5c（草火收口 + 纯攻绝技收口）

---

## 一、需求背景与目标

5c 完成了草系收口和火系新池，本版本继续推进 **水、毒、幽** 三个属性的技能池建设，达到草系级完备度。同时引入大量新战斗引擎机制（能耗变化、读层数动态数值、能量操作、新状态等），为后续版本的技能设计打基础。

## 二、引擎新机制（先读，后续技能引用）

### 2.1 能耗下降 / 能耗增加（energyDown / energyUp）

**定义**：属性状态类型，影响技能的 energy 消耗。
- energyDown：正面状态，层数 N → 技能能耗 -N
- energyUp：负面状态，层数 N → 技能能耗 +N
- 在技能选择面板实时显示修正后的能耗
- 结算时实际扣减/增加能量
- 随回合衰减（和其他属性状态一样，每层持续回合数=层数，每回合结束-1）
- **属于属性状态**：可被驱散（物理信仰那种驱散增益/减益）、可被相关技能触发

### 2.2 读状态层数动态数值（scalingByStatus）

**定义**：技能效果读取目标身上某状态的层数，动态调整数值。
- 适用场景：动态威力、动态连击、动态减伤、动态能耗
- 配置结构示例：
  ```js
  { target: 'enemy', type: 'scalingByStatus', status: 'poison', perPower: 10 }
  // 效果：敌方每有1层poison，本技能威力+10
  ```
- 支持的动态调整项：power（威力）、hits（连击）、damageReduce（减伤%）、energyCost（能耗）
- target 可以是 self 或 enemy

### 2.3 读双方能量做条件/动态（energyScaling）

**定义**：技能效果读取双方当前能量值，做条件判断或动态数值。
- 条件示例：敌能量 < 3 → 触发效果
- 动态示例：敌每1能量 → 威力-10%
- 对比示例：我方能量 > 敌方 → 威力+50
- **能量值取双方技能结算后的剩余值**（包括本回合回能后的数值）

### 2.4 能量操作（stealEnergy / drainEnergy）

**定义**：直接操作双方能量池。
- 扣敌能量并回自己：`{ target: 'self', type: 'stealEnergy', layers: 3 }`（扣敌3，回自3）
- 纯扣敌能量：`{ target: 'enemy', type: 'drainEnergy', layers: 2 }`

### 2.5 每连击触发效果（perHit）

**定义**：连击技能的 effects 标记 `perHit: true` 时，每一段都触发 effects（默认只触发一次）。
- 目前只有毒刺使用此标记
- 其他连击技能保持默认（只触发一次）

### 2.6 移除状态按层数转效果（cleanseByCount）

**定义**：移除目标身上某状态，每移除1层，触发对应效果。
- 示例1（净化回血）：移除我方负面状态，每1层回5%血
- 示例2（瘟疫医生）：移除敌方poison，每1层回自15%血
- 示例3（反转感染）：移除敌方增益，每1层给敌方附1层poison

### 2.7 随机负面状态（randomDebuff）

**定义**：从 debuff 池随机选一个挂上。
- debuff 池包含：所有属性状态的减益方向（降攻/降防/降特攻/降特防/降速）+ 连击数下降 + 技能威力下降 + 能耗增加
- 配置：`{ target: 'enemy', type: 'randomDebuff', layers: 3, count: 1 }`
  - layers=3 表示挂3层
  - count=1 表示从池里随机选1种状态

### 2.8 新状态：问灵（wenling）

**定义**：幽系专属效果状态，有回合计数。
- 附加时计数=0
- 每回合结束计数+1
- 奇数回合（计数为奇）：回合开始时为状态所有者回1点能量
- 偶数回合（计数为偶）：回合开始时扣除状态所有者「计数」点能量
  - 即第2回合扣2点，第4回合扣4点，第6回合扣6点……
- **属于负面效果状态**

### 2.9 效果状态的正负字段

**定义**：所有效果状态（非属性状态）增加 `isDebuff` 布尔字段。
- isDebuff=true：负面效果（目前全部已有效果状态都是 true）
- isDebuff=false：正面效果（暂无，预留）
- 条件"敌方有负面效果状态"= 检查敌方身上所有 isDebuff=true 的效果状态

### 2.10 新场地：湿润场地（field_water）

**定义**：水系场地类型，持续8回合。
- 场地内水系技能伤害+50%（独立乘区，和草系场地机制一致）
- 场地内我方受到的所有伤害-10%（额外减伤乘区，和防御技能减伤加算）

## 六、草系修正

### 6.1 能量球降层

`g_energyball`（能量球）：降敌方特防从 4 层改为 **2 层**。

原因：按技能折算标尺，3 能耗（1容量）= 70威力模板，能量球80威力+降4层特防（=2条正面效果）超模。修正为降2层。

## 七、验收标准

### 7.1 引擎机制

1. **能耗变化**：使用水环后，自身技能能耗面板实时下降，战斗结算按下降后能耗扣能量；能耗增加同理。
2. **读层数动态**：泡沫浪花在自身有2层energyDown时，威力从60变为80；毒液喷射在敌方有3层poison时，威力从100变为130。
3. **能量操作**：假面恐吓使用后，敌方能量-3，自身能量+3；阴影潜行防御成功后，敌方能量-2。
4. **每连击触发**：毒刺使用后，敌方获得2层poison（两段各触发1次）。
5. **净化层数转效果**：春雨净化敌方3层负面后，自回15%血；瘟疫医生移除敌方3层poison后，自回45%血。
6. **随机debuff**：布娃娃使用后，敌方随机获得3层某种减益属性状态（每次使用随机结果可不同）。
7. **问灵状态**：笔仙使用后，第1回合结束计数=1（回1能量），第2回合结束计数=2（扣2能量），第3回合结束计数=3（回1能量）……
8. **效果状态正负字段**：所有效果状态有isDebuff字段；落井下石在敌方有负面效果状态时威力+80，只有属性减益时不触发。
9. **湿润场地**：开启后水系技能伤害+50%，我方受到伤害-10%（与防御技能减伤加算）。

### 7.2 技能池

10. 水系 13 门新技能注册进 water 属性技能池，参数正确。
11. 毒系 14 门新技能注册进 poison 属性技能池；毒系纯攻绝技从 8 门减到 3 门。
12. 幽系 13 门新技能注册进 ghost 属性技能池。
13. 草系能量球降特防从 4 层改为 2 层。
