## 1. 需求背景与目标

M3-1-1 已落地沙盒走格子（7×7 三层架构），但存在结构性缺口：

1. **采集链路断裂**：v1.16.5 清空旧采集素材后未补，`collectTile` 出货池为空；工具未实体化（`hasTool=false` 硬编码空手）。
2. **地形体系是临时结构**：TERRAIN 仅 6 种临时地形（无 类型/植被/图例 分类），产出一类字段直接挂基类，无法支撑多地图、地形连贯。
3. **地图生成无连贯性**：genSandbox 逐格独立 roll 权重随机，水域孤格、山地孤立；MAP_CONFIGS 仅 1 张图。
4. **事件体系未结构化**：事件基类仅战斗事件有雏形，冒险/奇遇事件无基类条目；事件生成用权重、gather 混入事件；敌人池在区域级（ZONES），无法按模版差异化。

本版目标：把「地形表 / 事件表（基类）→ 派生地形表 / 派生事件表（地图层）→ 实例化（沙盒）」三层体系立起来，用【微风平原】7×7 案例跑通「锚点生成 + 事件数量 + 采集闭环 + 工具」机制，为 M3-1-5（事件内容 / 技能池）、M3-1-6（冒险地图派送表 + 升级曲线）打底。

## 2. 需求详情

### 2.1 道具表与标准系列工具

**统一道具表 ITEMS**（与 M2 补丁技能石/专长石同表）：
- 本版创建道具表，**实例 = 工具**；工具本身做成**类**（`type:'tool'`），未来不同工具/道具都走这张表。
- 工具 id 编码：`DJ_none_xxxxxx`（DJ 前缀、m=`none` 普通系——用户拍板标准系列工具均为普通系、6 位数字全表全局顺序编号）。**号段冲突处理**：与 M2 补丁技能石/专长石同号段，先落地版本先编号，后落地顺延，两版不得重复占用。
- 背包可见：工具进背包，展示复用道具展示能力（matGrid 支持 DJ_ 道具，M2 补丁已定义）。

**标准系列工具（12 个）= 斧 / 镐 × 6 品质**（普通/优秀/精良/稀有/史诗/传奇）：

| 字段 | 内容 |
|---|---|
| id | `DJ_none_xxxxxx`（全局顺序） |
| name | 标准系列·斧（普通）/ 标准系列·镐（精良）…（品质 + 品类） |
| type | `'tool'`（道具大类） |
| kind | `'axe'`（斧）/ `'pick'`（镐） |
| quality / rank | 6 品质档 |
| durability | 耐久：普通 100 / 优秀 120 / 精良 140 / 稀有 160 / 史诗 180 / 传奇 200（沿用 M3-1-1 数值） |

**工具行为（用户拍板方案 B）**：
1. **持有自动生效**：玩家持有斧/镐即自动使用（取背包中最高品质工具），无手动装备 UI；无工具 = 空手。
2. **100% 出货率**：带工具采集必出货（空手 50% 出货率且仅普通）。采集概率与品质锁属于采集机制本身的规则，不算工具规则。
3. **耐久消耗**：每次采集消耗 1 点耐久，耐久归零工具损坏（从背包移除）。消耗品。
4. **获取 = 锻造（炉子新增锻造模式，用户新拍板）**：炉子与炼化模式并列新增**锻造模式**（类 Minecraft 锻造台：模板在锻造中被消耗）。锻造配方：
   - **普通品质工具**：同大类同品质素材 ×3 + 生命精华（`SC_none_fine_000001`）×1 → 对应品质工具（**不需要蓝图，初始可用**）
   - **优秀 / 精良品质工具**：对应品质**蓝图**（锻造时消耗）+ 同大类同品质素材 ×3 + 生命精华 ×1 → 对应品质工具
   - **稀有 / 史诗 / 传奇品质工具**：本版无蓝图来源 → **无获取途径**（蓝图由未来地图/模版补充掉落）
5. **替换旧框架**：删除 TOOL_TREE 48 种（8 细分 × 6 品质）数据结构，工具定义统一进 ITEMS。
6. **蓝图道具（消耗品，用户新拍板）**：`type:'blueprint'`。**用途 = 锻造材料**：锻造对应品质工具时被消耗（一次锻造消耗 1 张）；蓝图本身无「使用解锁」动作。来源 = 战斗事件**其他掉落**（§2.4 ⑤：精英 → 优秀蓝图、首领 → 精良蓝图）。蓝图 id 同表顺延 `DJ_none_` 号段（与工具、技能石/专长石全局不重复）。**本版 4 个**：标准系列·斧蓝图（优秀）、标准系列·镐蓝图（优秀）、标准系列·斧蓝图（精良）、标准系列·镐蓝图（精良）。

### 2.3 事件表（基类 + 条目）

**结构**：事件表 = **类型（基类，3 个）** + **条目（具体数据，多条）**。类型定义"这类事件的结构"，条目是具体事件数据。

**类型基类（层 0，3 个）**：

| 事件类型 | 基类定义 | 说明 |
|---|---|---|
| **fight**（战斗） | {id, kind:'fight', size:1, **难度效果定义**} | 难度效果：简单=玩家增益/敌方减益、普通=无或双方同、困难=玩家减益/敌方增益（buff side 规则）；**难度占比不在基类**（派生层定义） |

### 2.5 沙盒地图生成规则（锚点方案通用引擎）

**设计原则**：通用引擎 + 地图参数分离。引擎输入地图的生成参数，输出满格地形图；**每个地图自定义**：锚点清单 / 数量 / 随机分布 / 扩展方式 / 避让机制 / 河流长度范围 / 事件数量 / 难度占比 / 敌人池 / 背景地形。

**执行流程（微风平原）**：

```
阶段A · 地形骨架（满格）
  ① 按地图配置采样锚点（平原/水域/山地/高原锚各 1，位置全随机）
  ② 所有锚点同时向外扩展（多源波前），直至完全占满地图
     - 同一格被多个锚同时侵占时，按避让优先级判归属：平原 > 水域 > 山地 > 高原
     - 类型内部随机：平原锚扩张出的格子随机为 草原/平原森林；山地锚随机为 丘陵/山谷
  ③ 河流锚最后落（见下）
阶段B · 资源实例化（满格）：按各地形 tileMats 的 resRange 随机资源量 + qualityDist
阶段C · 冒险图（可空）：按 eventCounts 精确撒事件（位置随机）：
        战斗·普通×10 / 战斗·精英×3 / 战斗·首领×1 / 冒险×2 / 奇遇×2
阶段D · 入口与出口：玩家进入随机落点（非出口格）；出口唯一、可见、随机位置
```

**河流锚特殊逻辑（用户定稿）**：
1. **最后落**：所有地形生成完后。
2. **落点**：选择一个**边缘地块 或 高山/高原类型地块**（微风平原 = 边缘格 或 平坦高原格）。
3. **长度**：地图配置范围（微风平原 2~4 格）。
4. **延伸**：
   - 选择一个可选方向延伸；可选方向 = 4 方向中排除「与自己相连的河流区块」与「边界外」。
   - 选定方向后，判断该方向前方 3 格（正前 / 左前 / 右前），按 **水域 > 平原 > 山地 > 高原** 优先选择流向前方。
   - 3 格同类型 → 朝正前方流动；选斜向 → 方向偏转（如选右前，下个方向转为 +y 正向）。
   - 前方为**水域** → 河流生成结束（汇入）；前方为其他类型 → 该地块变为河流，继续延伸。

**事件实例化（战斗）**：
1. 触发战斗事件（按数量撒布的格）→ 从对应模版敌人池选怪。
2. 按 **difficultyDist** roll 本次难度（easy/normal/hard）。
3. 按难度从 buff 池抽 buff 定 side（难度效果见 §2.3 基类定义）。
4. **难度实例化一次并持久**：已触发过的战斗事件，即使逃离、再次进入，难度不变。

### 2.6 采集机制闭环

**12 条测试素材落库**（编码已预留 `SC_none_*_000002~000013`，v1.16.5 登记）：

| id | 名称 | type |
|---|---|---|
| SC_none_normal_000002 ~ SC_none_legend_000007 | 普通/优秀/精良/稀有/史诗/传奇 植物素材 | plant |
| SC_none_normal_000008 ~ SC_none_legend_000013 | 普通/优秀/精良/稀有/史诗/传奇 矿物素材 | ore |

**collectTile 改造**：
1. **出货判定**：有工具（最高品质）→ 100% 出货；空手 → 50% 出货率且仅普通。
2. **出货内容**：按地块 `qualityDist` roll 品质 → 按 `subDist` 植物/矿物大类 → 出对应品质 + 大类的测试素材。测试阶段不细分素材类型。
3. **工具品质锁（采集机制）**：出货品质 **> 工具品质** → 视为不在池子，直接重新算概率；空手 = 只能出普通。
4. **资源扣减**：每次出货消耗资源量 = **1 + 2×品质档**（普通 1 / 优秀 3 / 精良 5 / 稀有 7 / 史诗 9 / 传奇 11）。
5. **空手失败**：一无所获，不扣资源，只扣体力。
6. **采空变灰**：格内资源量耗尽 → `looted=true`，渲染变灰，不可再采（已落地，保留）。
7. **体力**：采集消耗 1 点（M3-1-1 已拍板）。

### 2.7 战斗实例化衔接

- 战斗 buff：BATTLE_BUFFS（10 条，id 引用）+ 难度 side 映射（M3-1-1 已落地），本版不改。
- **模版倍率修正（用户已拍板口径落地）**：首领 =「普通的妖兽头目」，倍率从现状 `×5 血量 / ×2.5 攻防` **修正为 `×4 血量 / ×2 攻防`**；精英保持 `×3 / ×1.5`；速度均不乘。掉落上限与精英持平 +1 品质、但高品概率更高（掉落机制 M3-1-3 已定，本版只修倍率）。

### 2.8 冒险入口与地图详情页（用户新拍板）

## 4. 验收标准（可观测、可断言）

**A. 道具表与工具**
- A1 ITEMS 含且仅含 12 条标准系列工具（斧/镐 × 6 品质）+ 4 条蓝图（斧/镐 × 优秀/精良），id 均 `DJ_none_` 前缀、数字段全表不重复；工具字段含 kind/quality/rank/durability。
- A2 工具持有自动生效：持斧（任意品质）后进冒险采集，出货率 = 100%（采样 ≥40 次无空手失败）。
- A3 耐久：每次采集 -1；耐久归零工具从背包移除，继续采集按空手规则。
- A4 锻造配方（可复现）：普通工具 = 同大类同品质素材 ×3 + 生命精华 ×1；优秀/精良工具 = 对应蓝图 + 同大类同品质素材 ×3 + 生命精华 ×1。
- A5 蓝图为消耗品：锻造优秀/精良工具后背包蓝图 -1（每把消耗 1 张）；无蓝图时无法锻造该品质工具；蓝图无其他「使用」入口。
- A6 TOOL_TREE 48 种旧结构删除/替换，零残留引用。

**B. 地形表**
- B1 地形表恰 18 条，每条含 type（∈ 水域/平原/山地/高原）、veg、size（=1）、icon；无 plant/ore/qualityDist/subDist 残留。
- B2 旧临时地形（mine/rock/ruin）删除，全文件零残留。

**C. 事件表**
- C1 事件类型基类 3 个（fight/adventure/wonder）；战斗基类含难度效果定义、不含模版占比。
- C2 事件条目：fight_normal / fight_elite / fight_boss 三条存在；wonder 条目 = 现有 4 条；adventure 条目结构占位（可为空池）。
- C3 事件生成按数量：生成一局后，战斗普通/精英/首领/冒险/奇遇实际数量 = 配置值（10/3/1/2/2，位置随机）。

**D. 冒险地图表与沙盒生成**
- D1 微风平原配置含 7 种地形、锚点配置、tileMats、eventConfig（eventCounts / difficultyDist 2.5:5:2.5 / fightPools）、河流长度 2~4。
- D2 生成 7×7 满格地形图（49 格无缺）；平原类（草原/平原森林）占比最高（≥40%）；湖泊/丘陵/山谷/平坦高原均至少 1 格。
- D3 地形连贯：水域（湖泊）与山地（丘陵/山谷）成片——不存在「周围 4 向全为不同类型」的孤立湖泊/丘陵单格（沿边孤格除外）。
- D4 河流：长度 2~4 格、成链；落点为边缘格或平坦高原格；末端汇入湖泊终止，未汇入则整条链为河流格。
- D5 敌人池按模版：fight_normal 池内完美品质精灵权重显著低于 fight_boss 池；单图总精灵种类 ∈ [15, 25]。

**E. 采集闭环**
- E1 12 条测试素材落库，id 与命名（品质+大类）与 §2.6 表一一对应。
- E2 带工具采集按地块 qualityDist 出货（采样统计各品质出现；普通概率最高）；空手 50% 出货率且仅普通（采样统计）。
- E3 工具品质锁：持普通斧时出货仅普通（采样 ≥60 次验证）；持精良斧时普通/优秀/精良可出现，稀有及以上不出现。
- E4 资源扣减 = 1 + 2×品质档；资源耗尽格变灰不可再采。
- E5 空手失败不扣资源只扣体力。

**F. 难度实例化**
- F1 战斗事件触发按 difficultyDist roll 难度（采样统计 3 档占比 ≈ 25/50/25）。
- F2 已触发战斗逃离后再次进入，难度不变（同一格两次进入 difficulty 一致）。

**G. 模板倍率**
- G1 applyTemplate：精英 血×3 攻防×1.5；首领 血×4 攻防×2；速度不乘。

**H. 战斗其他掉落**
- H1 精英战胜利结算额外掉落 斧/镐蓝图（优秀）其一（采样验证）；首领战掉落 斧/镐蓝图（精良）其一；普通战无蓝图掉落。
- H2 蓝图进背包可查看；可在锻造中作为材料消耗。

**I. 冒险入口与地图详情页**
- I1 冒险 tab 展示地图列表（≥1 张：微风平原，含名称/尺寸/简介），不再直接进入冒险。
- I2 点击地图弹出详情页：含地形清单（7 种）、事件配置（10/3/1/2/2）、敌人池（3 模版，含精灵名与品质概览）、extraDrops（精英/首领蓝图）。
- I3 详情页【进入】按键开始冒险：随机落点 + 出口可见（§2.5 阶段D）。
