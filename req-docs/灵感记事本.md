## 条目清单

### 1. 普通品质精灵描述全面复查 🔒
- **内容**：现有普通品质精灵的描述书写角度偏了——对这些更"近人"的精灵，应该**从精灵本身进行描写**（它的习性、性格、特质），现在更多是"其他人看到了什么"的旁观视角。可参考宝可梦的精灵介绍写法（图鉴词条聚焦精灵自身）。
- **触发时机**：正式版内容冻结后、文案工具（条目5）就绪后，批量复查重写。

### 2. 精灵专属技能 🔒
- **内容**：部分精灵可配置专属技能（仅该精灵可学的独特技能）。
- **触发时机**：跟随"精灵特性"系统版本开发（专属技能与特性配套落地）。

### 3. 精灵家族进化链打通 🔒
- **内容**：当前精灵家族（按元素/主题聚类的种族群）之间没有进化链连接，之后要打通家族内部的进化关系。
- **触发时机**：正式版精灵池稳定后（与条目8配套做）。

### 4. 开发流程规范化：区分测试环境与开发环境 🔒
- **内容**：将开发流程规范化，区分出**测试环境和开发环境**，两边不互通代码与配置文件。这样版本发布才有价值，也保证搞砸了可以直接回滚到生产版本。
- **触发时机**：正式版发布流程（M5 发布相关内容）建立时。

### 5. 文案工具（直接改文案配置） 🔒
- **内容**：等所有需要文案写的东西规范下来后，做一个**给文案 agent 用的工具**，通过工具可直接修改文案配置文件（名字/描述/故事等），不用每次通过开发转手。
- **背景**：现在不能绕过开发，是因为没有文案工具做隔离——怕文案 agent 动到代码或不该改的配置信息。工具就绪后，文案 agent 的改动范围可以被硬性限定在文案配置内。
- **触发时机**：文案规范（命名/描述/素材格式）全面定稿后。

### 6. 文案小故事 🔒
- **内容**：基于宝可梦动漫剧情结构 + 本游戏精灵设定，写精灵小故事（可支撑图鉴彩蛋、奇遇剧情、宣传物料）。
- **触发时机**：文案工具（条目5）就绪 + 精灵设定稳定后。

### 7. 测试 skill 超级账户 🔒
- **内容**：账户系统做好后，给测试 skill 增加**超级账户**功能：验收用特权账号（可绕过资源限制、快速构造验收场景），既方便验收，也避免验收过程破坏正常环境数据。
- **触发时机**：账户系统落地后。

### 8. 自然进化链全配置 🔒
- **内容**：为所有精灵尽可能配置自然进化链（贴合设定意象的进化路径），与条目3的家族打通配套。
- **触发时机**：正式版精灵池稳定后。
