## 2. 实现方案

### 2.1 代码层改动点

1. **`renderBattle`（8351）**：
   - `card.appendChild(wrap)` 后补 `const func = el('div','bt-func','')` 与 `const detail = el('div','bt-detail','')`（修复崩溃）；
   - `stCls` 重写：专属色 map 补 flinch/wenling；`kind==='stat'` 按 `/_down$/` 判减益；`kind==='attr'` 按 `def.isDebuff` 判；其余（ctrl/mech/dot 未入 map 者）→ `neutral`；
   - 立绘：新增模块级 `ELEM_ICON` 属性→emoji 表 + `elemIcon(e, fb)`，立绘框/场地精灵/队列 chip 统一使用；
   - 血条：玩家/敌方 `hp-bar` 内嵌 5 个三角刻度 span；`hpPct` 四舍五入到 1 位小数；
   - 能量：敌方 `pad(b.beastEnergy||0)+'/'+pad(b.beastEnergyMax||10)`；
   - 队列：`renderQueue()` 渲染 `.bt-queue`——敌方有 b.queue 时逐敌渲染 `.bt-q-chip`（属性 emoji + 名字），否则 "—"（我方恒 "—"）；
   - 技能卡片：两行式（主行：属性圆标+名称+克制图标；次行：类型·威力·占容；描述行），克制图标按 `typeMult(def.elem, b.beast.elem)` 判定 克制↑/正常→/抵抗↓，类型用既有 `skillBattleType(def)`，威力 `power>0?power:'-'`；文本经 `esc()` 转义。

2. **`startBattle`（7204）**：battle 对象补 `beastEnergyMax:10`；链战上下文（chainCtx.chainIdx!=null）时从 `S.wild.chainPending.enemies.slice(idx+1)` 填 `b.queue`（name 取 `SPECIES[e.speciesId].name`）。

3. **CSS（525-581 区段）**：
   - `.bt-wrap`：`grid-template-columns:190px minmax(0,1fr) 190px`，gap:12px，align-items:stretch；
   - `.bt-side`：min-height 提至 420px；`.bt-portrait` 改 flex:1 纵向居中、新增 `.bt-portrait-em`（60px）；
   - `.bt-hp .hp-bar`：position:relative、height:14px；`.bt-hp-ticks` 改为绝对定位覆盖在管子上（inset 微缩避免 0/100 裁剪），5 个三角（border-top 透明底三角）等距 25%；
   - `.bt-stage`：height 300px；`.bt-fighter` 56px；
   - 新增 `.bt-st-ic.neutral / .flinch / .wenling` 色；`.bt-queue` 支持 flex chips + `.bt-q-chip`；
   - 技能卡片：新增 `.bt-skill-main/.bt-skill-elem/.bt-skill-vs(.up/.down/.norm)/.bt-skill-desc`，保持窄宽。

### 2.2 执行流程（实现后）

进战斗 → `startBattle`（初始化 energy/beastEnergyMax/queue）→ `renderWild` → `renderBattle`（三栏布局：左展示板[立绘框内名/属性emoji/状态图标/队列] | 中间[血条+三角刻度+能量+回合数 / 300px 场地 / 功能栏 / 详情栏] | 右展示板[镜像]）→ 点技能卡 → `battleSkill`（逻辑不动）。

## 3. 验收标准（§二 12 项中 1-7，逐条可观测）

1. 进战斗不再报错，三栏布局完整渲染（左右展示板、顶部血条+回合数、中间场地、功能栏+详情栏）；
2. 2.1 我方名字在立绘框内左上角、敌方在右上角；立绘为按属性的 emoji 占位（火🔥/水💧/草🌿…）；
3. 2.2 血条线性精确（70.0% 血 = 70% 长度）；管子上有 0/25/50/75/100 五个三角刻度；我方空在右、敌方空在左；
4. 2.3 能量在血条下方靠近展示板侧，蓝色 `XX/YY` 补零：我方 `05/10`、敌方 `05/10`（不再 /20）；
5. 2.4 状态栏只放图标不放名字；初始为空；不同属性不同图标+颜色；属性下降/能耗上升为红色减益、属性上升为绿色增益、dot/ctrl/mech 为效果状态其他色；右下角白色层数角标；
6. 2.5 队列栏在状态栏下方：我方留空 "—"；事件链车轮战时敌方显示剩余敌人（emoji+名）；
7. 2.6 技能卡片窄宽缩小；卡片含 名称/属性/类型/威力（攻击显示数值、非攻击"-"）/描述/克制图标（克制↑/正常→/抵抗↓）；选中高亮、冷却灰化沿用；
8. 2.7 战斗场地放大：中间列占主要宽度（≈1fr），场地高 300px，两侧展示板随列拉伸。
