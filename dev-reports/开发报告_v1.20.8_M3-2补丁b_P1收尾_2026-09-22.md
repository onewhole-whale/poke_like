- **日期**：2026-09-22

## 1. 变更点

### A 组 · 战斗演出收尾
- **A1 出招名片**：技能释放时在战斗场地中央浮现"技能名+克制图标"（我方右箭头、敌方左箭头），0.6s 后淡出。在 battleSkill/dgBattleSkill 结算后，按 lastCaster/lastSkill 信息在 stage 上浮层渲染。
- **A2 血条 hover 数值**：我方 .hp-bar 加 title="当前/上限"；敌方不加。
- **A3 日志最新在上**：showLog 渲染时 b.log.slice().reverse() 倒序；v1.20.7 R1 的 unshift warn 开场日志逻辑保留（最新仍在最上，自然落在倒序顶）。
- **A4 展示板血量数字**：左右展示板状态栏补 spHp/spMax 数字（常驻）。
- **A5 动画接线**：CSS 类已备，JS 接线——命中后攻击方 .lunge-left/right 0.3s、受击方 .hit 0.2s、伤害飘字 .bt-dmg-num 0.8s、按技能属性出粒子（canvas）、新状态图标 popIn。纯代码，总时长 ≤1.5s。

### B 组 · 战斗 UI 通用化
- **B1 通用渲染引擎**：renderBattle 改为接受 opts={battle, sp, ctx:{source, defOf, usableOf, onSkill, onResult}}；野外/副本共用同一套 UI。副本 renderSettle 战斗段废弃 bp- 旧布局（501-504 CSS 保留不删但不再用），改调 renderBattle。
- **B2 副本能耗 effEnergy**：dgPlayerTurn 4082-4083 改 effEnergy 口径（含 energyUp 加耗/energyDown 减耗/costdown 减耗）；dgSkillUsable 3918 同步。
- **B3 副本敌方能量 X/10**：renderBattle 已用 beastEnergyMax||10，副本 startDgFight 补 beastEnergyMax:10（与引擎 beastEnergyMax:10 一致）。

### C 组 · 功能补齐
- **C1 普通战斗逃跑**：showFlee 战斗中点逃跑 → 退回上一格、事件格保留不 resolved、无奖励。与 boss 逃跑行为一致。
- **C2 背包 UI 框架**：showBag 从占位改为真实列表（toolInv 读取）、空态提示、道具使用按钮置灰标"功能筹备中"。
- **C3 素材品质解锁**：upMatFor 实现——按 matId 的 elem+type+tags 在 MATS 找 bump 档同型素材（normal→good→fine→rare→epic→legend），找不到返回原 id。击杀结算 7048 改为"基础保留 + 额外加升级素材"（不替换）。
- **C4 事件链 check 读实际属性**：eventStatPanel 改为取 wildSpirit() 对应 stat 的实际面板值（spe/atk/def/spa/sdef/hp），不再用种族公式理论面板；lvlRef 口径保留。

## 2. 执行流程
- B1：renderSettle 战斗段 → renderBattle({battle:b, sp, ctx}) → 技能按钮调 ctx.onSkill → 结束调 ctx.onResult。
- A5：battleSkill 结算后 → stage 上 append 动画层（lunge/hit/dmg/particle）→ setTimeout 清理。
