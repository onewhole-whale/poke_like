# 开发报告 v1.20.7 · 产品验收跑偏项修复

- **版本**：v1.20.7（基线 v1.20.6）
- **日期**：2026-09-21
- **版本目标**：修复产品验收发现的 3 个跑偏项（R1 P1 / R2 P2 / R3 P2）。
- **本次来源**：产品验收（v1.20.5 功能 17/17+2 通过）。

## 1. 变更点

### R1（P1）安抚失败 ambushText 接线到战斗开场日志
- **现状**：`renderWildNode` 安抚失败分支（index.html:6788）设 `node.ambushText='安抚失败了！...'` 后调 `startBattle(...)`，但 `startBattle` 不读该字段，文案被丢弃，玩家看不到"安抚失败"提示直接进战斗。
- **改法**：安抚失败分支 `startBattle` 后，把 ambushText 作为第一条日志 unshift 到 `S.wild.battle.log`（who:'warn'），再 `renderWild()` 重渲染。日志出现在战斗日志最前，玩家能看到"安抚失败 → 进战斗"的因果。

### R2（P2）妖兽技能栏限高适配
- **现状**：`.bt-detail{max-height:240px}`（CSS 581 行），妖兽满级 14 门直接攻击 + 回能 = 15 卡，三列网格 5 行，溢出需滚动。
- **改法**：`renderBattle` 中 `sp.isBeast` 时给 detail 元素 inline `style.maxHeight='520px'`（放宽到可容纳 15 卡 + 头部），灵兽出战保持 240px 不变。不改解锁曲线、不改技能数。

### R3（P2）五选项分组视觉 + 两处文案
- **现状**：五选项平铺（正面安抚/正面战斗/悄悄离开/悄悄安抚/悄悄突袭），无视觉分组。
- **改法**：
  1. 分组视觉：选项分两组——「正面接触」（安抚/战斗）与「悄悄行动」（离开/安抚/突袭），组间加分隔标题。
  2. 文案微调：
     - 正面·战斗：`正面战斗，谁快谁先出手` → `正面对峙，按速度决定谁先手`
     - 悄悄·离开：`什么也不得到，直接离开` → `不发生战斗，本格标记为已探索`

## 2. 执行流程

- R1：点安抚失败 → roll 失败 → startBattle → unshift warn log → renderBattle 显示开场日志。
- R2：妖兽出战进战斗 → detail maxHeight=520 → 15 卡一屏可见无滚动。
- R3：遇非 boss 非被突袭妖兽 → renderWildNode 渲染两组（正面/悄悄）+ 新文案。

## 3. 验收标准（对应验收结论）

1. 安抚失败进入战斗后，战斗日志第一条显示"安抚失败了！X 警觉地亮出爪牙"（who=warn 样式）。
2. 妖兽出战（满级 14 技能）技能栏一屏可见，无需滚动；灵兽出战限高仍 240px。
3. 五选项卡分组显示「正面接触」「悄悄行动」两组；正面·战斗/悄悄·离开文案如上。
4. 回归：damage/wild/mech/v1192/v1195 全绿。

- CDP 冒烟：安抚失败 log 首条、妖兽技能卡数、五选项分组渲染；
