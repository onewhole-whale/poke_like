# 开发报告 v1.12.0 — 战斗机制补全（先制/命中/蓄力/混乱/连舞/力竭）

日期：2026-09-15　基线：v1.11.0（宝可梦式伤害公式）　类型：完整版本开发

## 1. 版本目标

解决测试 agent 报告的历史遗留：8 门草系技能「desc 承诺了机制，但 effects 为空 / 引擎无对应系统」。本次在战斗引擎中立项实现缺失机制，并把 desc 承诺的机制挂载到技能上，使 **desc 与实现一致**。

**变更点清单（类型打标）**：

| # | 变更点 | 类型 |
| --- | --- | --- |
| 1 | 先制 priority：技能可携带「本回合无视速度优先出手」 | 战斗机制（引擎） |
| 2 | 命中 accuracy：技能可携带命中率（<100 可能落空；100 必中） | 战斗机制（引擎） |
| 3 | 蓄力 charge：释放回合不攻击，下一回合自动发射 | 战斗机制（引擎） |
| 4 | 混乱 confusion：新控制状态（行动时 50% 自伤，层数=持续回合） | 战斗机制（状态系统） |
| 5 | 连舞 multilock：连续 N 个额外回合强制使用本技能，结束后附加结束效果 | 战斗机制（引擎） |
| 6 | 力竭 recharge：释放后下一回合无法行动 | 战斗机制（引擎） |
| 7 | 青草滑梯 → 场地内先制；魔法叶 → 必中；日光束/日光刃 → 蓄力；花瓣舞 → 连舞+舞停混乱；疯狂植物 → 力竭；叶绿爆震 → 反震 33；茁茁炸弹 → 寄生 3 层 | 技能数据（挂载 effects） |
| 8 | parasitic 状态改为每回合 −1 层衰减（连带：寄生种子 2 层 = 2 回合） | 状态系统（连带调整） |
| 9 | statusText / initStatus / cleanse 同步 confusion 状态 | UI / 状态系统 |

**不在本次范围**：打草结 / 草之誓约（desc 已自声明【待配套系统解锁】，体重/联动系统用户已拍板暂不做，占位声明保持）。

## 2. 实现方案

### 2.1 状态与效果定义（SKILL_STATUS，4233 起）

新增 5 个 mech 效果 + 1 个 ctrl 状态：

```js
/* mech 区追加 */
priority: {name:'先制',   kind:'mech', defLayers:1, target:'self', desc:'本回合无视速度优先出手（可带场地条件 cond）'},
accuracy: {name:'命中率', kind:'mech', defLayers:100,target:'enemy', desc:'本技能命中率 = X%（<100 可能落空；100 必中）'},
charge:   {name:'蓄力',   kind:'mech', defLayers:1, target:'self', desc:'本回合蓄力不攻击，下一回合自动发射'},
multilock:{name:'连舞',   kind:'mech', defLayers:2, target:'self', desc:'连续 N 个额外回合强制使用本技能，结束后附加 endEffects'},
recharge: {name:'力竭',   kind:'mech', defLayers:1, target:'self', desc:'释放后下一回合无法行动'},
/* ctrl 区追加 */
confusion:{name:'混乱', layers:1, cap:10, target:'self', kind:'ctrl', desc:'存在即生效：行动时 50% 概率攻击自己（无属性 40 威力）；层数 = 持续回合数，每回合 −1'},
```

### 2.2 状态系统联动

- `initStatus()`（4304）：返回值加 `confusion:0`。
- `statusText()`（4286）：加 `混乱X回合`。
- `cleanse`（4387）：负面清理列表加 `'confusion'`。
- `tickStatus()`（4470）：混乱每回合 −1；**parasitic 每回合 −1**（连带调整，见 §6）。
- `canAct()`（4532）：**不检查混乱**（混乱仍能行动，只是可能自伤）。

### 2.3 战斗引擎（野外 + 秘境对称改造）

**先制**（battleSkill 3701/4611 的 order 计算处）：
```js
const prioEf = skillEffectsOf(sk).find(ef=>ef.type==='priority');
let prio = false;
if(prioEf){
  if(prioEf.cond==='field_grass') prio = !!(b.field && b.field.elem==='grass');
  else prio = true;
}
const order = prio ? ['player','beast'] : (b.first==='player' ? ['player','beast'] : ['beast','player']);
```

**命中**（playerTurn/dgPlayerTurn，能量结算后、分段伤害前）：
```js
const accEf = efList.find(ef=>ef.type==='accuracy');
if(accEf && (accEf.layers||100) < 100 && Math.random()*100 >= (accEf.layers||100)){
  b.log.push({...落空日志...});
  return;   // 不结算伤害、不附加效果（能量照扣，与麻痹失败区分）
}
```

**混乱自伤**（playerTurn/dgPlayerTurn/beastTurn/dgBeastTurn，麻痹判定之后）：
```js
if(st.confusion>0 && Math.random()<.5){
  const d = Math.max(1, calcDamage(己方攻, 己方Lv, 己方防, 己方Lv, 40, {}, 'none', 'none'));
  // 扣血 + 日志「陷入混乱，攻击了自己」；玩家侧 hp≤0 → lost，敌方侧 hp≤0 → markWin
  return;   // 自伤替换本回合行动
}
```

**蓄力 charge**（playerTurn/dgPlayerTurn）：
```js
const chargeEf = efList.find(ef=>ef.type==='charge');
if(chargeEf && !chargeFire){
  b.charge = {side:'self', skId:sk.id, sk:sk};
  b.log.push({...蓄力中，下一回合发射...});
  return;   // 本回合不结算
}
if(chargeFire) b.charge = null;
```
- battleSkill/dgBattleSkill 入口（round++ 前）：`if(b.charge && b.charge.side==='self')` → 强制发射蓄力技（chargeFire 模式，忽略玩家本次点击），发射回合不再扣能量。
- 蓄力中若睡眠/畏缩无法行动，蓄力状态保留到可行动回合再发射。

**连舞 multilock**（playerTurn/dgPlayerTurn）：
```js
const mlEf = efList.find(ef=>ef.type==='multilock');
if(mlEf && !locked) b.lock = {side:'self', skId:sk.id, sk:sk, remain:Math.max(1,mlEf.layers||1), endEffects:mlEf.endEffects||[]};
```
- battleSkill/dgBattleSkill 入口：`if(b.lock && b.lock.side==='self')` → 强制连打锁定技（locked 模式：不扣能量、不重新写 lock），`remain--`；归零时附加 `endEffects`（混乱）并清 lock。
- 能量结算改为 `if(!locked){ burst 清空 / ult·direct 扣能 }`（锁定连打期间不再清空能量）。

**力竭 recharge**（applyMechEffect 新增 case + 行动阻挡）：
```js
case 'recharge': { b.recharge = {side: ef.target==='self'?'self':'enemy', pending:Math.max(1,ef.layers||1)}; break; }
```
- recharge 不进 preMech 白名单（不阻断伤害），由 applySkillEffects 后置执行（伤害结算后标记）。
- order 循环 player 分支：`if(b.recharge && b.recharge.side==='self')` → 日志「力竭无法行动」+ 清状态（敌方照常行动）。

## 3. 执行流程

- **先制**：玩家点技能 → battleSkill 读取 skillEffectsOf 的 priority → cond 满足（青草滑梯需 `b.field.elem==='grass'`）→ order 强制玩家先 → 玩家行动 → 敌方行动。
- **命中**：点技能 → 能量扣减 → accuracy 判定（<100 且随机命中失败）→ 落空日志 + 本回合无伤害无效果。
- **蓄力**：释放日光束（burst：能量≥5 触发 → 清空能量）→ 写 b.charge + 蓄力日志，本回合不结算 → 下一回合 battleSkill 入口发现 b.charge → 强制发射（chargeFire：跳能量结算、正常打伤害）→ 清 b.charge。
- **混乱**：花瓣舞第 3 回合末附加混乱 3 层（self）→ 后续每回合行动时 50% 概率自伤（40 威力无属性物理，打自己防御）→ tickStatus 每回合 −1 层 → 归零解除。
- **力竭**：释放疯狂植物（清空能量 + 150 威力伤害）→ 后置效果写 b.recharge → 下一回合该精灵行动被替换为「力竭」日志 → 清状态 → 再下一回合恢复。
- **寄生衰减**：茁茁炸弹命中 → 敌方 parasitic +3 层 → 每回合末先结算 9% 流失+回血，再 −1 层 → 3 回合后消失。

## 4. 验收标准（可观测断言，测试 agent 直接输入）

1. **先制**：给玩家装配青草滑梯 + 开青草场地，玩家速度 < 敌方，`battleSkill('g_grassyglide')` 后 battle log 先出现玩家行动；未开场地时同速度关系则敌方先手。
2. **命中**：`skillEffectsOf` 对魔法叶返回 `accuracy:100`；构造 accuracy:60 的技能时存在落空分支（日志含「落空」且敌方不掉血）。
3. **蓄力**：使用日光束当回合敌方 HP 不变、日志含「蓄力」；下一回合（再次点击任意技能）自动发射、敌方 HP 下降、日志含「发射」。
4. **混乱**：花瓣舞释放后连续 3 回合强制使用花瓣舞（期间玩家点击其他技能无效）；第 3 回合后 `spSt.confusion===3`；后续回合有 50% 自伤分支（日志含「攻击了自己」），且混乱每回合 −1。
5. **力竭**：疯狂植物命中后当回合敌方掉血；下一回合玩家行动被替换为「力竭」日志（本回合我方无伤害）；再下一回合恢复行动。
6. **反震**：叶绿爆震命中后我方 HP 下降（自伤 33%）。
7. **寄生**：茁茁炸弹命中后敌方 `parasitic===3`，每回合末流失 9% 并回复我方；3 回合后 `parasitic===0`。
8. **状态栏**：`initStatus()` 含 confusion:0；`statusText` 对混乱显示「混乱X回合」；cleanse 可清除混乱。
9. **回归**：既有 17 套测试全绿（reg_cdp 77/77、status_sys、stats_test、m1_check 等战斗相关套件）。

## 6. 连带调整 / 待确认

- **parasitic 衰减（连带）**：为使茁茁炸弹 desc「持续 3 回合」落地，parasitic 状态改为每回合 −1 层。**后果：寄生种子（2 层）从永续变为 2 回合**（每回合 6% 流失+回血，总计 12%）。理由：永续 6%/回合 dot 在长战斗过强，且与「层数=持续回合」语义统一。若你希望寄生种子保持永续，请告知，茁茁炸弹改用独立限时效果。
- **混乱自伤不吃状态修正**：混乱自伤用面板攻防（不含 buff/debuff 修正），与宝可梦原版略异，原型从简。
- **千变万花**：desc 亦承诺「必定命中」，但不在本次点名范围；当前引擎默认全命中，其行为已符合 desc，未额外挂载（遗留观察点）。
- **妖兽侧**：妖兽技能池无机制技，蓄力/连舞/先制仅玩家侧生效；混乱自伤妖兽侧已支持（未来毒系等可用）。
