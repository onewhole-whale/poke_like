## 1. 版本目标

将伤害公式从**崩铁式**（防御系数仅随等级、`def` 参数完全未参与）切换为**宝可梦式**，激活整套防御体系（防御/特防种族值、防御个体值、防御性格、防御专长、降防状态全部从"空转"变为生效）。同时落地用户拍板的三个定制：本系加成 ×1.25、随机浮动 0.85~1.0、破甲保留易伤逻辑。

**变更点清单（按类型打标）**：

| # | 类型 | 变更点 |
|---|---|---|
| 1 | 战斗机制 | `calcDamage` 重写：宝可梦原式基础伤害 + 随机浮动 0.85~1.0 + 本系 1.25（mods.stab） |
| 2 | 数值 | `spiritStats` 属性换算改宝可梦式（去 ×6 放大） |
| 3 | 数值 | `ivContribution` 去 ×6（20 点 iv 满级 +20 属性而非 +120） |
| 4 | 数值 | `dungeonBeast` / `wildBeast` 敌人数值换算同步宝可梦式 |
| 5 | 战斗机制 | 本系加成注入 6 处调用点（玩家 2 处 + 敌人 2 处 + 额外回合 2 处） |
| 6 | 测试 | `tests/iv_test.js` 3 处断言、`tests/reg_cdp.js` 2 处断言按新公式同步 |

**不动的部分**：mods 各乘区（dmgUp/critDmg/dmgDown/vuln/resist/pen/fieldMul）、typeMult 克制表、状态系统（dot 为 %maxHp）、斩杀/治愈/破甲等机制（百分比）、等级经验 lvl³、技能威力模板（40 无代价 +20/代价，威力在宝可梦公式中仍线性）。

## 2. 实现方案（函数级）

### 2.1 `calcDamage` 重写

```js
function calcDamage(atk, aLvl, def, dLvl, power, mods, atkElem, defElem){
  mods = mods||{};
  // 宝可梦式基础伤害：(2L/5+2) × power × A/D / 50，再 +2（宝可梦原式）
  // 注意：def 参数真正参与（A/D 比值）；dLvl 不再直接出现（等级只通过防御数值间接体现）
  const lvlTerm = Math.floor(2*aLvl/5 + 2);
  let dmg = Math.floor(Math.floor(lvlTerm * power * atk / Math.max(1,def) / 50) + 2);
  // 修正乘区（保留全部现有战斗机制）
  dmg = dmg * (1+(mods.dmgUp||0)) * (1+(mods.critDmg||0)) * (1-(mods.dmgDown||0)) *
    (1+(mods.vuln||0)) * (1-((mods.resist||0)-(mods.pen||0)));
  if(mods.fieldMul) dmg *= (1+mods.fieldMul);   // 场地：本系技能伤害独立乘区（+50%）
  dmg *= typeMult(atkElem, defElem);            // 属性克制 ×2 / 抵抗 ×0.5
  if(mods.stab) dmg *= mods.stab;               // 本系加成 1.25（调用方注入）
  dmg *= 0.85 + Math.random()*0.15;             // 随机浮动 0.85~1.0（宝可梦原式，影响最终伤害）
  return Math.max(1, Math.round(dmg));
}
```

**关键行为差异（旧→新）**：
- def 从"传入即丢弃"变为真正参与（A/D 比值）→ 防御数值、降防状态生效
- 移除旧 `defMul = (aLvl+20)/((aLvl+20)+(dLvl+20))`（等级差防御系数）→ dLvl 参数保留但不再使用（调用点签名不改）
- 新增随机 0.85~1.0 与本系乘区

### 2.2 `ivContribution` 去 ×6

```js
function ivContribution(iv, k, lvl){
  const v = (iv && iv[k]) || 0;
  if(!v) return 0;
  return Math.round(v*2*lvl/100);   // 宝可梦式：每点 iv = 2×lvl/100 面板值（去 ×6）
}
```

## 3. 执行流程（实现后调用链）

```
玩家出招（playerTurn/dgPlayerTurn）
  → mods 初始化（含 stab = 本系?1.25:1）
  → 前置机制（execute/sunder/surge/heal...）→ sunder 设 beastBuffs.vuln
  → statusMods 攻防乘算（def_down 在此生效：降防 → defSide 变小）
  → calcDamage(A, aLvl, D, dLvl, power, mods, sk.elem, defElem)
      → lvlTerm = floor(2L/5+2) → 基础 = floor(lvlTerm×power×A/D/50)+2
      → × 各 mods 乘区 → × typeMult 克制 → × stab 本系 → × 随机0.85~1
  → 多段循环累加 → 吸血/反震按实际伤害结算（drain/recoil）
敌人出招（beastTurn/dgBeastTurn）：同链，妖兽池技能恒本系 stab=1.25
```

## 4. 验收标准（测试 agent 直接断言）

1. **def 真正参与**：`calcDamage(300,30,1,30,60,{}) > calcDamage(300,30,100,30,60,{}) > calcDamage(300,30,9999,30,60,{})`（旧公式三者相等）
2. **防御系数不再只随等级**：同等级仅改 def → 伤害明显变化；def 翻倍 → 伤害约减半（A/D 比值）
3. **等级项**：`calcDamage(300,60,100,60,60,{}) > calcDamage(300,30,100,30,60,{})`（等级项 (2L/5+2) 随等级提升；同等级 Lv1/Lv30/Lv60 依次增大）
4. **本系加成**：`calcDamage(300,30,100,30,60,{},'fire','water') * 1.25 ≈ calcDamage(300,30,100,30,60,{stab:1.25},'fire','water')`（mods.stab=1.25 时伤害 ×1.25）
5. **随机浮动**：同一输入调用 N 次，伤害在 [基准×0.85, 基准×1.0] 内波动且不全相等（round 后至少 2 个不同值）
6. **降防生效（核心回归点）**：敌方 def_down 6 层（defSide ×0.4）→ 伤害比无降防时显著提升（约 ×2.2~2.5，受随机与 floor 影响）；sunder 破甲（vuln 0.2）→ 本回合伤害 ×1.2 仍生效
7. **属性换算**：满级 60、种族 100 → hp=190（floor(2×100×60/100)+60+10）、atk=125（floor(120)+5）；个体值 20 点 Lv30 → +12 面板（ivContribution 断言）
8. **敌人同步**：wildBeast / dungeonBeast 数值按宝可梦式生成（hp = mk+等级+10，不再 ×6 量级）
9. **战斗全流程**：野外/副本战斗可正常走完（无 NaN、无死循环），伤害、dot、吸血、斩杀、回血、升级回满血全链路正常
10. **回归**：14 套测试全绿（iv_test/reg_cdp 断言已同步更新）
