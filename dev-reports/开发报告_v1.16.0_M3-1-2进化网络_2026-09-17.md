### 2.4 进化边重构为 evoToBranches（§4.3 全表 130 条）

所有现有+新精灵的 evoTo/evoCond 改为 evoToBranches：
- 主线/分支（同属性）：lvl + aff（本系）+ mat（本系词条+品质）
- 异变（跨属性）：lvl + aff（目标系）+ mat（目标系词条+品质）+ 24 条跨偏向边加 stat

### 2.5 新增 mat 条件类型

`evoCondOk` 加分支：
```
else if(c.type==='mat'){
  // c.elem: 元素；c.v: 单位需求；c.qRank: 品质门槛（0=normal+）
  // 统计 matState 中 elem==c.elem 且 qualityRank>=c.qRank 的素材 unitOf 总量
  const total = Object.keys(matState).reduce((s,id)=>{
    if((matState[id]||0)<=0) return s;
    const m = matInfo(id); if(!m || m.elem!==c.elem) return s;
    if((QUALITY_RANK[m.quality]||0) < (c.qRank||0)) return s;
    return s + matState[id]*unitOf(m);
  },0);
  if(total < (c.v||0)) return false;
}
```

进化结算时（evolveSpirit）扣除对应素材：从 elem==c.elem 的库存里按品质从低到高扣 unit 单位。

### 2.6 清空专属技能池（§5.4）

所有 SPECIES 条目不加 `skills` 字段（原本就没有显式 skills 数组，只有 fallback 逻辑）。确认现有 SPECIES 无 species.skills 配置——已检查，现有物种均无 skills 字段，fallback `sp.skills[0]||SKILLS[sp.elem][0]` 已覆盖。新精灵同样不填 skills。

### 2.7 图鉴占位（§5.5）

图鉴遍历 SPECIES 自动收录新精灵，desc 留空字符串。无需额外代码。
