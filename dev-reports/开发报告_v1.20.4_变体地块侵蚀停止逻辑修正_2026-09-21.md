# 开发报告 v1.20.4 · 变体地块侵蚀停止逻辑修正

- **版本**：v1.20.4（基线 v1.20.3）
- **日期**：2026-09-21
- **版本目标**：按《需求文档_补丁_变体地块侵蚀逻辑修正_2026-09-21.md》修正变体地块侵蚀停止逻辑——去掉"遇到非同类就停止"，改为**到达侵蚀上限或所有相邻地块都没有同类地块了才停止**。
- **本次来源**：产品验收

## 1. 变更点

### 1.1 侵蚀停止逻辑修正（需求文档 §二）
- **现状问题**：`genSandbox` 变体地块侵蚀（阶段A④）用 BFS 洪水填充，只在**同类连通区**内侵蚀。被非同类地块（grassland/lake）隔开的同类碎片永远不会被侵蚀——即"遇到非同类就停止"的行为表现（需求文档错误实现）。
- **修正**：改为「洪水填充 + 跳岛」：
  1. 先从锚点洪水填充同类连通区（非同类方向跳过不停止，其他方向继续找同类）；
  2. 连通区耗尽且未达上限时，**跳岛**：从全图随机找未被侵蚀的同类基底格作新源点（绕过非同类地块，继续侵蚀其他方向的同类地块）；
  3. **停止条件** = ① 到达 `spreadSize` 侵蚀上限，或 ② 全图已无同类基底可侵蚀（此时所有变体地块的相邻地块中已无同类）。
- 同一段代码同时满足需求文档 §三 两条验收：非同类不阻断侵蚀（跨碎片继续）；只有达上限或无同类才停止。

### 1.2 附带修复：无 river 配置地图生成崩溃（阻塞验收）
- **现状问题**：`genSandbox` 阶段A③ 无条件读 `cfg.anchors.river.len`，而 **stillswamp（唯一含变体毒瘴沼泽的地图）的 anchors 没有 river 键** → 生成直接 TypeError 崩溃，毒瘴沼泽地图根本无法生成，变体侵蚀逻辑无法落地验收。
- **修正**：`if(riverCfg && riverCfg.len)` 守卫，无河流配置的地图跳过河流生成（仍保留湖泊锚）。gentlebreeze 等有 river 配置的地图行为不变（实测河流 3 格正常）。

## 2. 执行流程

`genSandbox` 阶段A④：`if(cfg.variants)` → 每变体：找基底格 → 随机锚点 → `cells[anchor]=v.id` → **洪水填充同类连通区（非同类跳过不停止）→ 耗尽且未达上限 → 跳岛全图随机同类基底格作新源 → 循环** → 停止 = 达 `targetN` 或全图无同类基底。阶段A③ 河流锚：无 `anchors.river` 配置直接跳过。

## 3. 验收标准（引用需求文档 §三 + 实现侧）

1. 变体地块侵蚀时，遇到非同类地块不会立即停止，会继续在其他方向找同类地块（跨碎片跳岛）；✅
2. 只有达到侵蚀上限，或所有相邻地块都没有同类地块了，才停止侵蚀；✅
3. 毒瘴沼泽（stillswamp）地图可正常生成（此前 river 崩溃）；✅
4. 有 river 配置的地图（gentlebreeze）河流生成不受影响；✅
5. 既有地图/战斗逻辑零回归。

## 4. 验证方式

- 语法：提取 `<script>` → `node --check`；
- 确定性构造复刻（四场景）：跳岛跨碎片 / 全图无同类停止 / 达上限停止 / 连通大碎片洪水填充；
- 真实页面：`genSandbox('stillswamp')` ×40 统计毒瘴分布 + `genSandbox('gentlebreeze')` 河流检查；
- 回归：v1195 / wild / mech / damage。
