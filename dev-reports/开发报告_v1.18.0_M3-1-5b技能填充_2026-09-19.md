# 开发报告 v1.18.0 · M3-1-5b 技能填充（10 属性样板技能 + 战斗引擎机制升级）

- **日期**：2026-09-19
- **来源**：需求文档 `req-docs/需求文档_M3-1-5b技能填充_2026-09-19.md`（v1.1）
- **版本号**：v1.18.0（当前最新 v1.17.1 +1）
- **变更类型**：技能数据 / 战斗机制 / UI（技能编辑器效果类型支持）/ 存档兼容

## 1. 版本目标

为 10 个属性（雷/冰/土/暗/灵/普/风/光/武/钢）各配 4 门样板绝技 = 40 门技能，让"属性=打法风格"；同时把支撑这些技能的战斗引擎机制一次做完（天气/先制度数值化/4 新状态/20 新效果/3 规则修正），M3-1-5c 只填内容不再动引擎。草系 56 门 + 回能技能迁移到新结构，删旧兼容逻辑，全游戏走一套引擎。

**变更点清单**：
1. 技能数据：40 门样板技能落池（进副本抽取范围）
2. 新状态：leech / combo / costdown / powerup 入 SKILL_STATUS
3. 新效果：20 个效果类型入 applyMechEffect / effects 体系
4. 天气系统：b.weather 字段，与 field 并行，雪天 5 回合
5. 先制度数值化：priority 布尔→整数（可负），宝可梦式双方预选后排序
6. 规则修正：冻结删受击解除 / 冰草雷免疫对应状态 / 增减状态 cap:6 移除
7. 状态栏分账：buff 分 normal/weather 状态栏，净化驱散不碰 weather
8. 草系迁移：回能/种子弹/藤绞/青草滑梯迁 effects，删 mechToEffects
9. UI：技能编辑器支持新效果类型与先制度数值显示

## 2. 实现方案

### 2.1 40 门技能数据（落 ULT_DEFS / GLOBAL_SKILL_POOL）

按需求 §2.9 全表落。每属性 4 门，全部 `kind:'ult'`。`energy` 默认 = `cost`。字段映射：
- 物理攻击：`track:'phys'`, `type:'攻击'`
- 特殊攻击：`track:'spec'`, `type:'攻击'`
- 状态：无 power/hits，`type:'状态'`
- 防御：guard + 条件效果，`type:'防御'`

技能 id 用需求建议短英文（th_emwave / ic_freeze / ea_bastion / da_thirst / ps_meditate / nr_armor / wi_tailwind / li_rainbow / fi_stop / st_mind 等）。

**注册**：新技能 push 进 `SKILLS[elem]` + `GLOBAL_SKILL_POOL[elem]`（对应属性键），进副本技能抽取范围。

### 2.2 4 个新状态（入 SKILL_STATUS）

```js
leech:   {name:'吸血', kind:'attr', layers:10, target:'self', desc:'每层=攻击回血 10%（与 drain 加算）'},
combo:   {name:'连击数', kind:'attr', layers:1,  target:'self', desc:'每层=连击技能 hits+1'},
costdown:{name:'费用降低', kind:'attr', layers:1, target:'self', desc:'每层=技能 cost −1（能耗 −1，下限 0）'},
powerup: {name:'技能威力', kind:'attr', layers:10, target:'self', desc:'每层=面板技能威力 +10'},
```

- `kind:'attr'`：我方属性增益，持有时对我方所有技能生效。
- **leech**：我方攻击造成伤害后，回 `dmg × 10% × leech层数`（与 drain 同基数加算）。
- **combo**：只对"连击技能"生效——临时标识 = `hits > 1`（除光系万花筒 varietyHits 外，现有连击技能都 hits>1）。连击技能 hits 叠加 = `sk.hits + combo层数`。
- **costdown**：释放时能量消耗 `max(0, sk.energy − costdown层数)`。
- **powerup**：面板威力 `powerBase += powerup层数 × 10`。

### 2.3 20 个新效果类型（入 applyMechEffect switch / effects 体系）

| 效果 | 实现位置 | 语义 |
|---|---|---|
| speedRatio | playerTurn/dgPlayerTurn 伤害前 | 倍率=clamp(⌊我方面板速度÷敌方面板速度⌋,1,5)，乘在 calcDamage 前；敌方麻痹(-50%)为独立乘区最后应用 |
| defRatio | 同上 | 同上，用物防 |
| freezeCountHeal | 释放时 | 回血 = 5% × 敌方当前 freeze 层数 |
| condCooldown | 回合末/释放时 | 敌方本回合用了攻击技能 → 我方防御技能 cooldown −1 |
| condBuff | 释放时 | 条件满足 → 给 self 加配置 buff 类型+层数 |
| condCombo | 释放时 | 条件满足 → 连击技能 hits+N（叠加在 combo 外） |
| condPower | 释放时 | 条件满足 → 本次威力+N（临时，不入 powerBase） |
| missingHpPower | 伤害前 | 每损失 10% 血 → 威力+15 |
| randomBuff | 释放时 | 从 [atk_up,spa_up,def_up,sdef_up,spd_up,leech,combo,costdown] 每层独立随机，共 N 层 |
| pierceGuard | 伤害结算时 | 敌方 guard 减伤失效（其他效果照常） |
| dispelBuff | 释放时 | 驱散敌方增益：仅技能来源的正向属性状态（六维正向+powerup），不驱散减益/dot/ctrl/weather |
| varietyBuff | 释放时 | 携带属性数 × 每属性层数（atk_up+spa_up） |
| varietyGuard | 释放时 | 基础减伤 + 每属性 +10% |
| varietyHits | 释放时 | 每属性 hits+1 |
| weatherClear | 释放时 | b.weather.turns=0，清空天气 |
| nullifyDamage | 受击时 | 敌方本回合用攻击 → 本次受伤害免伤 |
| cooldownUp | 释放时 | 敌方本回合技能 cooldown +1 |
| condSuperEffective | 伤害前 | 敌方本回合未用防御 → 本技能视为克制（typeMult 当 ×2） |
| neutralizeWeakness | 受击时 | 受到的克制伤害降为普通（×2→×1），抵抗仍 ×0.5 |
| copyPower | 释放时 | 敌方本回合用攻击 → 本次威力=敌方技能威力 |

**cond 条件 key（拍板）**：
- `enemyUsedAttack`：敌方本回合用了攻击技能
- `firstStrike`：我方本回合先于敌方发动
- `hpBelow:{pct}`：我方血量 < pct%（参数化，后续 75% 复用）
- `enemyNoDefense`：敌方本回合未用防御技能
- ~~notDamaged~~：不做，架势 fi_stance 的"未受伤"按 `enemyUsedAttack` 实现

### 2.4 天气系统

- `b.weather = {type, turns}`，与 `b.field` 并行互不覆盖。
- 新天气覆盖旧天气；weatherClear 清空。
- **雪天（暴风雪，5 回合）**：
  - 每回合末（tickStatus 阶段）：双方各 +2 freeze；
  - 冰属性精灵额外 +10 物防 +10 特防（**weather 状态栏**，source 标记）。
- 天气 buff 与技能状态加算（本体 50% + 天气 10 层 = 面板 150%）。

### 2.5 先制度数值化（B 方案，宝可梦式）

**核心改造**：双方同时选择视为一个时点。
- 技能 `priority` 升级为整数（可负）：默认 0；防御技能 −6；先发制人 +1；天气锁 −2；逻辑陷阱 −2。
- **出招排序**：玩家点技能 → 敌人 AI 预选技能（AI 是机器，预选在玩家点技能前/后/上回合结束都不影响）→ 双方按 priority 排序：priority 高者先；相同则面板速度高者先。
- **结算顺序**：按排序依次结算各技能（先发动先结算）；状态 dot 最后统一结算。
- **防御技能后手（−6）**：敌方攻击先结算（先扣血），防御技能后发动（再回血/触发条件效果）。
- **条件判定时机**："敌方本回合用攻击技能"在防御技能发动时判定（敌方先手已行动则为真）；"先手"= 我方技能先于敌方发动。

**双引擎同步**：野外 battleSkill/beastTurn + 副本 dgBattleSkill/dgBeastTurn 都要改成"预选后排序"。敌人预选 = 在玩家点技能时同步算出敌人本回合技能（AI 选招逻辑不变，只是时机提前）。

### 2.6 规则修正（3 项）

1. **冻结删受击解除**：freeze = 纯持续 dot（每层回合末 5% 冰伤，不衰减不解除，同 burn/poison）。
2. **属性免疫**：冰系免疫 freeze / 草系免疫 parasitic / 雷系免疫 para（毒系免疫 poison 已有）。免疫 = 状态附加无效（applyEffects 里按 elem 拦截）。
3. **增减状态 cap:6 移除**：atk_up/down 等 stat 类 cap 从 6 改为不设限（层数由技能配置决定）。dot/ctrl 类 cap 维持（para/burn 等）。

### 2.7 状态栏分账（天气 source）

- 场上角色 buff 分到不同状态栏：`spSt`（技能来源）+ `spStWeather`（天气来源）。
- 净化/驱散只作用于 `spSt`，不碰 `spStWeather`。
- 结算面板时合并两个状态栏（statusMods 读两个相加）。
- 雪天每回合末：冰系精灵在 `spStWeather` 累加 def/sdef（持续期间每回合重置为 +10，不叠加）。

### 2.8 草系与存量技能迁移（§2.10）

| 技能 | 旧写法 | 迁移到 |
|---|---|---|
| 回能 regen | `mech:'surge'` | `effects:[{target:'self',type:'surge',layers:5}]` |
| 种子弹 g_seedshot | `gain:1` | `effects:[{target:'self',type:'gain',layers:1}]` |
| 藤绞 g_vinegrip | `gain:5` | `effects:[{target:'self',type:'gain',layers:5}]` |
| 青草滑梯 g_grassyglide | `{type:'priority',layers:1,cond:'field_grass'}` 布尔先制 | 数值先制：field_grass 内 priority=+1（技能级 priority 数值 + 场地条件） |
| mechToEffects 兼容函数 | 旧 mech 枚举→effects | 删除（迁移后无调用者） |

迁移后行为不变（数值一致）。草系 56 门全部正常，普攻未动。

### 2.9 UI

- 技能编辑器：effects 下拉补新状态/新效果类型；先制度显示数值（整数，可负）。
- 战斗日志：新效果类型有中文描述。

## 3. 执行流程（关键调用链）

**先制度排序（B 方案）**：
1. 玩家点技能 battleSkill(skId) →
2. 敌人 AI 预选：在玩家点技能时同步算出敌人本回合技能（beastTurn 的 AI 选招逻辑提前）→
3. 双方 priority 比较：我方 priority > 敌方 → 我方先；< → 敌方先；= → 按 b.first 速度 →
4. 按排序依次 playerTurn / beastTurn →
5. battleRoundEnd：tickStatus（dot 最后结算）+ 天气回合结算

**天气**：
- 暴风雪释放 → b.weather={type:'snow',turns:5} →
- 每回合末 tickStatus：双方 +2 freeze；冰系精灵 spStWeather.def/sdef=+10 →
- 天气锁释放 → weatherClear：b.weather.turns=0 →
- weather 来源 buff 在净化/驱散时跳过

**新效果（以电磁脉冲 speedRatio 为例）**：
- 释放电磁脉冲 → playerTurn 伤害前读 speedRatio →
- 倍率=clamp(⌊spdSelf/spdEnemy⌋,1,5) →
- 乘在 calcDamage 的 power 上 →
- 敌方麻痹独立乘区最后应用（spdEnemy 已 ×0.5）

## 4. 验收标准（优先引用需求 §4）

1. **技能落池**：40 门样板技能全部入对应属性池，可被副本抽取；编辑器可见且字段完整。
2. **新状态**：leech 每层 10% 攻击回血（与 drain 加算）；combo 每层连击技能 hits+1；costdown 每层 cost−1；powerup 每层威力+10。
3. **天气**：暴风雪开启雪天 5 回合；每回合末双方各 +2 freeze；冰系 +10 def +10 sdef；天气锁清空天气；天气与场地并行；天气 buff 不被净化/驱散。
4. **先制度**：防御技能后手（−6）；先发制人 +1 先动；同 priority 按面板速度；先发动先结算；状态 dot 最后统一结算。
5. **规则修正**：冻结受击不再解除；冰/草/雷免疫对应状态；增减状态层数无 6 层上限（冥想 15 层生效）。
6. **效果点验**：电磁脉冲速度差倍率 clamp 1~5（含麻痹独立乘区）；地球上投物防差倍率；撕咬 hpBelow:50 连击+2；触底反弹每损失 10% 血威力+15；寸止条件免伤+敌方冷却+1；弱点击破条件克制；逻辑陷阱复制敌方威力；战斗堡垒以物防结算；光系三技能按携带属性数（含 none）缩放。
7. **存量迁移**：回能/种子弹/藤绞/青草滑梯迁移后行为不变；mechToEffects 删除后全游戏技能正常；草系 56 门全部正常；普攻未动。
8. **cond key**：enemyUsedAttack / firstStrike / hpBelow(pct参数化) / enemyNoDefense 四类条件可判定。
