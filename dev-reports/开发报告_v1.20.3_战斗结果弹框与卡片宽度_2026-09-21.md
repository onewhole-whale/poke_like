# 开发报告 v1.20.3 · 战斗结果弹框与技能卡片宽度

- **版本**：v1.20.3（基线 v1.20.2）
- **日期**：2026-09-21
- **版本目标**：修复产品验收提出的两个战斗 UI 问题——① 技能卡片宽度缩至现状 1/3；② 战斗结束（一方精灵血量归 0）无退出逻辑，改为弹框显示「战斗胜利/战斗失败」，点确认返回上一层（冒险→地图/冒险结束盘点；副本连战→下一场/通关结算）。
- **本次来源**：产品验收（用户直述「不是的是不是战斗UI管的」两条问题）
- **变更点清单**：战斗 UI × 2（技能卡片布局 / 战斗结束弹框），涉及野生战斗、事件链车轮战、副本连战三条结算路径。

## 1. 变更点

### 1.1 技能卡片宽度 → 现状 1/3
- 现状问题：`.bt-skill-detail` 内技能卡片独占整行（约 660px 全宽）。
- 修正：新增 `.bt-skill-grid` 三列网格容器（`repeat(3,1fr)`，gap 6px），技能/回能/逃跑卡片全部装入网格；卡片内部 name 已有省略号，meta 加 nowrap 省略；响应式：≤960px 两列、≤720px 单列。
- 实测：1440 视口下卡片 216px / 网格 660px = 1/3 精确命中。

### 1.2 战斗结束 → 结果弹框（胜利/失败 + 确认返回上一层）
- 现状问题：战斗结束（phase 变 won/lost）后详情栏只显示日志，退出需玩家自己点「跑」才出现杀死/捕捉或返回——没有明确的结束弹框与退出路径。
- 修正：
  - **触发钩子**：`renderBattle` 末尾检测 `b.phase!=='fight' && !b.resultShown` → `battleResultModal`；`renderSettle` 胜利路径同样钩子 → `dgResultModal`；副本失败在 `dgRoundEnd` 拦截 → `dgResultModal`。每场战斗 `resultShown:false` 初始（startBattle / startDgFight 战斗对象新增字段），保证只弹一次。
  - **野生胜利弹框**：「战斗胜利」+ 击破描述 + [杀死·剥取素材] / [捕捉·留它活口]（逻辑从 showFlee 原样迁移，含精英/Boss 素材升级、无伤加成 flawless、捕捉概率/异色、掉落结算），确认后返回地图（wildNodeDone → move）。
  - **事件链胜利弹框**：「战斗胜利」+ [继续挑战]（有剩余敌人 → 经验 + 下一场）/ [领取奖励]（全灭 → 链奖励 + 回事件链节点）。
  - **失败弹框（野生/事件链）**：「战斗失败」+ 力竭败退说明 + [确认] → 冒险结束盘点（state='done'，原生失败流程）；事件链中断 + loseEffects + 返回地图。
  - **副本胜利弹框**：「战斗胜利」+ 第 X/N 场 + [继续前进]（→ 下一场展示页）/ [通关结算]（末场 → 结算页）。
  - **副本失败弹框**：「战斗失败」+ [确认] → dgLose 结算页。
  - **弹框锁**：结果弹框设置 `window.__modalLock`，遮罩点击不可关闭，必须按钮确认（原遮罩点击关闭逻辑加锁判断）。
  - 「跑」按钮保留为兜底重开入口（phase!=='fight' 时重新弹框）。
- 遗留原状（不在本次范围）：副本（秘境）战斗仍用旧版 `.battle-panel/.bp-side/.skill-btn` 布局，仅结束路径接入弹框。

## 2. 执行流程

- 技能卡片：`showSkills` → 卡片装入 `.bt-skill-grid` → 网格三列渲染。
- 野生战斗结束：`battleSkill/beastTurn` 将 phase 置 won/lost → `renderWild` → `renderBattle` → 钩子 `battleResultModal`（一次）→ 按钮动作 → `wildNodeDone`（回地图）/ `startChainBattle`（下一场）/ `applyChainRewards`（链结算）/ `state='done'`（冒险结束盘点）。
- 副本战斗结束：`dgRoundEnd`（失败）或 `renderSettle`（胜利）→ `dgResultModal` → [继续前进/通关结算] → `dgWinFight`（下一场/通关）/ [确认] → `dgLose`（结算页）。

## 3. 验收标准

1. 战斗（野生 1v1）胜利后自动弹出「战斗胜利」弹框，含 [杀死·剥取素材][捕捉·留它活口]，点任一后返回地图网格（phase='move'）。
2. 战斗失败自动弹出「战斗失败」弹框，点 [确认] 进入冒险结束盘点（state='done'）。
3. 事件链车轮战：胜 → 弹框「战斗胜利」，有剩余敌人时按钮为 [继续挑战] 且进入下一场（chainIdx+1）；全灭时按钮为 [领取奖励] 且回到事件链节点（phase='chain'）。
4. 副本连战：胜 → 弹框「战斗胜利」+ [继续前进]，点击进入下一场展示页；末场按钮为 [通关结算]，点击进入通关结算页（phase='done'，won=true）。
5. 副本失败 → 弹框「战斗失败」+ [确认]，点击进入结算页（phase='done'，won=false）。
6. 结果弹框不可点遮罩关闭（`__modalLock`），必须按钮确认。
7. 技能卡片宽 = 网格宽的 1/3（三列），回能/逃跑卡片同样入网格；小视口 ≤960px 两列、≤720px 单列。
8. 既有战斗逻辑零回归（直接攻击/受击回能/副本结算等套件全绿）。

## 4. 验证方式

- 语法：提取 `<script>` → `node --check`；
- CDP 冒烟：18 项（野生胜/败弹框、链战继续/领奖、卡片 1/3 宽、副本胜/败/通关/下一场、遮罩锁）全部通过；
