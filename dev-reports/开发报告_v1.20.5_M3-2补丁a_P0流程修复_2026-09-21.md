## 1. 变更点

### 1.1 P0-1 妖兽出战补直接攻击（需求 §二 P0-1，方案 A）
- **现状**：`wildSpirit()` 妖兽分支（index.html:5948）`skills:[]`，战斗中只有「回能」，无输出必败。
- **改法**：`wildSpirit()` 妖兽分支 `skills` 由 `[]` 改为 `directUnlocked(sp.elem, b.lvl||1).map(s=>({...s}))`——与敌方妖兽 AI（5452/7656 同源 `directUnlocked`）同规则。
- **浅拷贝说明**：`directUnlocked` 返回 SKILLS 池内对象引用；`battleSkill`（7332）会往 `sp.skills` 元素上写 `uses`，直接用池引用会污染全局池对象。故 `.map(s=>({...s}))` 浅拷贝——id/name/power/elem 等字段齐全，`renderBattle` 8502 经 `skillById(sk.id)` 仍取到（含 skillEdits 覆盖的）最新 def，与灵兽装备技能时拷贝 name 的既有行为一致。
- **占容显示（拍板第 5 条）**：妖兽无容量/亲和力体系，`renderBattle.showSkills` 对 `sp.isBeast` 跳过「占容」段——头部 capInfo 显示"妖兽出战 · 无容量体系"，技能卡 meta 不拼"占容+X"。
- **不动**：副本构建入口（本就不允许妖兽出战）、妖兽受击回能/结果弹框/面板、妖兽 sneak 先手一击（7289 读 `sp.skills[0].mastery/track`，妖兽拷贝无此二字段，沿用默认 mastery=30 与 DIRECT_TRACK，与现状空 skills 行为一致）。

### 1.2 P0-2 野外战斗技能解析统一走 skillById（需求 §二 P0-2）
- **现状**：野外引擎两处查原池 `Object.values(SKILLS).flat().find(x=>x.id===skId)`——
  - `battleSkill`（7329）：技能执行 def 查找；
  - `renderBattle.showSkills`（8502）：技能卡片 def 解析。
- **改法**：两处均改为 `skillById(skId)` / `skillById(sk.id)`（5621 定义，含 `S.skillEdits` 覆盖）。
- **不动**：副本 `dgSkillDef`（5129，已含 skillEdits，回归对象）；5601/5615（副本奖励发技能，非战斗解析）；`skillUsable` 用解析后 def，编辑后能耗/门槛随之生效。

### 1.3 P0-3 野外遭遇策略恢复（需求 §二 P0-3）
- **现状**：`moveTo`（8217）遇 fight 事件直接 `startBattle`；`renderWildNode`（8326，五选项+被突袭应战）整段无调用点；22% 被突袭无确认界面。
- **改法**：
  1. `moveTo` fight 分支三分支化：
     - `template==='boss'` → 直接 `startBattle(beast,'normal',buffs)`（不弹遭遇卡，保持 v1.15.0 决策）；
     - 其他 → 构造 `w.node={type:'beast', beast, ambush:!!event.ambush, buffs:event.buffs, template:event.template}`，`w.phase='node'`，`renderWild()`。
  2. `renderWild` 分派新增 `if(w.phase==='node' && w.node){ root.appendChild(renderWildNode(w.node)); return; }`（置于 result/chain 分支之前、grid 阶段之前）。
  3. `renderWildNode` 按钮回调补传 `node.buffs`：被突袭应战 `startBattle(node.beast,'ambush',node.buffs)`、安抚失败 `startBattle(node.beast,'normal',node.buffs)`、正面战斗/突袭 `startBattle(node.beast, sneak?'sneak':'normal', node.buffs)`。
- **收尾链路（既有，不动）**：安抚成功/悄悄离开 → `wildLoot` → `w.phase='result'` → `renderWildResult`「继续前行」→ `wildNodeDone` 标记当前格 resolved 并回网格；战斗结束经 `battleResultModal` → `wildNodeDone`。

### 1.4 P0-4 捕捉成功点亮图鉴（需求 §二 P0-4）
- **现状**：`battleResultModal` 捕捉成功分支（8607）直接 `S.beasts.push(...)`，未调 `markDexSeen`。
- **改法**：push 后补一行 `markDexSeen(b.beast.speciesId)`（最小改动路径，不改成 makeBeast 构造）。
- **边界**：捕捉失败（宁死不从，8613 else 分支）不动；重复 push 同物种 markDexSeen 幂等（`S.dexSeen[id]=true`）；异色沿用现有 shiny 判定。

## 2. 执行流程

- **妖兽出战**：选妖兽入野 → `wildSpirit()` 现算 `skills=directUnlocked(elem,lvl)` 浅拷贝 → `renderBattle` 遍历 `sp.skills` 渲染直接攻击卡 + 回能卡 → 点卡 → `battleSkill(skId)` → `skillById(skId)` 取 def（含编辑覆盖）→ `playerTurn` 结算。
- **遭遇节点**：`moveTo` 踩 fight 格 → boss 直战 / 非 boss 走 `phase='node'` → `renderWildNode` 五选项卡 → 各按钮走安抚 roll / startBattle（带 buffs）→ 结束统一 `wildNodeDone` resolved。
- **捕捉点亮**：胜局弹框点「捕捉」→ 60% 成功 → `S.beasts.push` + `markDexSeen(speciesId)`。

## 3. 验收标准（引用需求 §四，逐条对应）

**P0-1**
1. 选妖兽出战进野外战斗：技能栏 ≥1 张直接攻击卡（属性=妖兽属性、含威力/能耗/类型）+ 回能卡（技能卡数 ≥2）。
2. 循环点直接攻击卡：敌方掉血；普通 1v1 可胜（`phase==='won'`）。
3. 副本构建界面仍不可选妖兽（入口不变）。
4. 灵兽出战零回归：技能栏=原技能+回能，数量/行为不变；妖兽出战技能卡不显示「占容」（头部显示"妖兽出战·无容量体系"）。

**P0-2**
5. 编辑器把某技能 power 改 999 → 野外释放该技能伤害显著 > 原版。
6. 编辑器新增自定义攻击技能并装配 → 野外技能栏显示该卡（非"—"），点击生效（敌方掉血+日志）。
7. 副本用同一编辑技能伤害与编辑前一致（dgSkillDef 路径不回归）。

**P0-3**
8. 遇非 boss 非被突袭 fight → 五选项卡（正面安抚/正面战斗/悄悄离开/悄悄安抚/悄悄突袭）。
9. 正面安抚成功 → 免战 + calm 掉落 + 回网格 + 事件格 resolved；失败 → 进战斗。
10. 悄悄安抚成功 → 免战 + calm 掉落；失败 → 进战斗（无先手）。
11. 悄悄突袭 → 玩家先手一击（`b.hitBeast=true`）。
12. 悄悄离开 → 无掉落、回网格、事件格 resolved。
13. 被突袭事件 → 「被突袭·应战」卡；应战 → 敌方先手一击（`b.hitSelf=true`）。
14. boss 事件 → 直接正面对峙，不弹遭遇卡。

**P0-4**
15. 捕捉图鉴未点亮物种成功 → `S.dexSeen[speciesId]===true`。
16. 重复捕捉同物种不报错；捕捉失败不点亮。

**回归**
17. damage / wild / mech / v1192 / v1195 套件全绿；本次不新增过期断言。
