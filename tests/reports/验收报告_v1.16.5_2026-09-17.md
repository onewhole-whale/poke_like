## 3. 差异清单（给开发 agent 的核心反馈）

### D1【严重】545 条专属素材落库，超出 v1.16.5 验收范围

- **设计预期**：验收指令明确"**13 素材中仅 SC_none_fine_000001 落库**"、"采集素材空、空手采集 0 出货、奇遇 normal/bad 无素材奖励（M3-1-4 补测试素材后恢复）"；DEV_PLAN §10 v1.16.5 行"② MATS 旧 13 条采集素材全清、旧素材 id 引用全部清空；**仅 life-essence 保留机制**、归普通系重编码 SC_none_fine_000001"。
- **实测行为**：MATS 实存 **546 条** = SC_none_fine_000001 + **545 条专属素材**（SC_fire_normal_000014 ~ SC_fire_legend_000558，如"烬灰碎毛/焦爪印/烬牙"等）；**109 只 SPECIES.drops 全部挂载专属素材**（妖兽战 kill/calm 有掉落）；炼化投妖兽入炉带出专属掉落+生命精华。
- **差异描述**：开发按需求文档 §1.2 素材配置表（545 条，§1.1 明确"专属素材承接 000014 起、共 545 条"）落库——**数据与 §1.2 逐条比对完全一致（0 缺 0 多，id/name/elem/quality/type/count 全匹配，抽 8 组含首尾）**，但超出 v1.16.5"补丁 · id 编码体系（纯 id 替换 + 清理）"范围。**根源：需求文档 §1.1（545 条落库定稿）与 DEV_PLAN v1.16.5 行（仅保留生命精华）冲突，开发选择了需求文档**。空窗（采集/奇遇）已实现，但妖兽战掉落已挂 545 专属（非空窗）。
- **严重程度**：严重（范围差异，需用户/产品拍板）。
- **修复建议**：
  - **方案 A（回滚，严格按 v1.16.5）**：删除 MATS 545 条专属素材 + SPECIES.drops 清空，v1.16.5 保持"仅生命精华"空窗；545 条素材随 M3-1-3 主版本（v1.16.6+）另落。
  - **方案 B（认可提前落库）**：545 条与需求文档 §1.2 定稿完全一致，视为提前完成 M3-1-3 素材填充主内容；验收口径更新为"素材已落库"，后续验收按新口径（妖兽战有掉落、训练有素材可用）执行。**测试侧倾向 B（数据正确、无回归），但以用户拍板为准**。
