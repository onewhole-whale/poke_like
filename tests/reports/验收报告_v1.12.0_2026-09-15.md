## 3. 差异清单（给开发 agent 的核心反馈）

> 全部为【警告】级（文案 / 文档 / 日志顺序），**无功能不一致**。5 机制 + 8 技能 + 双引擎全部按设计工作。

### #1【警告】混乱 / 寄生「附加当回合末即结算并衰减一次」的时序与 §4 断言表述不完全对应

- **功能点**：混乱（§4.4）、寄生（§4.7）
- **设计预期（§4 原文）**：「第 3 回合后 `spSt.confusion===3`」「命中后敌方 `parasitic===3`，每回合末流失 9%」
- **实测行为**：
  - 混乱：花瓣舞第 3 回合末附加 3 层后，同回合 `tickStatus` 立即结算一次并衰减 → **回合末观察值为 2**，实际自伤生效 2 个完整回合（第 4、5 回合）。`confusion===3` 仅在 tickStatus 之前成立。
  - 寄生：茁茁炸弹命中回合末即结算 9% 流失并衰减 3→2 → **回合末观察值为 2**；流失节奏为 9%/6%/3%，第 3 个回合末归零（总流失 18%，符合 desc「持续 3 回合」）。`parasitic===3` 仅在 tickStatus 之前成立。
- **差异描述**：附加当回合的「层数=3」断言需要放在 tickStatus 之前测；回合末的合法观察值是 2（衰减 1 次）。该语义与既有状态（麻痹 4 层当回合末衰减、实际 3 回合）完全一致，**非新增缺陷**，属验收标准断言表述未覆盖回合末时序。
- **严重程度**：警告（文档表述，非实现 bug）
- **修复建议**：开发报告 §4.4 / §4.7 补一句时序说明：「层数在附加当回合末即结算并 −1，回合末观察值 = 附加值 −1，实际持续 = 附加值 −1 个完整回合」；或将验收断言改为回合末观察值。

### #2【警告】叶绿爆震 desc 文案（「反噬」）与战斗日志文案（「反震」）不统一

- **功能点**：反震（§4.6）
- **设计预期（§2.4 / desc）**：desc 为「……承受反噬伤害」
- **实测行为**：战斗日志实际输出「炎狼 受到 16 点反震伤害」（`applyMechEffect` recoil 分支文案为「反震」）
- **差异描述**：同一效果两处用词不一（desc=反噬、日志=反震），不影响数值（33% 自伤正确），纯文案一致性。
- **严重程度**：警告
- **修复建议**：统一为「反震」或「反噬」其一（建议统一为 desc 的「反噬」）。

### #3【警告】效果附加的日志 push 顺序：效果日志先于伤害日志（与结算顺序相反）

- **功能点**：机制技效果日志（蓄力/寄生/连舞混乱等）
- **设计预期**：无显式规定日志顺序；自然阅读预期为「伤害 → 效果」
- **实测行为**：`playerTurn` / `dgPlayerTurn` 中 `applySkillEffects` 的效果日志（如「寄生 3 层」「进入蓄力状态」）先于伤害日志 push；而实际结算顺序是伤害 → 效果。日志展示顺序与结算顺序相反，同回合日志形如「…受到 48 点伤害…（效果日志已在上方）」。
- **严重程度**：警告（仅日志展示顺序）
- **修复建议**：`playerTurn` / `dgPlayerTurn` 中把效果日志 push 移到伤害日志之后（双引擎同步改）。

### 已确认无问题的观察点（供记录，非差异）

- **§6 parasitic 连带调整（永续→每回合 −1，寄生种子 2 层=2 回合）**：实现已按「层数=持续回合」落地，与 desc「持续 3 回合」一致。该连带开发侧标注【待用户确认】——**用户尚未表态**，本验收按当前实现记录：茁茁炸弹 3 回合（9/6/3% 总 18%），寄生种子随之变为 2 回合（6%/回合 总 12%）。若用户要求寄生种子保持永续，属设计决策变更，需开发侧改方案，届时回归复测。
- **混乱自伤不吃状态修正**：实测混乱自伤 = 40 威力无属性物理、吃面板（不含 buff/debuff 修正）、50% 概率、每回合 −1，与 §6 声明一致。
- **千变万花「必定命中」**：当前引擎默认全命中，行为符合 desc，未单独挂载 accuracy —— §6 遗留观察点，维持现状，非本次范围。

## 6. 最终结论

**【存在警告，建议完善文案与文档】**

- 功能层面：v1.12.0 全部 5 个新战斗机制（先制/命中/蓄力/连舞/力竭）、8 门草系技能 desc↔effects、双引擎一致性、21 套回归**全部通过，0 功能 FAIL**。
- 3 条【警告】均为非功能项：① §4 混乱/寄生断言未覆盖「附加当回合末即衰减」时序（与既有状态语义一致，建议补文档）；② 叶绿爆震 desc「反噬」vs 日志「反震」文案不统一；③ 效果日志 push 顺序先于伤害日志（展示顺序与结算顺序相反）。
- 1 条【待用户确认】：§6 parasitic 永续→每回合 −1 连带（寄生种子 2 层=2 回合），用户尚未表态；当前实现与 desc「持续 3 回合」一致。

**建议开发侧处理**：3 条警告均为文案/文档级，不影响玩法正确性，可在下个版本顺手修复；parasitic 连带等待用户确认后定稿。
